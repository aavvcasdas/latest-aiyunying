# 立绘（长大后的样子）—— 默认不用

> **一句话**：`立绘/art/raw/` 里那八张全身立绘，是这几位角色的**长大后的样子**。
> **一般不用，不建议用，只有明确说「长大」才采用。** 其余所有画面（MV、封面、图鉴、分镜）照旧用 Q 版图集格。
> **可以混用**：一条片子里允许放 1–2 个立绘镜头，条件是那一刻正好是戏里的「长大」（时间跳跃、多年后、长大），
> 或者立绘在这个景别上效果明显更好。混用不是默认，是例外。
>
> 技术说明（怎么抠图、怎么形变、怎么离线渲染）在 [`../立绘/README.md`](../立绘/README.md)；
> 已经渲出来的一套动作预览在 [`../番外MV/立绘/`](../番外MV/立绘/)。

## 2. 为什么默认不用

1. **比例对不上人设页。** 人物页、图鉴、动作库写的都是 Q 版格子（`whale_idle`、`gpt_boss_*`…）；
   立绘是七头身，和 Q 版**同框会跳**，剪在一起像两部片子。
2. **演不了手和嘴。** 单张立绘没有独立的手臂、眼睛、嘴，所以没有抬手、眨眼、口型：
   「打招呼」是侧身加轻跳，「递出去」是整个人前探，不是真的伸手。要这些得先拆层。
3. **它不是从图集来的。** 图集是从上游 `assets/ai-girls/` 那批像素图重建的；立绘是另一条 AI 生成的线
   （见 [`../素材许可与来源.md`](../素材许可与来源.md)）。两套形象在细节上并不严格一致。
4. **它走的是另一套渲染。** 立绘靠浏览器实时形变（`/cast`、`/`）或 `立绘/tools/render-actions.mjs` 离线出图；
   Remotion 那条成片线（`通用模板/engine`）喂不了立绘。用它就等于另开一条产线。

这四条说明的是「为什么不默认用」，不是「绝对不能用」——长大时刻该用就用，只是别整片都换过去。
立绘进成片目前只能靠离线出图／录屏再剪进去，Remotion 那条线还没有把它接进去（要接是另一件事）。

## 3. 什么时候可以用

- 用户**明确说要「长大的样子」「长大版」「立绘」**——原话里得出现这三个词之一。
- 单独做「立绘动作」素材本身（像 `番外MV/立绘/立绘_动作总览.png` 和 24 个 gif 那样）。
- **片子里的「长大」时刻**：时间跳跃、多年后、回忆退场的那一刻——这些地方可以切立绘，观众看到的是「她长大了」，
  不是「换了个画风」。这是混用最正当的用法。
- **立绘明显更好看的那个景别**：比如全身摆拍、需要七头身比例撑住的构图。这种也算，但要能说清好在哪。
- 做「小时候 / 长大后」对照时，两边分别标注。

**没有明确说「长大」、也不是长大时刻的时候，一律按 Q 版图集走**——哪怕立绘看起来更漂亮。

## 4. 用的时候怎么落

- 分镜、需求、文件名都带标记：镜头 id 或目录加 `_长大` / `长大版`，别人一眼能看出这是另一套。
- **一条片子允许混用，但要有分寸**：通常 1–2 个立绘镜头（约 3–8 秒）就够；不要一半 Q 版一半立绘，
  那会读成两部片子拼起来。
- **同一个镜头里不让两套形象并排**：立绘和 Q 版分镜给，切换处放一个明确的转场——
  闪白、推镜、同一构图对切、镜头穿过雨/门/光，让观众读到的信号是「长大了」。
- 立绘的素材一律从 `立绘/art/tachie/` 取（`art/raw` 是原图，`art/tachie` 是透明底可直接用的那份）。

## 5. 混用的两种标准做法

| 用法 | 怎么接 | 例子 |
| --- | --- | --- |
| 长大瞬间 | Q 版最后一镜 → 闪白/推镜 → 立绘第一镜（同一构图、同一站位） | 小时候蹲在水洼边 → 长大后站在同一片雨里 |
| 长大后收尾 | 全片 Q 版，最后一到两镜切立绘，做「多年以后」 | 结尾她站在门外，七头身，回头看 |

两种都要求：**只在长大之后才出现立绘**，不提前；出现之后尽量别再切回 Q 版，真要切回去得让人一眼看出是回忆（画质、色差、画幅变化都行）。

## 6. 出处

- 用户 2026-11-14 上传的 `立绘图片.zip`（仓库根）＋ `立绘.zip`（同一天上传的工程包，含 `rig.ts` / `actions.ts` / 播放台）。
- 包内 `立绘说明.txt` 写明：**图片为 AI 生成**，静态立绘不含逐帧动画，公开使用前自行确认角色形象与平台声明。
- 和 Q 版图集的关系：两套形象都照 [`人物/`](人物/) 第 2 节的视觉锚点来，但**不是同一批图**，谁也不是谁的上游。
