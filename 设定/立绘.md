# 立绘（长大后的样子）—— 主要用 Q 版，长大时刻接立绘

> **一句话**：`人物/立绘/art/raw/` 里那八张全身立绘，是这几位角色的**长大后的样子**。
> **主要用 Q 版**；立绘一般不用、不建议用，只有「长大」的时候才接。
> **允许混用，也允许同一个镜头里混**：一条片子里放 1–2 个立绘镜头（或一两段），
> 可以是**动态长大**（Q 版缩小淡出、长大版浮现），也可以是**和长大的自己对话**（小时候蹲着、长大版站着低头看她）。
> 判断标准只有一条：这一刻是不是「长大」；是就接，不是就别接。
>
> 技术说明（怎么抠图、怎么形变、怎么离线渲染）在 [`../人物/立绘/README.md`](../人物/立绘/README.md)。

## 2. 为什么默认不用

1. **比例对不上人设页。** 人物页、图鉴、动作库写的都是 Q 版格子（`whale_idle`、`gpt_boss_*`…）；
   立绘是七头身，和 Q 版**同框会跳**，剪在一起像两部片子。
2. **演不了手和嘴。** 单张立绘没有独立的手臂、眼睛、嘴，所以没有抬手、眨眼、口型：
   「打招呼」是侧身加轻跳，「递出去」是整个人前探，不是真的伸手。要这些得先拆层。
3. **它不是从图集来的。** 图集是从上游 `assets/ai-girls/` 那批像素图重建的；立绘是另一条 AI 生成的线
   （见 [`../素材许可与来源.md`](../素材许可与来源.md)）。两套形象在细节上并不严格一致。
4. **它走的是另一套渲染。** 立绘靠浏览器实时形变（`/cast`、`/`）或 `人物/立绘/tools/render-actions.mjs` 离线出图；
   Remotion 那条成片线（`通用模板/engine`）喂不了立绘。用它就等于另开一条产线。

这四条说明的是「为什么不默认用」，不是「绝对不能用」——长大时刻该用就用，只是别整片都换过去。
立绘进成片目前只能靠离线出图／录屏再剪进去，Remotion 那条线还没有把它接进去（要接是另一件事）。

## 3. 什么时候可以用

- 用户**明确说要「长大的样子」「长大版」「立绘」**——原话里得出现这三个词之一。
- 单独做「立绘动作」素材本身（`人物/立绘/tools/render-actions.mjs` 离线出一套 gif）。
- **片子里的「长大」时刻**：时间跳跃、多年后、回忆退场的那一刻——这些地方可以切立绘，观众看到的是「她长大了」，
  不是「换了个画风」。这是混用最正当的用法。
- **立绘明显更好看的那个景别**：比如全身摆拍、需要七头身比例撑住的构图。这种也算，但要能说清好在哪。
- 做「小时候 / 长大后」对照时，两边分别标注。

**没有明确说「长大」、也不是长大时刻的时候，一律按 Q 版图集走**——哪怕立绘看起来更漂亮。

## 4. 用的时候怎么落

- 分镜、需求、文件名都带标记：镜头 id 或目录加 `_长大` / `长大版`，别人一眼能看出这是另一套。
- **一条片子允许混用，但要有分寸**：通常 1–2 个立绘镜头（约 3–8 秒）就够；不要一半 Q 版一半立绘，
  那会读成两部片子拼起来。
- **同一个镜头里可以混，但要给信号**：动态长大时让 Q 版缩小淡出、长大版浮现，中间配一次闪白或推镜；
  两人同框（小时候与长大的自己）时，靠身高差和站位分开——小孩压低、长大版站直，别让两人重叠成一团。
  引擎里现成两个东西：`k.tachie('whale')` 和 `growInto(q, g, p)`（见第 6 节）。
- 立绘的素材一律从 `人物/立绘/art/tachie/` 取（`art/raw` 是原图，`art/tachie` 是透明底可直接用的那份）。

## 5. 混用的两种标准做法

| 用法 | 怎么接 | 例子 |
| --- | --- | --- |
| 长大瞬间 | Q 版最后一镜 → 闪白/推镜 → 立绘第一镜（同一构图、同一站位） | 小时候蹲在水洼边 → 长大后站在同一片雨里 |
| 长大后收尾 | 全片 Q 版，最后一到两镜切立绘，做「多年以后」 | 结尾她站在门外，七头身，回头看 |
| 同一镜头长大 | Q 版缩小淡出 + 立绘浮现放大（`growInto`），站位不动，中间闪白 | 蹲在水洼边的孩子 → 同一位置上站起来的大人 |
| 和长大的自己对话 | 一镜里两个：Q 版矮身位在左，立绘站直在右，视线对得上 | 小时候抬头问，长大后的自己低头答 |

三种做法都要求：**只在长大那一刻才出现立绘**，不提前；出现之后尽量别再切回 Q 版，真要切回去得让人一眼看出是回忆（画质、色差、画幅变化都行）。
同一个镜头里做长大，要留出 0.5–1 秒的过渡（闪白前后各 3–5 帧），别一帧之内换人。

## 6. 接进通用模板（Remotion 成片线）

2026-11-14 接好了，混用镜头不用再单独出图再剪：

| 位置 | 是什么 |
| --- | --- |
| `通用模板/engine/tachie.ts` | `TACHIE` 八位角色的长大版、`Tachie` 类、`growInto()`；形变直接调 `人物/立绘/src/mv/rig.ts` 的 `drawTachie`，两条线只有一套公式 |
| `通用模板/engine/core.ts` `Kit.tachie(id)` | 镜头里派一位长大版上场：`k.tachie('whale').act('idle', f.t).at(0, 0, 0)` |
| `通用模板/engine/engine.ts` | 每帧 begin / commit 立绘，全片预检也把它算进去（会不会消失、算不算得出、倒着走一不一样） |
| `通用模板/样板/tachie/` | 三个镜头的样板：G1 小时候 → G2 动态长大 → G3 同框对话 |

```bash
npm run film -- info   通用模板/样板/tachie        # 预检 + 时间轴
npm run film -- stills 通用模板/样板/tachie 200     # 抽一帧看长大版
npm run film -- sheet  通用模板/样板/tachie        # 三个镜头的分镜总览
```

写混用镜头的三条注意：

1. **立绘要预载**：`project.tsx` 的 `preloads` 里加 `() => preloadImage(TACHIE[id].url)`，否则第一帧是空贴图（`imageOf` 会直接报错，不会静默）。
2. **动作名**来自 `人物/立绘/src/mv/actions.ts`（`idle` / `wave` / `bow` / `tilt` / `sway` / `hop` …），没有抬手和口型。
3. 立绘是 unlit 材质，颜色由引擎按镜头调色（`cardTint`）对齐，别自己再上色；要半透明就用 `.alpha()`。
