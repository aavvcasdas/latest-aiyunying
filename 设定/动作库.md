# 动作库（写分镜时查）

写镜头时最容易卡的一句话是「她这会儿在干什么」。这张表给的是**动作名**，不是画面来源。
动作名借自 [`Houraiji9/ai-pet-7in1`](https://github.com/Houraiji9/ai-pet-7in1) 的 112 段动画清单（每个角色 112 段，DeepSeek 娘 106 段）；**画面不借**，理由见 [`素材许可与来源.md`](../素材许可与来源.md) 第三节。
我们能不能演，按 `通用模板/README.md` 里的造型格与角色方法判断。

## 一、引擎现在能给的

| 能做的 | 怎么写 |
| --- | --- |
| 正面待机 + 自动眨眼 | `.front(T)` |
| 换造型（硬切） | `.set('格子名')` |
| 走（脚不打滑）、来回走、按位移走 | `.walk(T, 速率)` / `.walkX(a, b, p)` / `.walkBy(距离)` |
| 跳、挤压拉伸、倾斜 | `.lift(h)` / `.sq(a)` / `.tilt(r)` |
| 透明、隐藏、闪白、剪影、染色、去影 | `.alpha()` `.hide()` `.flash()` `.sil()` `.tint()` `.noShadow()` |
| 服饰叠层 | `.wear('crown'\|'hood'\|'tophat'\|'bow'\|'tiara'\|'ears'\|'tail')` |
| 说话时轻颠 | `.talk(T, true)`（写在上面的修饰之后） |

**没有的**：手部动作、道具互动动画、口型、独立的"跑"帧、情绪切换的中间帧。这些只能靠**镜头调度 + 道具 + 字幕**凑，或者新做造型格。

## 二、状态机：现在这些片子要哪几个状态

| 状态 | 7in1 里对应的动作名 | 我们怎么拍 |
| --- | --- | --- |
| 待机 | `待机呼吸休闲`、`原地漂浮踏步` | `.front(T)`，安静两秒就够，别一直抖 |
| 登场 | `登场-星光现身` | `.flash()` 一拍 + `.sil()` 剪影 → 换造型；或从画外走进来 `.walkX()` |
| 走 / 跑 | `原地左转走路`、`原地左转奔跑`、`螃蟹走路` | `.walkX()`；"跑"靠提高速率 + 加大位移，不是换造型 |
| 被拎起 / 悬空 | `被鼠标拖拽悬空反馈` | `.lift()` + `.tilt()` + `.sq()` 三件一起用 |
| 点击回应（开心 / 害羞 / 生气） | `点击回应-元气挥手`、`-害羞惊讶`、`-傲娇生气`、`-开心跃动`、`-挠痒咯咯笑` | 挥手用 `whale_wave`；生气用 `gpt_boss_rage`；害羞只能靠 `.tilt()` + 侧身 |
| 工作（忙 / 卡 / 认输 / 完成） | `工作状态-忙碌点按`、`-原地踱步张望`、`-垂头叹气冒汗`、`-思考冒泡`、`-清点归档`、`-雀跃庆祝` | 踱步 = 小范围 `walkX` 来回；认输 = 垂头靠 `.tilt()`；庆祝 = `.lift()` + `.flash()`；**思考冒泡、清点归档要气泡或道具，现在没有** |
| 碎碎念 | `碎碎念-发呆碎碎念`、`-对屏碎碎念`、`-擦桌碎碎念` | `.talk(T, true)` + 对话条；对着屏幕说的那种，机位放她身后 |
| 额度 / 余额 | `余额-钱袋满溢` … `余额-分文不剩`（六档） | **不能拍钱袋**：画面红线不许余额条。改成米缸深浅、碗里剩多少、饭价牌翻面 |
| 专属动作 | 每角色 6 段（Grok 是 `专属-X标志`、`专属-坏笑吐槽`、`专属-坐火箭`、`专属-太空漂浮`、`专属-星系`、`专属-黑洞`） | 都没有对应造型格（Grok 那 6 段也没有——她 2026-11-12 起连待机 / 侧身 / 步态都没有了）。真要，先加像素数据重建图集 |

## 三、能直接用现有造型演的

这些动作名，用现有的格子加修饰就能兑现，写分镜可以直接抄：

`待机呼吸休闲` · `原地漂浮踏步` · `原地左转走路` · `原地左转奔跑`（加速率）· `小幅度原地360度旋转展示`（翻转 + 换侧身格）· `东张西望`（侧身格来回切）· `原地重力下蹲压缩`（`.sq()`）· `原地跳跃抓碎头顶物品`（`.lift()`，头顶物品得另做道具）· `超大伸懒腰`（`.sq()` + `.lift()`）· `哈欠连天`（眨眼格 + 慢速）· `被鼠标拖拽悬空反馈` · `点击回应-元气挥手` · `点击回应-开心跃动` · `点击回应-傲娇生气` · `数金皱眉` 这一类"皱眉"可以换成头像格 `p_gpt_haughty` / `p_claude_dizzy` 那种。

## 五、怎么用这张表

1. 先写"她要完成什么"，再从第二节挑一个状态，别一集塞五个状态。
2. 挑到第四节的动作，先问一句：**这一镜能不能用别的方式表达同一个意思**（换成对话条、换成道具特写、换成别人的反应）。能换就换，不能换才考虑做道具或加造型格。
3. 加造型格的唯一正规路径：往 `通用模板/cast/source/` 加像素数据 → 重建图集（`npm run atlas`）→ `npm run atlas:check` 校验 → 再写镜头。**不许生图，不许把外部素材抠进来。**

## 六、来源与边界

- 只借命名与分组，**没有使用它的任何画面**；它的素材是 CC BY-NC-SA 4.0（非商业），我们的成片不接。
- 我们的造型格以 `通用模板/README.md`「八位角色与可用造型」为准；图集由 `通用模板/cast/source/` 重建，来源与许可另见 [`素材许可与来源.md`](../素材许可与来源.md)。
