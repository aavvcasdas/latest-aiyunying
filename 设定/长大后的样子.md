# 长大后的样子（图集里的非 Q 版格）

> **一句话**：图集里真正画成成年比例的整身格只有**两组**——龙娘的 `gpt_boss_*` 和豆包的 `walk_doubao_big_*`；
> 本鲸的 `whale_big_*` 只是「大只版」，比例仍是 Q。其余角色**一格都没有**，不许凭空画。
> 对照图：[`图鉴/长大后的样子_对照.png`](图鉴/长大后的样子_对照.png)（三组等高摆放，头身比一眼看得出来）。
>
> 这份只管**形象**；谁是谁、什么性子在 [`人物设定.md`](../番外MV/人物设定.md) 与 [`人物/`](人物/) 里。
> 出处一律是仓库自己的图集：`通用模板/engine/assets/cast_atlas.png` + `cast_atlas.json`，
> 精灵源码在 `通用模板/cast/source/`（`sprites_data.js` / `walk_cycle_data.js`），**不新增生图**。

## 1. 有什么（一张表）

| 角色 | 成年格 | 格数 / 尺寸 | 是什么样 | 能演 | 不能演 |
| --- | --- | --- | --- | --- | --- |
| 龙娘（`gpt`） | `gpt_boss_idle` `gpt_boss_blink` `gpt_boss_rage` `gpt_boss_cast0` `gpt_boss_cast1` | 5 格 · 132×176（cast0 137、cast1 127） | 白发长角、白金长裙、龙尾，**约 4.5–5 头身**，细腰长腿，一眼不是 Q | 正面待机 / 眨眼 / 生气 / 抬手施法（两个方向） | **没有成年步态**（她的走是 `gpt_fly_0/1` 的龙形飞掠）；没有背面、没有坐姿、没有吃东西等派生动作 |
| 豆包（`doubao`） | `walk_doubao_big_0` … `_7` | 8 格 · 86×84 | 棕色短发、黑色上衣长裤的上班族，**约 5–5.5 头身**，只在侧面 | 走路（8 帧循环）、站着（用第 0 帧当站姿，别配上身动作） | **没有成年正面立绘**：正面只有 `doubao_cage_0/1`（鸟笼里的半身）和 `act_doubao_idle_*`（Q 版派生动作）——所以「长大后的豆包」站在那儿朝镜头说话这件事，目前演不了 |
| 本鲸（`whale`） | `whale_big_idle` `whale_big_blink` `whale_big_wave` `whale_big_point` | 4 格 · 131×148 | 尺寸是常规格的两倍、细节更多，但**头大腿短，比例仍是 Q**（约 3.5 头身） | 正面待机 / 眨眼 / 挥手 / 指 | 当「成年本鲸」用——它不是；没有步态、没有背身 |
| 小克 / 猫 / Kimi / 千问 / 狐狸 | 无 | — | 只有 Q 版正面两格 + 步态 8 帧（`claude_front_*`、`gemini_front_*`、`kimi_front_*`、`qwen_front_*`、`zai_front_*`） | 日常线全部 | 一切「长大后的她」——图集里没有，写分镜时不许自己编 |
| 笨鱼 / 老大 / Grok | 无 | — | 无造型格（Grok 的 13 格 2026-11-12 因发糊撤下） | — | 同上 |

**尺寸与缩放是两回事。** 这三组格子在图上画得比常规格大，引擎里必须同时把世界尺寸压回去，否则人比场景还高：

| 键前缀 | 引擎里的缩放 | 在哪 |
| --- | --- | --- |
| `gpt_boss`（及 `act_gpt_*` 除 hover） | `0.58` | `通用模板/engine/actors.ts` 的 `scaleFor()`；`勾指起誓_gemini4` 的 `src/engine/actors.ts` 同款；`勾指起誓_opus5.5` 的 `src/mv/gfx.ts` 里叫 `unit()` |
| `whale_big` | `0.60` | 同上 |
| 其余 | `1` | 基础像素单位 `PX = 0.0195` 世界单位 |

## 2. 在 MV 里怎么用

引擎里「谁能站着、谁能走」是**按角色登记**的，不是按镜头现挑的。想换成年形态，改的是登记表：

| 工程 | 登记在哪 | 现在的样子 |
| --- | --- | --- |
| 通用模板（`番外MV/童话镇` 等） | `通用模板/engine/actors.ts` → `CAST_SETS` | `gpt: { front: ['gpt_boss_idle','gpt_boss_blink'] }`（**龙娘默认就是成年格**）；`doubao: { walk: 'walk_doubao_big_', front: ['doubao_cage_0','doubao_cage_1'] }`（**走是成年、站是半身**）；`whale: { front: ['whale_idle','whale_blink'] }`（Q 版） |
| `勾指起誓_gemini4` | `src/engine/actors.ts` | 与模板同一张表（脚本是从模板抄的） |
| `勾指起誓_fable5.1max` | `src/mv/atlas.ts` 的 `CAST` 表（每行 `front` / `side` / `walk` / `walkN`） | 龙娘 `front: ['gpt_boss_idle','gpt_boss_blink']`、`side/walk` 走 `gpt_fly`；豆包 `side/walk` 走 `walk_doubao_big`、`front` 却挂 Q 版派生动作 `act_doubao_idle_0/4` |
| `勾指起誓_opus5.5` | `src/mv/gfx.ts` 的 `FRONT` / `WALK` 两张表 | `gpt: 'gpt_boss_idle'`、`whale: 'whale_idle'`、`doubao` 走 `walk_doubao_big_`、正面 `doubao_cage_0` |
| 《坏女孩》3D | `番外MV/坏女孩/src/mv/three/actors.ts` | 构造函数留了 `big` 开关（`actor(id, size, big)` → `this.big ? 'whale_big_idle' : 'whale_idle'`），但 `shots.ts` 里**没有一处传 true**；龙娘恒用 `gpt_boss_*` |

想临时在某个镜头里直接用某一格（不改登记表），照各家 `drawSprite(ctx, 'gpt_boss_cast0', x, y, { scale })` 这类写法直接点键名即可——
**点错键名会当场抛错**（`rectOf()` / `castPreflight()` 找不到格就报），不会静默换成别人。

### 什么时候可以说「这是长大后的她」

1. **番外 / 回忆 / 另一条时间线**里可以，日常线不可以——日常线一律 Q 版，这是这套片子的画风锚。
2. 说清楚是**几年后**：龙娘的成年格是长裙＋长尾，适合「很久以后还在原地等」这类镜头；豆包的成年格是通勤装，适合「她后来去上班了」。
3. 一个镜头里**不许两个比例的同一角色同时出现**（Q 版站在成年版旁边 = 观众会以为是两个人）。
4. 换形态要**在剪辑上给一个交代**（黑场、翻信纸、镜头穿过门），不许硬切。

### 现在就已经在用的地方

- 《坏女孩》3D：龙娘全程 `gpt_boss_*`，就是成年比例；本鲸有 `big` 开关。
- `勾指起誓` 三支：豆包**走路**用的是成年格（`walk_doubao_big_*`），站定/说话时回到 Q 版——这条是现成的「长大只长腿」的 bug，写新分镜时要么只用她走路，要么别让她站定说话。
- 参考 MV（`参考资料/参考MV/反乌托邦/`）的「每天重演」镜头：一排本鲸全用 `whale_big_*`（`s: 0.8`，按拍点换 idle / wave / point）。

## 3. 想新增「长大后的样子」怎么走

1. **只走图集这条线**：`通用模板/cast/source/walk_cycle_data.js`（步态）/ `sprites_data.js`（立绘）加格 → `通用模板/cast/bake_atlas.mjs` 重建 `cast_atlas.png` 与坐标表 → `npm run atlas:check` 逐字节自校验。
2. 新格的**编号必须从 0 连着编**（`setProblems()` 会查），尺寸要跟同族一致，否则 `atlasProblems()` 会让 `loadAtlas()` 直接拒绝加载。
3. **不改别人的格**：图集是九支片子共用的，改一格等于九支一起变；要试新造型就新开一个前缀（如 `whale_adult_*`）。
4. 不新增生图、不拿官方头像顶（见 [`素材许可与来源.md`](../素材许可与来源.md)）。

## 4. 出处与校验

- 坐标与尺寸：`通用模板/engine/assets/cast_atlas.json`（2048×3126 / 682 格）。
- 精灵源码：`通用模板/cast/source/sprites_data.js`、`walk_cycle_data.js`；重建脚本 `通用模板/cast/bake_atlas.mjs`。
- 对照图生成：按坐标表逐格裁切，等比缩到等高后排在同一基线上（`设定/图鉴/长大后的样子_对照.png`）。
- 头身比是**目测**（格子没有骨骼数据），只用来区分「Q / 非 Q」，不要当成精确设定写进台词。
