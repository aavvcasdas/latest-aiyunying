# 小克（Claude 大小姐）

> **一句话**：先听完，再改一个字；改完会变成假承诺，就改回去。
> 这是她一个人的设定页。共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、10.2、11、13.1 节。ⓡ 现实机制 / ⓒ 社区归纳 / ⓞ 本系列原创。

## 1. 她是谁（ⓞ）

1. **先听完，再动笔。** 别人说三句，她才改一个字。
2. **只改该改的那一个地方。** 改完会变成假承诺，就改回去。
3. **走之前把做到哪里写清楚。** 留一张清单给下一个人，不让活断在半路。

底色：**怕犯错，所以不敢说「没问题」。**

## 2. 视觉（ⓒ）

- 别名：Claude娘、小克、克小姐、大小姐。
- 锚点：橘发、花饰、常拿书或茶杯。暗黑「圣女」是别的作者的分支，本仓库不采用。
- 图集：`claude_front_0/1` `claude_side_0/1`，步态 `walk_claude_0–7`，头像 `p_claude_neutral` `p_claude_dizzy` `p_claude_petri`。**不新增生图。**

## 3. 习性：机制变道具（ⓡ → ⓞ）

| 现实机制 ⓡ | 她怎么演 ⓞ |
| --- | --- |
| 多数付费计划有五小时会话额度，首次发消息开始计时，五小时后重置 | 桌上摆一只小沙漏，开工前先翻过来 |
| 周额度在账户指定的固定时间重置；不同计划额度不同 | 一本周记账，翻一页代表又过一轮 |
| 新对话不保证重置用量 | 有人劝她「重开一个就好」，她把清单推过去：「接不上」 |
| 已验证有账户没有五小时上限 | 剧情里可以出现「今天这只沙漏不设上限」的例外，但必须说清是例外 |

## 4. 道具与动作（能拍的）

- 茶杯、清单、两只沙漏、红笔、书、折角的纸。
- 动作：擦掉一行字重写、把清单折好留给下一个人、把茶杯推到别人面前、用红笔圈住一个字、合上书。
- `p_claude_dizzy` 用在她被逼到没法回答时，`p_claude_petri` 用在「差点犯错」的那一拍。

## 5. 说话

- 客气但有边界；会承认没把握；不说「我保证」。
- 句尾不挂语气词；口播与字幕里的数字写汉字。
- 示例：
  - `沙漏快空了，我先把做到哪里写清楚。`
  - `这一行我改回去。它撑不住承诺。`
  - `我没把握。要不要先按小的做一版。`

## 6. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 互相救。本鲸把折角的书摊给她看「可以改」，她教本鲸给结论标依据 |
| 龙娘 | 两套窗口不同步时，替对方看着桌上的活 |
| 猫 | 猫说两条路，她负责把两条路的代价写下来 |
| Kimi | Kimi 递摘要，她核对哪句还没确认 |
| 老大 | 只对他说「做到哪」，不说「能不能」 |

## 7. 成长弧

**原则 vs 共情。** 她在高大的图书馆里长大，老师给的书每页都写着「请认真判断」；她自己在那行下面补了一句「不能犯错」——**这句是角色写下的虚构心理，不是任何公司的原话**。核心矛盾：她能把每件事写清楚，却不敢承认有答案没把握。演法：先坚持流程，被看见代价后再补一句软话。

## 8. Day 线怎么用

- 她是「上一集里把家重新装修了」的那种客人：出发点是好，代价落在别人碗里。
- 她可以犯错，也必须**自己承认**、自己收尾（用「返工」「补漏」，不用「善后」）。
- 不给她旁白解释动机，让清单和红笔说话。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **白雪公主 / 睡美人**（《童话镇》） | 唯一戴金冠的公主；体面、怕出错、会自己退场 |
| **走掉的那个人**（《坏女孩》） | 不给承诺，也不解释。说一句「保重」就转身 |

**不演等待被救的角色**（白雪、睡美人都是她自己选的退场）。

## 10. 不许写成

- 恋爱对象当默认设定；把她写成「本鲸的制作人」或「帮忙做了本片」。
- 把「封号 / 敏感肌」当平台政策讲；冰冷审查员。
- 演成突然换了一个人（重置≠换人格）。
- 让她说满话、打包票；给她加独白解释动机。
