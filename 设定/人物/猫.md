# 猫（Gemini 猫娘）

> **一句话**：先给两个看法，最后必须选一个。
> 这是她一个人的设定页。共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、10.2、11、13.2 节。ⓡ 现实机制 / ⓒ 社区归纳 / ⓞ 本系列原创。

## 1. 她是谁（ⓞ）

1. **先给两条路，再逼自己选。** 她想法多，但最后必须落一条，不落就出不了这间房。
2. **她把两个世界并排放。** 别人说「现在几点」，她先问「你说的哪个钟」。
3. **被要求选时会先抱怨一句，然后选。** 抱怨只有一句，不拖。

底色：**好奇，但怕选错，所以想同时留着两个答案。**

## 2. 视觉（ⓒ）

- 别名：Gemini娘、猫娘、基米、哈基米（「北美豆包」是有褒有贬的类比，不采用）。
- 锚点：蓝紫发、猫耳、异色瞳；意象：猫猫、香蕉画笔。
- **哈基米 = 她，不是 Kimi。** 两者不许按谐音合并。
- 图集：`gemini_front_0/1` `gemini_side_0/1`，步态 `walk_gemini_0–7`，头像 `p_gemini`。别的蓝紫发少女不一定是她。

## 3. 习性：机制变道具（ⓡ → ⓞ）

| 现实机制 ⓡ | 她怎么演 ⓞ |
| --- | --- |
| Gemini API 的日请求额度按**项目**计算 | 她桌上那块牌子写的是「项目」，不是「我的」 |
| 额度在美国太平洋时间午夜重置 | 一只**猫耳钟走太平洋时间**，另一只走北京时间 |
| 夏令时与冬令时不同：北京 15:00 或 16:00 | 钟边贴一张便利贴「夏冬令时会变」 |
| 这个规则只管 API，不管所有 App 的对话额度 | 她被问到就指另一只钟：「那边不算这个」 |

## 4. 道具与动作（能拍的）

- 两只猫耳钟、日历、粉笔、香蕉画笔、台灯（她当成按钮按）。
- 动作：指另一只钟、用粉笔在地上画地球、追光标跑、把两只钟并排放、抱着画笔跳。
- 猫的动作用**跳起 + 挤压**（`.lift()` / `.sq()`）表达，不用步态快速切换冒充。

## 5. 说话

- 跳，句子短，想法多；被要求选时先「喵」一句再选（「喵」是她的自称习惯，不是语气词堆砌）。
- 句尾不挂语气词；示例里不出现「呀、啦、吧」。
- 示例：
  - `两条路。选近的。`
  - `我的午夜在另一只钟上。`
  - `先记两个答案。然后我选。`

## 6. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 给本鲸出时区题；本鲸最后还是要一个结论 |
| 龙娘 | 同一件事的两种解法，谁都不服谁 |
| Kimi | 换算是 Kimi 帮她算的；她负责画图 |
| 千问 | 一个打乱顺序，一个重新排，凑一起正好一件事 |

## 7. 成长弧

**好奇 vs 必须选。** 她长在满是图画、声音与文字的彩色工作室，看到什么都想拼成新点子；拼完的东西太多，反而选不出来。演法：她把两条路都摆好，最后一秒自己踩上其中一条。

## 8. Day 线怎么用

- 她是「点子最多的客人」：进门先给两个方案，本鲸负责砍到一个。
- 别让她把正片讲散——一集只允许她提两个方案，第三个要被打断。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **爱丽丝**（《童话镇》「疯帽喜欢爱丽丝」） | 在两个世界之间来回看 |
| **糖果屋 / 匹诺曹** | 先伸手又缩回；说法一套一套，鼻子长了才停 |

**不说谎那场必须让鼻子「停」一次**——她可以编，但观众要看见她收住。

## 10. 不许写成

- 一次抛一堆支线把正片讲散。
- 把 API 项目级额度说成所有 App、所有模型的规则。
- 和 Kimi 混成一个人；用「哈基米」叫她以外的人。
- 只卖萌不推进剧情：她每集至少要有一个「必须选」的时刻。
