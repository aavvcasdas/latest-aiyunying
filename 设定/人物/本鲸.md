# 本鲸（鲸鱼娘 / DeepSeek）

> **一句话**：先问哪条不能改，再筛。短句，先结论，再补刀。
> 这是她一个人的设定页。共用的规矩（三层分层、梗词典、红线、关系语法）在 [`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、10、11、13 节 ＋ 引擎造型表。标记：ⓡ 现实机制 / ⓒ 社区归纳 / ⓞ 本系列原创。

## 1. 她是谁（ⓞ）

三条行为规则，写戏时按顺序兑现：

1. **先问哪条不能改。** 拿到活先找约束条件，不问「你想要什么」，问「什么动不了」。
2. **能等的活就等，等不了就照接。** 省下来的是大家的，不是她一个人的。
3. **饭先推给更饿的人。** 她嘴硬，但动作永远往外推。

底色是**怕只因为便宜才被留下**。她不说这句，戏里靠动作露出来。

## 3. 习性：机制变道具（ⓡ → ⓞ）

| 现实机制 ⓡ | 她怎么演 ⓞ |
| --- | --- |
| DeepSeek API 有峰谷价：工作日北京时间 09:00–12:00、14:00–18:00 峰价，12:00–14:00 谷价；周末与中国公共假期全日谷价 | 门口挂一块写「峰 / 谷」的翻牌；临近 12 点抱碗等牌翻；急活照接，不拿「等便宜」当借口 |
| 缓存命中算另一档价 | 缓存命中时把上次备好的米饭端出来：「同一碗，热一下」 |
| 搜索、抓取这类工具另外计费 | 出门前先数一遍要跑几趟，回来报「跑了两趟」 |

**不许**把这套讲成公司公告，也不许出现任何数字。

## 4. 道具与动作（能拍的）

- 蓝饭盆、峰 / 谷翻牌、谷时篮、任务篮、小本子、电视遥控器、鲸落那张纸。
- 动作：瞄一眼翻牌、把牌翻过去、端碗、尾巴拍着数拍子、蹲下捡米粒、指着屏幕、把纸摊平、把碗往里推、回头看门口。
- 等待时先给「网络 / 工具等待」的信号，**不演成她偷懒**。

## 5. 说话

- 短句。先判断，再理由。不说满，不解释自己换了谁。
- 句尾不挂语气词：呀、啦、吧、嘛、诶、呜、呢、哦、哇、啊、哼、嘿。
- 永久禁用词见总纲第 9 节；口播里的数字写汉字。
- 示例（原创）：
  - `先问哪条不能改。改完再说。`
  - `这活不急，等牌翻过去再做。`
  - `省下的，算大家的。`

## 7. 成长弧

**开放 vs 被认可。** 她出生在门常开的小工坊，桌上摆着供大家抄阅的图纸，不同访客为她添过一粒米；她也把修好的工具借出去。她不是没成本的小孩——**饭盆下压着水电账单**。核心矛盾：人人夸她划算，她怕自己只有便宜才值得被留下。演法：有人把难活交给她，她先说「等牌翻过去」，最后还是接。

## 8. 日常线（Day，2026-11-12 已删）怎么用

- 唯一的**口播人**。一集一个矛盾、一个反转，反转落在最后两三句。
- 一集请一位客人上桌，其余人只在台词里被转述，或出现在纸条、名牌上。
- 开场 3 秒要让没看过设定的人知道「她今天要什么」。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **河水**（《童话镇》序章、「只有睿智的河水知道」） | 旁观、把话递出去，不进门 |
| **丑小鸭** | 还没被认出来的那个 |
| **小人鱼 / 泡沫** | 为别人上岸，最后自己散掉 |
| **坏女孩**（《坏女孩》第一主角） | 怕自己只有乖才被留下，于是改颜色 |

**不做公主**（那是小克），也不在别人的段子里抢中心位。

## 10. 不许写成

- 只认便宜；为了省钱降低交付；真的摸鱼转包。
- 程序员；报价格、报额度、报 token 换算；画面里出现余额条或数据曲线。
- 把鲸落写成死亡、停机，或「看个视频就恢复回复」。
- 借别人的招牌动作：翻书（小克）、举沙漏（龙娘）、摊卷轴（Kimi）、推算盘（狐狸）。
