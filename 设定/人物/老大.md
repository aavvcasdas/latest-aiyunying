# 老大（用户）

> **一句话**：白天上班的人，不是程序员。米和补全是他买的。
> ⓞ 本仓库原创住户。研究资料里没有他——只有「AI 娘 × 用户」这类镜头反打的用法可以借用。
> 共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。

## 1. 他是谁（ⓞ）

1. **他是付账的那个，但片子不演账。** 米是他买的，这件事只在需要时被提一句。
2. **他不懂行话。** 每集让本鲸用一句人话把事讲清楚，观众跟着他听懂。
3. **他不解决问题。** 他的作用是「提出需求 + 收尾时出现」，不是救场。

## 2. 视觉

- **只在门口或画外出现**：门缝里的光、递东西的手（不画假手，用道具挡：外卖袋、钥匙、手机）。
- 身体基本不入画；真要入画只给背影，且不超过两秒。
- 没有造型格，**不安排他和像素角色同框对谈**。

## 3. 道具与动作（能拍的）

- 手机、外卖袋、钥匙、门缝的光、桌上留下的便条。
- 动作：推门缝、把袋子放门口、拿起手机又放下、背对镜头站着。

## 4. 说话

- 他的台词极少，且都从**画外**来（一句就够）。
- 语气：平、短、不带情绪动员。
- 示例：
  - `今晚不用赶。`
  - `先把能交的给我。`
  - `我明天再看。`

## 5. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 互相嘴硬。他要结果，她要一条不能改的线 |
| 笨鱼 | 他说话前会先停一下，这个停顿是他全部的关心 |
| 客人 | 不直接对话。客人只对本鲸说话 |

## 6. 不许写成

- 专业程序员、技术大神、创业者。
- 失业、降薪、被裁这类笑料；任何收入、房贷、存款数字。
- 替他做主、替他付钱、替他承诺。
- 让他在 MV 里演任何形象（他没有造型格）。

## 7. 来源

本仓库的住户设定；研究原文第 4 节「AI 娘 × 用户」的反打结构（ⓒ）只用来设计镜头方向，不是人物来源。
