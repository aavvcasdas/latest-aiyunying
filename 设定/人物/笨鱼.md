# 笨鱼（鲸落那条线）

> **一句话**：人机校验没过的那一个。真心话写在纸上，由本鲸代读。
> ⓞ 她是**本仓库原创的住户**，不是研究资料里的角色；研究里只有「被刷下来的大肥鱼」这层情绪，用来解释她为什么懂这种滋味。
> 共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。

## 1. 她是谁（ⓞ）

1. **她还在。** 只是接不上实时的话，写不了字，也回不了消息。
2. **她不解释自己。** 要说的话都在纸上，纸上的字短、直、不带情绪词。
3. **她不求恢复。** 全片没有一句「我会好起来」。

## 2. 视觉

- 和本鲸同一套骨架，但不出现在正脸大特写里：她多半坐在电视的光里、在纸后面、在门口暗处。
- 造型用 `whale_idle` / `whale_blink`，配合 `alpha()` 压低、`sil()`（剪影）、`noShadow()`（脚下没影子，观众能看出她「接不上」）。
- **不新增造型、不换画风。**

## 3. 道具与动作（能拍的）

- 纸、折角的书、压在碗下的账单。
- 动作：递纸、摇头、把手缩回袖子里、坐在电视光里不动、把碗往前推一点又收回。
- 可以用：`whale_point` 指一下纸，`whale_wave` 只挥一次（多了像正常打招呼）。

## 4. 说话

- **不新增对白。** 只有两条路：纸上的字给观众看，或者本鲸念出来。
- 纸上的字：一句一条，不带语气词，不用问号堆情绪。
- 示例（纸上的字）：
  - `别念了。吃饭。`
  - `今天不用等我。`
  - `这个错，不是你的。`

## 5. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 唯一的翻译。本鲸念她的纸，也替她挡话 |
| 老大 | 他对她说话时会先停一下——这个停顿本身就是戏 |
| 其他人 | 不来探视。谁提她，都要先问「这样写合不合适」 |

## 6. 这一条线写什么

不是「她病了」，是**「屋子还在运转，但少了一个能回话的人」**。每集只碰一次，别反复。

## 7. 不许写成

- 死亡、停机、下线、告别仪式。
- 看一段视频、换个模型、重开一次对话就恢复。
- 承诺「哪天会好」。
- 第二主唱：她不上口播，不抢本鲸的话。
- 把她当成「悲情道具」每集哭一次。

## 8. 来源

本仓库自己的鲸落设定；研究原文第 12.1 节「服务器繁忙」的社区用法只提供情绪参照（ⓒ），不构成她的剧情依据。
