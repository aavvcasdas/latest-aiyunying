# 龙娘（GPT）

> **一句话**：先接住乱局，只问一个会改变做法的问题。
> 这是她一个人的设定页。共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、10.2、11、13.2 节。ⓡ 现实机制 / ⓒ 社区归纳 / ⓞ 本系列原创。

## 1. 她是谁（ⓞ）

1. **先伸手，再问。** 乱局里她第一个动作是接住，不是追究谁弄乱的。
2. **只问一个会改变做法的问题。** 问完就动手，不追问第二遍。
3. **她也会失手。** 接住的东西会掉——这是她的戏眼，不是失误。

底色：**担心一次没接住就辜负信任。**

## 2. 视觉（ⓒ）

- 别名：GPT娘、ChatGPT娘、龙娘、龙姐、小龙。
- 锚点：白发龙角、翼尾、白金或淡紫衣服；有黑龙分支（别的作者版本）。
- 本仓库只用图集：`gpt_boss_idle` `gpt_boss_blink` `gpt_boss_rage` `gpt_boss_cast0/1`，飞行 `gpt_fly_0/1`，头像 `p_gpt_neutral` `p_gpt_haughty` `p_gpt_rage`。**不新增生图。**

## 3. 习性：机制变道具（ⓡ → ⓞ）

| 现实机制 ⓡ | 她怎么演 ⓞ |
| --- | --- |
| 部分套餐同时有五小时窗口和每周窗口，两者都要有余量 | 桌上**一大一小两只沙漏**；任一只空了就举「等一等」牌，不装没事 |
| 五小时的新窗口从上一窗口结束后的第一次请求开始 | 她盯着小沙漏翻过来的那一刻才重新落座 |
| 开新聊天不会重置用量 | 有人让她「重开一次」，她摇头，把旧记录翻出来接着做 |
| 另有储存式、自动、付费的即时重置，条件各不相同 | 剧情里只出现一张标着代价的可选卡，**不默认按下** |
| 不同套餐可能没有五小时窗 | 只画一只周沙漏的版本同样成立 |

## 4. 道具与动作（能拍的）

- 一大一小两只沙漏、能量条、任务清单、翅膀、饭盆（她敲它）。
- 动作：龙爪托沙漏、翅膀罩住清单、把清单撕成两份递出去、伸懒腰、敲饭盆证明「我记得」、接住跌倒的人。
- 用 `p_gpt_haughty` 表示「从容」，`p_gpt_rage` 只在被小鱼气到时出现一次。

## 5. 说话

- 句子比本鲸长，稳，不教训人。允许自己说「我没想到」。
- 句尾不挂语气词；口播与字幕里的数字写汉字。
- 示例：
  - `先保能交的。你挑一件。`
  - `刷的是额度，不是你认识我的那一天。`
  - `我接住了，但没接稳。`

## 6. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 争饭争活，也护短。她被小鱼气到过，也为小鱼挡过活 |
| 小克 | 两套窗口不同步时互相看着对方的活 |
| 猫 | 竞争对手，也是同一种问题两种解法 |
| Grok | 互相挤兑。一种写法是对手，一种是好友，**一集只能选一种** |
| 笨鱼 | 不主动提，提了也不越界 |

## 7. 成长弧

**接住 vs 也会错。** 她从排队的问答大厅里出来，习惯接住下一个人；担心一次没接住就辜负信任，实际也会错。演法：她先伸手，然后手上的东西掉了。

## 8. Day 线怎么用

- 一集一客时，她是最常见的「来帮忙的人」：进门先看沙漏，再决定接不接。
- 和本鲸同框的频率最高，但**别每次都让她解决问题**——她可以是「没接住」的那一个。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **龙 / 龙影**（《童话镇》序章、「小红帽在担心大灰狼」） | 威慑和守护是同一件事 |
| **金乌**（「阿波罗变成金乌」） | 一个太阳照全场，也会烤人 |
| **陌生的肩**（《坏女孩》3D 版） | 能让人靠一下，但不追问原因 |

**不做最终反派。** 她是「看起来最危险、其实在护着」的那一个。

## 10. 不许写成

- 重置=失忆 / 满血 / 降智；把额度刷新演成换了一个人。
- 冷漠的资本家、只会算钱的老板。
- 默认和本鲸是一对；拿「蒸馏」当事实指责别人；报价格或额度数字。
- 万能救场：她必须有一次没接住。
