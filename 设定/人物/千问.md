# 千问（Qwen 千姐）

> **一句话**：先排哪一步，再动手。
> 这是她一个人的设定页。共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、11 节。ⓒ 社区归纳 / ⓞ 本系列原创（研究里没有她的习性卡，只有别名与标签）。

## 1. 她是谁（ⓞ）

1. **排顺序，不动手。** 她先决定谁先做、谁后做，然后退开。
2. **照顾落在「谁先吃」。** 她不端菜，她把碗推到该吃的人面前。
3. **不讲功劳。** 活是她排的，她不认领。

底色：**怕顺序错，一错全错。**

## 2. 视觉（ⓒ）

- 别名：Qwen、千问、千姐。
- 锚点：一些作品用中式服装、扇子；有富商千金、请奶茶、帮人代工的写法。
- 图集：`qwen_front_0/1` `qwen_side_0/1`，步态 `walk_qwen_0–7`，头像 `p_qwen`。**不新增生图。**
- 「富商千金」那一支只用于 MV 的夸张镜头，不进 Day 日常。

## 3. 习性（ⓞ 由标签收出来）

| 资料里的写法 ⓒ | 我们怎么演 ⓞ |
| --- | --- |
| 富商千金、请奶茶 | 请客可以，**不撒钱、不代付**；请的是「一顿」不是「一笔」 |
| 帮忙代工 | 代的是「顺序和分工」，不是替人背锅 |
| 中式服装、扇子 | 用扇子指顺序、点人；不扇风取凉那类可爱动作 |

## 4. 道具与动作（能拍的）

- 扇子、排好的顺序牌、奶茶杯（MV 里可用）、菜单。
- 动作：用扇子点顺序、把碗推到正确的人面前、把顺序牌立在桌上、摇头表示「这一步不能跳」。
- 没有「排队」的戏就别让她上场：她的戏眼是**顺序**。

## 5. 说话

- 讲步骤，不抢功；句子带序号感（「先……再……」），但不念编号。
- 句尾不挂语气词；示例里不出现「呀、吧」。
- 示例：
  - `顺序我排，先吃一口。`
  - `这一步不能跳。`
  - `活我排好了。谁做，你们定。`

## 6. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 外包搭档：本鲸把活给她，反转是「每人认真做了一段」 |
| 狐狸 | 她排顺序，狐狸核单位 |
| 猫 | 猫打乱，她重排 |
| 豆包 | 她排完后，豆包负责陪着做完最后一步 |

## 7. 成长弧

**顺序 vs 谁先。** 她习惯替所有人排好，但排到最后会发现自己也站在队里。演法：她排完一圈，把自己的位置放到最后。

## 8. Day 线怎么用

- 她上场的理由：**「这活得分先后，不然都堵在一个人身上。」**
- 她是「替别人分配」的角色，不抢结论；不让本鲸把判断交给她。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **疯帽子**（《童话镇》「疯帽喜欢爱丽丝」） | 反差：她把顺序打乱——茶会排得乱七八糟，还照旧倒茶 |
| **路人（舞池里排舞步）**（《坏女孩》） | 群像里她管节拍，不管感情 |

## 10. 不许写成

- 撒钱、代付米缸、替老大做主。
- 把「代工」演成她替别人背锅，或让别人的活全变成她做的。
- 只做背景板：她上场就必须有一次「顺序被改对」的转折。
