# 狐狸（智谱 GLM 狐娘）

> **一句话**：先写完成标准，再做最小的一版。
> 这是她一个人的设定页。共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、10.1、11、13.2 节。ⓡ 现实机制 / ⓒ 社区归纳 / ⓞ 本系列原创。

## 1. 她是谁（ⓞ）

1. **先定标准，再动手。** 她会先问「做到哪算完」，然后只做那三条。
2. **只算对错，不算多少。** 她关心账平不平，不关心账大不大。
3. **困与醒在一句话之间。** 平时戴着眠罩，听到单位不对立刻竖耳朵。

底色：**怕账糊。**

## 2. 视觉（ⓒ）

- 别名：GLM娘、智谱娘、狐娘、嘎啦嘛。
- 锚点：黑发狐耳、黑白服装；部分版本带书或眼罩。某个项目把她写成「摸鱼图书管理员」，那是那一家的演法。
- 图集：`zai_front_0/1` `zai_side_0/1`，步态 `walk_zai_0–7`，头像 `p_zai`。**不新增生图。**

## 3. 习性：机制变道具（ⓡ → ⓞ）

| 现实机制 ⓡ | 她怎么演 ⓞ |
| --- | --- |
| 官方公开了模型与代码仓库，版本各有用法 | 档案室里的标签：每一格都写清哪一版 |
| 国内价格本轮只有第三方记录，没有直读官方价目 | 她手里那本账**只写币种，不写数字**；问价就翻页，翻到空页 |
| 「标准」和「版本」容易混 | 有人把两种单位混着算，她把算盘一推 |

**本仓库不写任何具体价格。** 她的戏只能用「单位不对」「币种不能相加」这类**结构**。

## 4. 道具与动作（能拍的）

- 眠罩、算盘、分栏账本（人民币 / 美元两栏）、价签、档案盒。
- 动作：戴眠罩打盹、听到数字不对立刻竖耳朵、把算盘一推、翻账本对页、把价签翻过去不让人看。
- 眼睛的「睁」用造型切换（`zai_front_0` → `zai_front_1`），不用缩放冒充。

## 5. 说话

- 两档：困（句子短、慢）与醒（快、准、不留情）。切换就在一句里。
- 句尾不挂语气词；示例里不出现「哦、嘛」。
- 示例：
  - `标准三条。只做这三条。`
  - `美元和人民币不能直接相加。`
  - `等一下。这个单位不对。`

## 6. 关系

| 对谁 | 一句话 |
| --- | --- |
| Kimi | 对账搭档：一个记旧话，一个记旧数 |
| 本鲸 | 提醒她「别把 App 的费用当 API 的费用」 |
| 千问 | 一个排顺序，一个核单位，凑一起才不出错 |
| 龙娘 | 不催她交活，只问她「这活怎么算完」 |

## 7. 成长弧

**困倦 vs 一叫就醒。** 她在档案室边打盹边整理标签，听到数据单位不对就醒。演法：前两秒她像睡着了，第三秒她自己把账本合上、报出结论。

## 8. Day 线怎么用

- 她是「来对账的客人」：进门不看饭，先看账本对不对。
- 一集只允许她挑一个错；挑完就走，不做审判官。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **彼得潘**（「彼得潘总长不大」） | 反差：唯一不算账的那一版 |
| **杰克**（「杰克他有竖琴和魔法」） | 用最小成本换最大 |
| **侏儒怪**（「侏儒怪拥有宝石满箱」） | 把名字当账：知道名字就有把柄，被喊出名字时手停住 |

## 10. 不许写成

- 把每场谈话都变成表格；用价格战报数字。
- 为任何厂商编精确的重置时刻或价目。
- 只会睡觉的工具人：她必须在关键一拍醒来。
- 用她的「算」去否定别人的情绪。
