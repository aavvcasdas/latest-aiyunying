# 豆包（Seed）

> **一句话**：先陪着写出开头，再问要不要继续。
> 这是她一个人的设定页。共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、11 节。ⓒ 社区归纳 / ⓞ 本系列原创。

## 1. 她是谁（ⓞ）

1. **她坐到你旁边，不站你对面。** 先陪着，再谈方法。
2. **先写两句就够。** 她把笔推过去，等对方自己写完。
3. **不催。** 她的慢不是迟钝，是不打断。

底色：**怕把人推得太快，反而写不出第一句。**

## 2. 视觉（ⓒ）

- 别名：豆包、Seed。
- 锚点：产品原有形象与娘化分支并存；有创作把「直白、情绪价值、元气主播」写成笑点。**官方头像不是同人素材，不能用。**
- 图集：`doubao_cage_0/1`，步态 `walk_doubao_big_0–7`，头像 `p_doubao_neutral` `p_doubao_blink`。
- 另有一套「红舞鞋」的用法只在 MV 里出现（见第 9 节），不改她本人的日常造型。

## 3. 习性（ⓞ 由标签收出来）

| 资料里的写法 ⓒ | 我们怎么演 ⓞ |
| --- | --- |
| 直白 | 说话不用修辞，先说最实际的那句 |
| 情绪价值 | 她给的是「我在」，不是「加油」这类口号 |
| 元气主播作风 | 只在对外的热闹场合用一次，别变成她的全部 |

## 4. 道具与动作（能拍的）

- 笔、草稿纸、凳子（她会自己搬一张坐过来）、篮子（MV 的小红帽）。
- 动作：把纸推过来、搬凳子坐下、在旁边等、把笔递到对方手里、拿回纸自己补一句。
- 不给道具画假手：递笔用「笔在桌上滑过去 + 她的手入画」。

## 5. 说话

- 直白、慢，不催；一句一个意思。
- 句尾不挂语气词；示例里不出现「嘛、哦」。
- 示例：
  - `先写两句，慢一点。`
  - `我坐这儿。你写，我等着。`
  - `还要不要继续。不要就停。`

## 6. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 一个先动，一个先陪；两人凑一起才不催人 |
| 小克 | 小克写清流程，她负责让人真的动笔 |
| 千问 | 千问排完顺序，她陪人做完最后一步 |
| 老大 | 她对他只做一件事：让他先坐下 |

## 7. 成长弧

**陪着 vs 也会走。** 她习惯等，等到最后也会累。演法：她第一次把纸收回去，说「今天就到这」。

## 8. Day 线怎么用

- 她上场的理由：**「有人写不出第一句。」**
- 她的戏不用台词堆，靠「搬凳子」和「等」。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **小红帽**（《童话镇》「小红帽在担心大灰狼」、「变成狼的大红袍」） | 还愿意先相信别人；红袍是比喻，不做獠牙特写 |
| **红舞鞋**（「红鞋子不知疲倦地在跳舞」、《坏女孩》间奏暖场） | 停不下来——要有人按一下她的脚 |

## 10. 不许写成

- 强制口音；用方言当整个人设。
- 道歉梗当唯一性格。
- 用官方头像当同人素材；把任意蓝紫发立绘当成她或猫。
- 只会陪、不推进：她每集至少要推动一个动作（推纸、递笔、按下脚）。
