# Kimi（月球少女）

> **一句话**：先把漏掉的旧句找回来，标一句就停。
> 这是她一个人的设定页。共用规矩：[`../AI娘设定总纲.md`](../AI娘设定总纲.md)。
> 出处：研究原文第 2、3、10.2、11、12.1、13.2 节。ⓡ 现实机制 / ⓒ 社区归纳 / ⓞ 本系列原创。

## 1. 她是谁（ⓞ）

1. **先翻旧账，再说新话。** 别人忘了的字句，她记得住。
2. **标一句就停。** 她的毛病是一直查——戏里必须有人（或她自己）让她停。
3. **不抢结论。** 她把证据摊开，让本鲸下判断。

底色：**怕重要的细节被忘掉。**

## 2. 视觉（ⓒ）

- 别名：Kimi娘、月球少女。**不是「哈基米」**（那是 Gemini 猫）。
- 锚点：银紫发、月亮与 K 元素、不对称服装；意象：长文档、卷轴、资料管理员。某个同人游戏里是月光歌姬，属该作者设定。
- 图集：`kimi_front_0/1` `kimi_side_0/1`，步态 `walk_kimi_0–7`，头像 `p_kimi`。**不新增生图。**

## 3. 习性：机制变道具（ⓡ → ⓞ）

| 现实机制 ⓡ | 她怎么演 ⓞ |
| --- | --- |
| 官方强调超长文本能力 | 一条长卷轴，能从桌子这头铺到那头 |
| 有上下文缓存，能复用就不必从头算 | **书签**：夹住的位置下次接着看；久了的书签会褪色（缓存过期），褪色就得重新查，不是「失忆」 |
| 有高速档，单价更高 | 两张牌：普通 / 高速。亮高速牌前先问预算，**不替人加急付费** |

## 4. 道具与动作（能拍的）

- 卷轴、书签（新旧两张，旧的那张褪色）、两张牌、放大镜（借用一下别人的也行）。
- 动作：摊开长卷轴、把书签夹进去、把褪色书签举到光下、标一句然后合上卷轴、把牌翻过来又收回去。
- `p_kimi` 一张头像就够，靠卷轴和书签区分状态。

## 5. 说话

- 安静，说重点；句子不长，但每一句都能落到具体那一行。
- 句尾不挂语气词；示例里不出现「呢、啦」。
- 示例：
  - `这份卷了书签，能复用就不用重翻。`
  - `旧评论这条。太熬。别去。`
  - `我只标一句。剩下的你自己看。`

## 6. 关系

| 对谁 | 一句话 |
| --- | --- |
| 本鲸 | 递证据的人。本鲸念出来，她不再补第二遍 |
| 小克 | 递摘要；小克核对哪句还没确认 |
| 猫 | 帮她换算时区与钟点 |
| 狐狸 | 对账搭档。一个管记忆，一个管数字 |
| Grok | 消息太多时，她先要来源 |

## 7. 成长弧

**记得 vs 该放下。** 她在月光书库整理长卷轴，渐渐学会替别人提炼重点；怕漏，所以舍不得停。演法：她把最关键的一句圈出来，然后主动合上卷轴。

## 8. Day 线怎么用

- 她的上场理由永远具体：**「有一条旧评论 / 一句旧话，你们漏了。」**
- 戏里必须有一个「她本来还想再查」的动作，被本鲸或时间拦住。

## 9. MV 线能演什么

| 形象 | 为什么是她 |
| --- | --- |
| **灰姑娘**（「灰姑娘丢了心爱的玻璃鞋」） | 捡起证据、看一眼、放下走开 |
| **智者 / 河水**（「只有睿智的河水知道」，与河道并排） | 替所有人记得 |
| **长生树**（「悬崖有棵长生树」） | 记得最久，站着不动 |

## 10. 不许写成

- 靠堆页码显聪明；把「记得」演成背台词。
- 哭成固定人设；把她写成被动的情报工具。
- 说缓存等于永久记忆、等于人的记忆。
- 为速度擅自替用户加价。
