> 这一份是**能拿来拍**的设定：从 [`参考资料/项目调研/Agent-Reach研究/`](../参考资料/项目调研/Agent-Reach研究/README.md) 的两份研究里挑出来的东西，收成本仓库自己的口径。

> 研究原文取文 HEAD `01a625ad`（2026-11-08），本文件不改原文，只做取舍；原文是别人的资料，不是我们的正史。

## 0. 怎么用这份文件

**一份设定，两条线。**

| 线 | 谁是镜头 | 怎么用这份文件 |
| --- | --- | --- |
| Day（`Day/`） | 本鲸第一人称口播，客人只在台词里被转述，或作为纸条/名牌出现 | 查第 2、3、4 节：这话该谁的口吻说、哪个道具能演、哪些梗不能用 |
| MV（`番外MV/`） | 角色真上场，按选角锁定演童话角色 | 查第 3、5、8 节：她在这版里是什么性格、和谁对戏、动作和镜头怎么落 |

### 三层不许混着说

研究原文第 1 节定的规矩，这里照抄执行。每写一句都该知道自己在哪一层：

| 层 | 标记 | 是什么 | 例子 |
| --- | --- | --- | --- |
| 现实机制 | ⓡ | 厂商官方页面上写着的规则 | 峰谷价时段、五小时窗口、太平洋午夜重置 |
| 社区归纳 | ⓒ | 同人圈、资料库、个别作者对产品的性格化 | 吃白饭=烧 token、重置=失忆、摸鱼 |
| 本系列原创 | ⓞ | 我们自己编的桥段、道具、关系 | 米缸、账本、第一天鱼、鲸落那条线 |

**能演的只有第三层。** 前两层只用来解释「为什么她这么想」，一句都不许当事实说出口。

### 证据等级

| 级 | 是什么 | 能不能写进片子 |
| --- | --- | --- |
| A | 官方文档原文（DeepSeek 价目、OpenAI 额度说明、Claude 用量说明、Gemini 速率限制、各家模型页） | 可以当背景，但**数字不进口播** |
| B | 资料库整理、二手报道、社区总结 | 只用来设计性格，不当事实 |
| C | 只拿到标题/简介的页面（B 站、抖音、贴吧、Reddit 大批） | 只当选题灵感，不当剧情依据 |

C 级的具体名单见 `参考资料/项目调研/Agent-Reach研究/ai-girls-reference-audit.md`：B 站两条动态被验证码挡住、抖音多条只返回登录壳、贴吧两条 HTTP 500、Reddit 403、**所有视频都没完整看过**。所以「某片子里她们怎么演的」这句话，本仓库不写。

### 改设定的规矩

1. 要改谁的性格、换谁的口吻，**先改这份文件**，再改 `分镜.md` / `shots/*.ts`。
2. 镜头代码里不许现编性格：写不出来的反应，说明设定里没写清楚，回来补设定。
3. 这份文件的结论和 Day / MV 任一 README 冲突时，以这里为准，并把那条 README 一起改掉。

## 1. 屋子：一间房，一个米缸

### 空间

同一套可复用的客厅 / 厨房 / 工作桌，一集不超过两个主场景（研究原文第 7 节的合租办公室，我们收成现在这间房）。场景常量写在 `shots/` 里共用，换集只换事件，不换房间。

### 资源

| 东西 | 在片子里是什么 | 什么时候才允许映射 |
| --- | --- | --- |
| 米缸 / 米饭 / 饭碗 | 生活道具，最常用 | 默认就是饭。**只有那一集明说了，才代表 token 和额度** |
| 账本 | 谁欠谁一顿、谁替谁垫了活 | 记「人情账」，不记钱。画面红线不许出现余额条、数据曲线、账本表格 |
| 电视 | 上一集 / 别人的画面 | 只放真实渲出来的画面，不放空面板、不放假画面 |

### 编制

- **固定住户三位**：本鲸、笨鱼、老大（第 2 节）。
- **客人七位**：龙娘、小克、猫、Kimi、狐狸、千问、豆包（第 3 节）。Grok 只出口播，不上画面（没有造型格）。
- **一集一张新脸**：Day 线「一天一客」，其余人只在台词里被转述，或出现在纸条、夹页、名牌上。
- 谁上场要用户点名 + 有获准文件；没有的只许被提到。

### 黑话对照（本系列自己的词，客人一律不用）

| 我们的词 | 指的是 | 用的时候注意 |
| --- | --- | --- |
| 本鲸 | 鲸鱼娘自称 | 只有她自己这么说，别人叫她「鲸鱼」「小鱼」「大肥鱼」 |
| 米缸 / 米饭 / 饭碗 | 额度、算力、饭 | 能只当饭用；当额度用时当集必须点明 |
| token | 同一个东西的书面说法 | 口播里尽量换成米；屏幕上可以出现 |
| 住户 | 住在这间房里的人 | 老大、本鲸、笨鱼是住户，客人不是 |
| 账本 | 人情账 | 不写钱、不写余额 |
| 第一天鱼 | 最早那条、最初的自己 | 怀旧用，不解释成起源设定 |
| 摸鱼 | 偷懒的玩笑 | 只能是她自己嘴硬时的反问，不能演出她真的偷懒 |
| 读评论 | 看别人怎么说 | 本鲸的动作，别人不抢 |
| 收尾 / 返工 / 兜底 / 补漏 / 捞 / 背锅 | 收拾残局 | 一律用这几个词，**不用「善后」** |
| 鲸落 | 人机校验没过、接不上实时话 | 不是死亡，不是停机，看视频不等于恢复回复 |
| 本鲸养鲸鲸 / AI 养 AI | 自己解决自己的问题 | 自嘲用，不说成公司在做的事 |

## 2. 住户（固定三位）

### 本鲸 · 唯一口播 ⓞ（原型 DeepSeek 鲸鱼娘 ⓒ）

| 项 | 内容 |
| --- | --- |
| 一句话 | 先问哪条不能改，再筛。短句，先结论，再补刀 |
| ⓡ 现实锚点 | DeepSeek API 有峰谷价，工作日北京时间 09:00–12:00、14:00–18:00 是峰价，12:00–14:00 是谷价（详见第 6 节） |
| 道具 | 米缸、饭碗、小本子、电视遥控器 |

### 笨鱼 · 鲸落那条线 ⓞ

| 项 | 内容 |
| --- | --- |

| 情绪来源 | 社区里「被刷下来的大肥鱼」只用来解释她为什么懂这种滋味 ⓒ，不是剧情 |
| 道具 | 纸、折角的书、压在碗下的账单 |

| 不许写成 | 死亡；停机；看个视频就恢复回复；恢复校验的承诺；第二主唱 |

| --- | --- |

| 道具 | 手机、外卖袋、钥匙、门缝里的光 |
| 能拍的动作 | 只在门口/画外出现；递东西；背影 |

## 3. 客人（七位）

每张卡三件事：**她先做什么**（顺序决定性格）、**关心落在哪件小事**（别都写成本鲸）、**不能写成什么**。
造型格与头像格见 [`通用模板/README.md`](../通用模板/README.md) 的「八位角色与可用造型」，这里只管人。

### 龙娘 · GPT ⓒ

| 项 | 内容 |
| --- | --- |
| 一句话 | 先接住乱局，只问一个会改变做法的问题 |
| ⓡ 锚点 | 部分套餐同时有五小时窗口和周窗口，两者都要有余量；开新聊天不会重置用量 |
| 道具 | 一大一小两个沙漏、能量条、任务清单 |
| 能拍的动作 | 龙爪托沙漏、翅膀罩住清单、伸懒腰、敲饭盆 |
| 说话 | 稳，句子比本鲸长；不教训人；允许自己错 |
| 关心落在 | 把别人的活分成能交出去的小份，而不是自己硬扛 |
| 不许写成 | 重置=失忆/满血/降智；冷漠的资本家；和鲸鱼默认是一对；报数字；拿「蒸馏」当事实指责别人 |

示例台词：`刷的是额度，不是你认识我的那一天。`

### 小克 · Claude ⓒ

| 项 | 内容 |
| --- | --- |
| 一句话 | 先听完，再改一个字；改完会变成假承诺，就改回去 |
| ⓡ 锚点 | 多数付费计划有五小时会话额度，首次发消息开始计时；周额度在账户固定时间重置 |
| 道具 | 茶杯、清单、两个沙漏、红笔、书 |

| 关心落在 | 把做到哪里写清楚，让下一轮能接上 |
| 不许写成 | 冰冷审查员；恋爱对象；说她制作或帮忙制作了本片；把「封号/敏感」当政策说；拿她和谁组 CP 当默认设定 |

示例台词：`沙漏快空了，我先把做到哪里写清楚。`

| --- | --- |

| 道具 | 笔、草稿纸、小红帽斗篷（MV 选角） |

### Grok · 只在台词里 ⓒ

嘴快、追热点、查证；随身带来源卡。**没有造型格，不安排上场**：只作为口播里的转述、或纸条上的一句。

不许写成：嘴臭当人设；斧头当暴力；默认和龙娘是一对。示例（口播转述用）：`消息劲爆，先看是谁说的。`

## 4. 梗词典：能演、慎演、不演

| 梗 | 怎么演 | 边界 | 本系列 |
| --- | --- | --- | --- |
| 吃白饭的大肥鱼 | 抱饭盆、干饭、蹭饭 | 饭不必每碗都指 token | **用**，但一集只映射一次，且要点明 |
| token 投喂 | 把用量说成吃饭 | 是玩笑，不证明盗用 | **慎用**：屏幕可写，口播换「米」 |
| 摸鱼 / 转包 | 请别人帮忙，最后发现各做了一段 | 不能演成模型故意偷懒 | **用**，收成「谁把活外包了」的误会 |
| 铁盆 / 专武 | 饭碗当盔甲、当要饭道具 | 社区回答，非设定 | MV 可用一次 |
| 服务器繁忙 | 喘不过气、装睡、挡攻击 | 不指代任何真实服务状态 | **用**（鲸落那条线） |
| 稳稳接住你 | 龙娘接住跌倒的人 | 具体作品口头禅，非官方口吻 | 一场一次，不重复 |
| 假扮小克 / 换装 | 穿对方衣服冒充 | 原作品明确是模仿秀 | 可拍，必须让观众看出是假的 |
| Claude 封号 / 敏感肌 | 写成「容易受刺激」 | 用户体感，不是政策 | **不演**，最多一句嘴硬 |
| 月初神仙月底笔仙 | 从充裕到拮据 | 预算解释不等于订阅规则 | 可做一集群像 |
| 败犬 AI / SOTA | 排名写成校园故事 | 娱乐表达，不是榜单 | **不用**：本仓库不报排名 |
| 半场开香槟 | 先庆祝再公布结果 | 样本是娱乐投票 | 可做反转，别暗示真实评测 |
| 蒸馏=争吵/亲密 | 室友互相借鉴 | 虚构指责不证明训练或侵权 | **只做室友误会**，不指向任何真实公司 |
| 中转站背锅 | 身份与路由不一致写成抢活 | 未复现配置 | 可做误会，不报真实路由 |
| 鱼灾 / 赛博鱼塘 | 一片鲸鱼头像在评论 | 报道，非流量统计 | **不用**：会变成运营叙事 |
| 哈基米 / 香蕉画笔 | 猫娘称呼与画图意象 | 哈基米≠Kimi | **用**，只给猫 |
| 爱心与争宠 | 要求抱抱、要小鱼干 | 名次不能当评测 | 一次为限 |
| 轮流帮忙不承认 | 用户以为有神秘第四人 | 原创提案 | 可做 Day 群像 |

## 5. 关系语法

**先定来源，再写关系。** 每条关系在分镜里要么写明「原创」，要么指向具体作品；**同框不等于恋爱、结盟或血缘**。

| 组合 | 资料里出现过的写法 ⓒ | 我们能用的戏剧关系 ⓞ |
| --- | --- | --- |
| 本鲸 × 小克 | 大肥鱼拯救小克；假扮小克；表白短剧 | 活泼闯祸者 × 严肃照顾者；**互相**拯救，不是单向 |
| 本鲸 × 龙娘 | 换装；龙姐照顾小肥鱼 | 争饭争活，也护短 |
| 本鲸 × 千问 | 请千问帮翻译、代工 | 外包搭档，反转落在「每人认真做了一段」 |
| 龙娘 × 猫 | 竞争对手 | 用不同方式理解同一件事 |
| 龙娘 × Grok | 互相挤兑；另一短剧里亲密同框 | 正经 × 毒舌，两种关系都行，选一种写 |
| Kimi × 狐狸 | 师徒（仅某游戏）；中秋同框 | 记性好的月亮 × 爱睡的小狐狸；**师徒只属那款游戏** |
| AI 娘 × 老大 | 饭盆投喂；用户怒了反转 | 从「被安排工作」到「向老大算账」，适合反打镜头 |

三条硬规矩：

1. 一个组合**只选一种关系**演，别一集里又对手又亲密。
2. CP 由本系列自己决定，不默认、不暗示、不靠同框推。
3. 现实话题（蒸馏、风控、价格）只能当**虚构误会**的道具，剧中人要有一句把它拉回「这是我们瞎猜」。

## 6. 时间、额度、账本：机制怎么变成道具

表里左边是ⓡ现实，右边是ⓞ道具。**数字不进画面、不进字幕、不进台词**；口播里的数字一律写汉字。

| 机制 ⓡ | 道具 / 演法 ⓞ | 不许说 |
| --- | --- | --- |
| DeepSeek API 峰谷价：工作日北京时间 09:00–12:00、14:00–18:00 峰价，12:00–14:00 谷价，周末与公共假期全日谷价 | 一块写着「峰 / 谷」的翻牌；中午 12 点她端着碗等翻牌 | 说 App 收费一样；把峰时说成「更慢」；把调休当谷时 |
| OpenAI 部分套餐五小时 + 每周双窗口，两者都要有余量；新开聊天不重置用量 | 一大一小两只沙漏；任一空了举「等一等」牌 | 说重开对话就满血；说重置会清人格 |
| Claude 多数付费计划五小时会话额度（首次发消息起算），周额度按账户固定时刻重置 | 小克桌上的小沙漏 + 一本周记账 | 说新对话能重置；演成「突然换了一个人」 |
| Gemini API 日额度按项目算，太平洋午夜重置 = 北京时间 15:00 / 16:00（夏冬令时不同） | 两只猫耳钟，便利贴上写「夏冬令时会变」 | 说所有 App 都在那一刻重置；把项目额度说成个人额度 |
| Kimi 有上下文缓存与高速档，高速档更贵 | 褪色书签（缓存过期）+ 两张牌 | 说缓存是永久记忆；替用户加急付费 |
| 智谱有公开仓库与版本；国内价格本轮无官方直读 | 分栏账本、价签 | 报任何具体价格；编重置时刻 |

**共同禁忌**：高峰价 ≠ 慢；重置 ≠ 失忆；等待工具 ≠ 摸鱼；额度 ≠ 人格。这四句是本系列的默认底色，写戏时不用解释，但一句都不许反着演。

## 7. 出生与成长：三条能反复用的弧线

不是家庭正史，是三条冲突。一集挑一条，别混。

**弧线一：开放 vs 被认可（本鲸）**
她出生在门常开的小工坊，桌上摆着供大家抄阅的图纸，不同访客为她添过一粒米；她也把自己修好的工具借出去。她不是没成本的小孩——**饭盆下压着水电账单**。核心矛盾：人人夸她划算，她怕自己只有「便宜」才值得留下。演法：有人把难活交给她，她先说「这活等饭价牌翻过去再做」，最后还是接。

**弧线二：原则 vs 共情（小克）**
她在高大图书馆里长大，老师给的书每页都写着「请认真判断」；她自己在那行下面补了一句「不能犯错」——**这句是角色写下的虚构心理，不是任何公司的原话**。核心矛盾：她能把每件事写清楚，却不敢承认有答案没把握。演法：先坚持流程，被看见代价后再补一句软话。

**弧线三：接住 vs 也会错（龙娘）**
她从排队的问答大厅里出来，习惯接住下一个人；担心一次没接住就辜负信任，实际也会错。演法：她先伸手，然后手上的东西掉了。

群像共用的三条表演规则（研究原文第 11 节，照用）：

1. 把规则演成道具，不把道具当事实。饭价牌、双沙漏、猫耳钟能同框，结尾不解释成产品公告。
2. 每个角色要有一次反差：本鲸也会认真，龙娘也会缺额度，小克也会犯错，狐狸睡醒能解决问题。
3. 生活作息是虚构编排：她们不吃饭、不睡觉；高峰价不是慢，重置不是失忆。

## 8. 画面与动作（MV 线专用）

### 运动分三层，别用整体缩放冒充动作

| 层 | 做什么 | 素材 |
| --- | --- | --- |
| 全身 | 平移、倾身、遮罩 | 图集立绘（`k.actor` 的造型格） |
| 局部 | 眨眼、嘴、发梢、衣摆、鲸尾、龙翼 | 分格驱动，按帧号确定性求值 |
| 关键姿势 | 转身、奔跑、近距离手势 | 补画的关键帧序列，**不用缩放假装** |

本仓库不新增生图：动作只能在图集已有的格里做（可用造型见 [`通用模板/README.md`](../通用模板/README.md)），要更多动作先往 `通用模板/cast/source/` 加像素数据再重建。

### 镜头语言

- 前景飘落书页 / 中景人物 / 背景深海或图书馆，做 2.5D 视差。
- 用闭眼特写、手与饭碗的动作连接、逆光轮廓、对拍反打。
- 字幕像手写歌词嵌进构图，**不许大字遮住脸**；中文换行手工校。
- 别每镜都站桩弹跳，也别整片靠频谱条。

### 节拍

先定音源与字词时间，再标鼓点、段落和情绪转折；每个镜头按音乐实际波形调整（本仓库的 `cues.json` 由 `align` 实测生成，不手改数字）。

### 技术边界

- Remotion 里用 `useCurrentFrame` / `interpolate` / `spring` 驱动确定性动画，随机数固定种子。
- 实时循环、物理模拟不能按指定帧重现的，先导出确定性序列再合成。
- 渲染前跑角色预检：角色坐标算成 `NaN` 时 three.js 不报错、直接不画，成片里人就没了。

### 30 秒 PV 骨架（研究原文第 15.3 节的样片，收成可复用的骨架）

| 段 | 秒 | 做什么 |
| --- | --- | --- |
| 起 | 0–4 | 一个人的房间里重复一件做不到的事，字迹划掉一次就够，不堆压迫文字 |
| 开 | 4–8 | 切到另一个人的空间，共享的物件被打开，几只手递来同一样小东西 |
| 隔 | 8–13 | 玻璃/门框两侧对视，两次反打，从紧绷到好奇 |
| 交 | 13–18 | 把写错的草稿递过去，对方愣住，再在旁边写下修改 |
| 抬 | 18–25 | 两人一起改，发丝、书页、尾巴随风轻动，情绪抬升 |
| 落 | 25–30 | 镜头拉远，末帧才出标题；留安全边距给平台 UI |

**最小验收**：先做 4 秒单镜头，查脸一致、遮挡、发梢、字幕和 30fps 重复渲染；再扩到 30 秒。这只是骨架，不是已拍过的分镜。

## 9. 红线（写之前先过一遍）

### 永久禁用词

`擦屁股` `屁股` `屎` `拉屎` `尿` `粪便` `排泄` `屁`。
「善后」改写成：收尾、返工、兜底、补漏、捞、背锅。

### 句尾不许挂语气词

呀、啦、吧、嘛、诶、呜、呢、哦、哇、啊、哼、嘿。**这条对纸条上的字同样有效**。

### 其余八条

1. **不直说 3D**：画面是像素纸片人也只说「画面」，不解释技术。
2. **不报数字**：价格、额度、token 换算、粉丝数、播放量都不进口播；口播里的数字写成汉字。
3. **不出现运营数字**：数据曲线、余额条、账本表格、进度条一律不画。
4. **不伪造接触**：不给道具画假手，饭盆不会自己浮起来。
5. **不把社区玩笑写成机制**：重置不是失忆，摸鱼不是偷懒，白饭不必是 token。
6. **不编厂商日程**：拿不到官方原文的（Kimi、Grok、智谱的重置周期）就不写具体时刻。
7. **不照搬上游美术与台词**：参照动作，不复制立绘、音乐、声音、代码；素材授权各自核对。
8. **不承诺**：不说能找到工作、能恢复校验、米是别人买的、下一集一定怎样。
