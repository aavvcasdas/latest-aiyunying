# 备选池

> 想说但这一轮没做的事，全放这里，一条一行，写清楚「是什么 / 为什么先不做 / 真要做第一步动哪里」。
> 立这份的原因是：讨论里冒出来的想法，如果只留在对话里，下一轮就没了。
> 最后更新 2026-11-12（撤掉 Grok 那套派生造型）。

## 使用规矩

1. **进池不等于要做。** 池子只保证「不会被忘掉」，不保证「会被做」。
2. **一条一件事。** 不要把「七个角色各补六个动作」写成一行的七个动作。
3. **动手时先从池里划掉**，再开新的待办；做完了也回来说一句做完了。
4. 池里的东西**不许当成已经有的能力**写进分镜。镜头只认 [`动作库.md`](动作库.md) 第二节那张表。
