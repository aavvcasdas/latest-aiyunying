## 备选池

想说但这一轮没做的事，都收在 [`备选池.md`](备选池.md)：造型格、动作与道具、人物与设定三类，一条一件事，写清楚「为什么先不做 / 真要做第一步动哪里」。**进池不等于要做**，也不许把池里的东西当成已经有的能力写进分镜。

## 三条使用规矩

1. **人物页是唯一出处。** 短表只做取舍和速查；两边冲突时以人物页为准，并把短表改掉。
2. **镜头代码里不现编性格。** 写不出来的反应，说明设定没写清，回到那一页补，再改 `分镜.md` / `shots/`。
3. **三层不许混着说。** 现实机制（官方页面上的规则）、社区归纳（同人怎么开玩笑）、本系列原创（我们自己编的桥段）分开；能演的只有第三层，前两层只解释动机，不当事实说出口。
