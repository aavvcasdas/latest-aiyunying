# 设定（AI 娘世界观）

这个目录放**能拿来拍的东西**：谁在这间房里、她先做什么、关心落在哪件小事、哪些话不许说。
素材与出处不在这里，在 [`参考资料/项目调研/Agent-Reach研究/`](../参考资料/项目调研/Agent-Reach研究/README.md)；研究方向在 `00_运营总览/`。

## 文件

| 文件 | 是什么 | 谁读 |
| --- | --- | --- |
| [`AI娘设定总纲.md`](AI娘设定总纲.md) | 总纲：三层分层、住户与客人的完整设定卡、梗词典、关系语法、机制怎么变道具、三条成长弧、MV 动作与镜头、红线、证据边界 | 两条线都读。**改设定先改这里** |
| [`../Day/设定表.md`](../Day/设定表.md) | Day 线用的短表：一集一客、纸条口吻、能不能露脸、不许写成 | 写 Day 台词和分镜时看 |
| [`../番外MV/设定表.md`](../番外MV/设定表.md) | MV 线用的短表：八位角色 × 选角锁定 × 一句话性格 × 动作层 | 写 MV 分镜时看 |

## 三条使用规矩

1. **总纲是唯一出处。** 短表只做取舍和速查，两边冲突时以总纲为准，并把短表改掉。
2. **镜头代码里不现编性格。** 写不出来的反应，说明设定没写清，回到总纲补，再改 `分镜.md` / `shots/`。
3. **三层不许混着说。** 现实机制（官方页面上的规则）、社区归纳（同人怎么开玩笑）、本系列原创（我们自己编的桥段）分开；能演的只有第三层，前两层只解释动机，不当事实说出口。
