# 通用角色与模板：半成品修改说明

- 日期：2026-11-26
- 分支：`arena/786ec221-latest-aiyunying`
- **状态：半成品 / WIP。只是阶段性修改，不是完成版，不是视觉验收通过版。**
- 本次提交保存当前会话的累计代码、必要图片资产、实验记录与文档；不代表此前被用户否定的表现已全部修好。

## 一、这次修改了什么

### 1. 把主要工作从独立样片移到通用模板

新增 `通用模板/engine/rigid-character.ts`，在 `tachie.ts`、`tachie-assets.ts` 与角色锚点注册表中接入刚性角色路径。追加角色 key 为 `whale_cutout`，没有覆盖原像素图集，也没有替换旧八位立绘。

带 `rig` 的角色必须注册对应骨架与纹理；缺绑定时直接报错，不再悄悄回退到原来的单图横带形变。模板的预载会等待全部骨段与眼睛素材。

### 2. 增加固定骨长的分段骨架

- 手臂拆为上臂、前臂、手掌，分别对应肩、肘、腕与掌端。
- 腿拆为大腿、小腿、鞋，分别对应髋、膝、踝与鞋尖。
- 每根骨段只平移、旋转，不使用横带、沿骨段混合蒙皮或拉伸来补关节。
- 支持肘角为零的直臂检查、手动指定肩肘角、按时间定格，以及读取关节坐标。
- 重定了本鲸的膝、踝位置，并调整分段切图和关节盖片；这仍属于待打磨的绑定美术。

实现与资产位于：

- `通用模板/engine/rigid-character.ts`
- `通用模板/engine/assets/rigid/whale/bind.json`
- `通用模板/engine/assets/rigid/whale/`
- `人物/立绘/tools/prepare-rigid-whale.py`

### 3. 加入走路的基础求解

增加支撑期 / 摆动期、固定骨长两段 IK、摆动脚抬起、双膝同向屈曲与双臂反相摆动。IK 不可达会报错，不伸长骨头兜底。

角色接口提供 `travelX()`。把该距离加到角色世界位置后，支撑期脚踝保持世界位置固定；不加则只是原地跑步机式调试，不能宣称完全没有滑步。

**目前只是基于正面原画的二维步态，不是自然侧面走路的精确复刻，也不是三维重建。**

### 4. 面部表情接入模板每帧更新

增加平静、喜、怒、哀、乐、惊讶六种表情，独立控制眼睛、眼睑、眉形、嘴形与泪光；支持表情强度、自动眨眼与嘴形测试。

绘制在模板当前帧执行，`commit` 时会更新，因此不是仅修改标签或依靠另一个样片播放器。每帧复位表情、关节覆盖、定格和调试状态；正序预检也补上了与逆序 / 实际渲染一致的立绘复位。

**当前丰富表情使用同步图层 / 路径绘制，不应描述为 Iki 模型已完成全部喜怒哀乐绑定。**此前 Iki 实验仍作为历史研究保留。

### 5. 新增模板骨架定格台

运行：

```bash
npm run rig:preview
```

默认 5173 端口，首页进入 `/rig.html`。它直接使用模板的 `Tachie`，不是另一套动画实现。

可检查：

- 播放、暂停、按 30fps 逐帧和拖动时间定格；
- 绑定直臂、走路、招手与站立；
- 手动锁肩肘，确认肘角为零时骨段共线；
- 显示关节骨架及支撑脚标记；
- 自动或手动切换喜怒哀乐与表情强度。

旧 8000 端口独立实验服务已停止。新入口的接口说明见 [角色骨架文档](../通用模板/角色骨架.md)。

### 6. 更新生图与资产版本规则

按用户要求解除“禁止新增生图”和不可更新哈希规则，更新 AGENTS、README、模板说明与 skill。

`assets.manifest.json` 现在作为可更新版本记录：默认检查提醒有意的版本变化，`--strict` 用于审计记录版本，`npm run assets:write` 刷新记录。新增注册角色及骨段资产也会被发现。

仍保留缺文件、实时母版 / 镜像不一致、字体缺字、音频实测对齐等检查。解除美术限制不等于获得第三方素材的发布或商业许可。

### 7. 保存来源和实验历史

保留完整原始提示词，另存修订提示词；追加无肢体身体补画以重建四肢背后的头发与鲸尾。图片工具没有提供的模型、版本和 seed 如实记为 unknown。

`paperdoll/` 包含此前独立 Cutout / Iki 实验、来源图、静帧和代码，**其中机器检查通过的历史结果不等于用户已认可视觉效果**。后续工作应以通用模板路径为主，不继续把这些旧实验当完成品。

## 二、明确没有完成的部分

- **没有完成正常走路观感的人工验收。**肩、肘、膝、鞋口的轮廓与遮挡仍需继续修，不能仅凭骨长测试通过就说“手脚已经自然”。
- 角色袖子原有的圆润造型、关节盖片和正面原画的透视局限仍然存在；固定骨长不等于美术与动作质量已完成。
- **没有给原有八位单层立绘全部重绑。**通用协议已加入，当前只有本鲸新 key 提供了这套实际资产与绑定。
- 没有完成完整 Iki 表情模型、真实音频口型、手指动作、三维转身、头发物理或接物碰撞。
- 刚性角色未实现的旧动作 / blend 会报错，不伪装为全部动作已适配。
- 没有正式 MV、发布许可或商业授权结论。
- **用户要求停止出样片后，本轮没有导出新视频。**历史 MP4 按忽略规则不随本次提交入库，临时帧不入库。

## 四、建议的下一步

1. 在骨架定格台逐帧确认本鲸的肩、肘、腕、膝和脚底，先修分层边缘与遮挡，再讨论动作自然度。
2. 根据目标视角补齐直臂、侧面 / 四分之三行走等必要美术，不强行用一张正面图承担全部运动。
3. 确认一位角色的绑定和表情达到人工标准后，再逐个迁移其他角色。
4. 根据需要扩展真正的 Iki 表情绑定及音频口型，不能只复用参数名称就宣称接入完成。
5. 获得明确的人工认可和后续出片要求后，再考虑完整视频输出。
