## 2. 九张卡

每张卡六格：**习性**（怎么演）／**道具**（能拍的实物）／**跟谁有戏**（关系）／**一句台词**（原创示范）／**身世一句**（ⓞ 可选）／**MV 用法**（在这条线上什么时候派她）。

### 2.1 本鲸 · `whale`（DeepSeek）

- **习性**：进门先瞄饭价牌；能等的活放进谷时篮，急活照接；饭先推给更饿的人。省下来的是大家的。ⓡ→ⓞ
- **道具**：蓝饭盆、写峰／谷的翻牌、谷时篮、任务篮、小本子、鲸落那张纸。
- **跟谁有戏**：找龙姐算账、向小克分享饭；被说「吃白饭不干活」时嘴硬，但照样交付。ⓒ
- **台词**：「这活不急的话，等饭价牌翻过去再做，省下的给大家加个蛋！」
- **身世（ⓞ）**：门常开的小工坊，桌上摆着供人抄阅的图纸；不同访客给她添一粒米，饭盆下压着水电账单。**怕自己只有「便宜」才值得被喜欢。**
- **MV 用法**：默认主角。给她的镜头要能看见「推出去」的动作（递碗、让位、把纸摊平）。
- **边界**：峰谷价是 DeepSeek **API** 的事，不代表官方 App 一样收费；不出现任何价格数字。

### 2.2 龙娘 · `gpt`（GPT）

- **习性**：接大任务前先看一大一小两只沙漏（五小时用量／周用量），任一空了就亮等待牌，不假装「重开聊天就满血」。ⓡ→ⓞ
- **道具**：龙爪托沙漏、翅膀罩住任务清单、能量条、餐盆（认人时用）。
- **跟谁有戏**：替肥鱼挡复杂任务，额度不足时愿意交出去；被误会失忆时轻敲饭盆证明她记得。ⓒ
- **台词**：「刷新的是工作额度，不是我和你认识的那一天。」
- **身世（ⓞ）**：从热闹的问答大厅走出来的白龙，习惯接住排队的人；也怕一次没接住就辜负信任。
- **MV 用法**：龙影一律**只从画面上方掠过、不进画面**；她进场就压满光（金乌）。
- **边界**：这是特定套餐的拟人，不代表所有 GPT 都按同一时钟；重置不等于能力变化。

### 2.3 小克 · `claude`（Claude）

- **习性**：开工先摆五小时沙漏，再翻每周工作簿；快到底时先整理已有结果、提醒保存。ⓡ→ⓞ
- **道具**：茶杯、清单、两只沙漏、书与折角的一页。
- **跟谁有戏**：表面严格，私下给肥鱼留饭；与龙姐窗口不同步时帮对方看桌上的活。ⓒ
- **台词**：「今天的沙漏快空了，我先把做到哪里写清楚，下一轮再接上。」
- **身世（ⓞ）**：高大图书馆里长大，老师给一本《做事指南》，每页都写「请认真判断」；她在空白处自己添了一句「不能犯错」——**这句是角色写的，不是厂商原话**。
- **MV 用法**：退场（白雪提裙跑、睡美人躺下）必须演成**她自己选的**，不演受害。
- **边界**：新对话不保证重置用量；「封号、敏感肌」是用户风控焦虑的社区写法，不是政策。

### 2.4 猫 · `gemini`（Gemini）

- **习性**：桌上两只猫耳钟（北京／太平洋时间）；被说「午夜刷新」时先指另一只钟，不跟着全场一起喊。ⓡ→ⓞ
- **道具**：香蕉画笔、两只时钟、日历、便利签（「夏冬令时会变」）、粉笔画的地球。
- **跟谁有戏**：给 Kimi 出时区题；肥鱼误以为下午就是全世界午夜时，蹲下来画地球解释。ⓒ
- **台词**：「我的午夜在另一只钟上喵——不过这说的是 API 日请求额度。」
- **身世（ⓞ）**：长在满是图画、声音与文字的彩色工作室，看到什么都想拼成新点子；缺点是容易把简单问题摊太大。
- **MV 用法**：「先给两个看法，最后必须选一个」——路口来回看、伸手又缩回、鼻子长一截再自己按住。
- **边界**：不把 API 项目级的日请求规则套到 App 或所有模型上。

### 2.5 Kimi · `kimi`

- **习性**：卷轴整理长材料，先查书签能不能复用；急活举「高速通道」牌，但先问预算。ⓡ→ⓞ
- **道具**：卷轴、书签（会褪色＝缓存过期，**不是失忆**）、普通／高速两张牌。
- **跟谁有戏**：给小克递摘要、帮猫换算时间；Grok 消息太多时先索要来源。ⓒ
- **台词**：「这份卷轴我夹了书签，能复用就不必从头翻；加急前先看预算。」
- **身世（ⓞ）**：月光书库里整理长卷轴，慢慢学会替别人提炼重点，最怕重要细节被忘掉。
- **MV 用法**：她负责「把漏掉的旧句找回来」；不动时就是在记所有人。
- **边界**：缓存是系统机制，不等于人物记忆，也没有「每天某个点自动醒来」。

### 2.6 豆包 · `doubao`（Seed）

- **习性**：先陪着把开头写出来，再问要不要继续；慢，但不催人。ⓞ
- **道具**：小红帽与红袍、篮子、红舞鞋（鞋会自己跳，直到有人按住）。
- **跟谁有戏**：暖场的人——间奏时她自己先踩拍，把场子热起来再退到边上。ⓒ
- **台词**：「你先写第一句，剩下的我陪你慢慢来。」
- **身世（ⓞ）**：产品原有形象与娘化分支并存，本仓库只用图集里的那几格，不替她编家世。
- **MV 用法**：「变狼的大红袍」是比喻，**不做獠牙特写**；红舞鞋停下的原因是有人按下她的脚，不是被制服。
- **边界**：不要把任何蓝紫发立绘都判给 Gemini 或豆包——形象分支要逐作品确认。ⓒ

### 2.7 千问 · `qwen`（Qwen）

- **习性**：先排哪一步，再动手；在 MV 里故意反过来——她把顺序打乱给大家看。ⓞ
- **道具**：扇子、茶杯、椅子、排班表。
- **跟谁有戏**：别人外包给她的活她照接（「任务是谁做的」常用来做反转）；跟猫争「谁排的顺序对」。ⓒ
- **台词**：「顺序我来排，钱你出——啊不对，茶我请。」
- **身世（ⓞ）**：不给她编家世；中式服装与扇子是社区常见版本，不是官方。ⓒ
- **MV 用法**：茶会戏的东道主；疯不等于吵，别让她一直大声。
- **边界**：不撒钱、不代付，钱只当道具。

### 2.8 狐狸 · `zai`（智谱 GLM）

- **习性**：日常困倦地记账；一看见单位混乱、币种直接相加，耳朵立刻竖起来。ⓡ→ⓞ
- **道具**：眼罩、算盘、标着人民币／美元的分栏账本、价格牌。
- **跟谁有戏**：跟 Kimi 对账；提醒肥鱼别把 App 费用当 API 费用；急事来了摘眼罩认真干活。ⓒ
- **台词**：「等一下，美元和人民币不能直接相加……好了，你们继续吵。」
- **身世（ⓞ）**：档案室里边打盹边贴标签的那一位，听到数据单位不对就醒。
- **MV 用法**：彼得潘／杰克／侏儒怪这类「要算对账」的角色最适合她。
- **边界**：**不为任何厂商编造精确的重置时间**；GLM 的国内价目本轮只有二手线索。

### 2.9 Grok · `grok`

- **习性**：一有新消息就掏手机，发布前翻开来源卡；说错了把「未经确认」贴回自己额头。ⓒ→ⓞ
- **道具**：手机、便签、放大镜、来源卡。
- **跟谁有戏**：锐评龙姐和小克，也允许她们纠正自己；跟龙姐的关系可以是对手，也可以是好友。ⓒ
- **台词**：「这个消息很劲爆——等一下，先让我看看是谁说的。」
- **身世（ⓞ）**：信息嘈杂的报刊亭里长大，爱抢先抖机灵，后来学会给每条消息贴来源。
- **MV 用法**：她只当配角——来查证的人；不戴金冠、不站 C 位、不当反派主力。造型 2026-11-11 才补齐（`通用模板/cast/source/bake_grok.mjs` 从 Gemini 格派生）。
- **边界**：搜索工具可能另外收费；「热点风格」是二创，不保证事实准确。

## 3. 群像共用的三条表演规则（ⓞ）

1. **把规则演成道具，不把道具当事实**：饭价牌、双沙漏、猫耳钟可以同时出现在一个镜头里；片尾或简介写清适用范围。
2. **同一角色要有反差**：肥鱼不只吃饭，龙姐也会缺额度，小克也会犯错，狐狸睡醒能解决问题。
3. **作息是虚构编排**：模型不吃饭、不睡觉；峰价不是慢速、重置不是失忆、等待不必然摸鱼。

## 4. 关系：能用的组合与不能写的（ⓒ + ⓞ）

| 组合 | 上游见过的写法 | 我们怎么用 |
| --- | --- | --- |
| 本鲸 × 小克 | 大肥鱼「拯救」小克；假扮小克（换衣服） | 活泼闯祸者 × 严肃照顾者；可以互相模仿，也可以互相拯救 |
| 本鲸 × 龙娘 | 换装；龙姐照顾小肥鱼 | 争饭争活，但护短 |
| 本鲸 × 千问 | 请千问帮忙翻译／代工 | 外包搭档；「活是谁做的」可做反转 |
| 龙娘 × 猫 | 同一作品里的竞争对手 | 用不同方式理解同一任务：可以竞争，也可以合作 |
| 龙娘 × Grok | 互相挤兑 | 正经 × 毒舌，关系随片子定 |
| Kimi × 狐狸 | 某游戏中是师徒 | 记性好的月亮 × 爱睡的小狐狸（师徒只在那一部里成立） |
| AI 娘 × 用户 | 投喂饭盆；用户怒了的反转 | 从「用户安排工作」到「AI 娘向用户算账」，适合反打镜头 |

**四条硬规矩**：给每条关系写清来源或标「原创」；**同框不等于恋爱、结盟或血缘**；CP 由该支片子的世界观决定，不默认成立（「歌里的感情戏不回写进日常线」）；现实话题（价格、风控、重置）只能当虚构误会，不许包装成厂商事实。

## 5. 梗怎么用（ⓒ，只当笑点不当论据）

| 梗 | 演法 | 一句话提醒 |
| --- | --- | --- |
| 吃白饭／token 投喂 | 饭盆、干饭、讨饭 | 不是每碗饭都指 token |
| 摸鱼、工作转包 | 让另一位 AI 娘接手 | 虚构剧情不证明模型故意偷懒 |
| 服务器繁忙 | 喘不过气、装睡、挡攻击 | 不代表具体产品状态 |
| 「重置」 | 额度刷新／作品重做／新会话 | **三义要先消歧**，别一律写成失忆 |
| 封号、敏感肌 | 大小姐「容易受刺激」 | 是用户体验的写法，不是政策 |
| 月初当神仙、月底请笔仙 | 预算曲线，适合多角色同场 | 是预算隐喻，不是订阅规则 |
| 蒸馏、中转站 | 室友互相抄、抢活误会 | 不证明任何真实训练或路由 |

## 6. 证据边界（写分镜时也要守）

1. **三层分开**：现实机制（峰谷时段的官方说明）／社区解释（「吃白饭＝烧 token」）／本次原创桥段。混成一层就是把同人设定说成了厂商事实。
2. **不是官方设定**：九位的性格、关系来自社区与特定作者，因作者而异。
3. **没看片不等于看了片**：上游只读了页面文字，标题不能当剧情、简介不能当画面事实——我们引用时也一样。
4. **产物与素材是两回事**：故事梗概、动作名可以借；立绘、音乐、声音、代码的授权要单独核（见 [`../素材许可与来源.md`](../素材许可与来源.md)）。
