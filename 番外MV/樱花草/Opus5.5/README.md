# 《樱花草》Opus5.5

来源：分支归档 `樱花草opus5.5.zip`。

- 成片：`成片/樱花草_Opus5.5_1280x720.mp4`
- 规格：1280×720（工程原生画布）、30 fps、H.264/AAC、4:37.5。
- 音源：复用仓库根目录《樱花草》.mp3，时间轴从 0 秒起；压缩包缺少角色图集、字体及音乐二进制，因此工程内补入项目已有 `人物/atlas.png`、站酷快乐体 WOFF2 和原曲。
- 增加 `window.__mvReady` / `window.__mvSeek(t)` 离线渲染钩子，不启动音频播放；没有新增或改动人物主图集。
- 校验：`npx tsc --noEmit`、`npm run build` 通过；全片解码无错误，抽查了前奏、主副歌、间奏和终段画面。
