# 《樱花草》Gemini4

来源：分支归档 `樱花草gemini4.zip`。

- 成片：`成片/樱花草_Gemini4_1280x720.mp4`
- 规格：1280×720（工程原生画布）、H.264/AAC、4:37.55，封装为 30 fps。
- 软 3D WebGL 画面以 15 fps 的离线时间点逐帧渲染，成片按 30 fps 输出（相邻帧复用）；时间戳按工程原轴，音轨从 0 秒对齐。
- 压缩包没有包含歌曲、角色 PNG 图集和字体：音源复用仓库《樱花草》.mp3，图集复用现有 `人物/atlas.png`，字体复用已有站酷快乐体 WOFF2；没有新生成人物或修改主图集。
- 为稳定离线导出增加了 `window.__mvSeek(t)`，只驱动画面，不启动声音播放。
- 校验：`npx tsc --noEmit`、`npm run build` 通过；成片完整解码，并抽查多段画面。
