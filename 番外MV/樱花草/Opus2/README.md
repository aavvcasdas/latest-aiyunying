# 《樱花草》Opus2

来源：分支归档 `樱花草opus2.zip`。

- 成片：`成片/樱花草_Opus2_1280x720.mp4`
- 规格：1280×720（工程原生画布）、30 fps、H.264/AAC、4:37.5。
- 音源：复用仓库根目录《樱花草》.mp3；压缩包没有携带歌曲、角色 PNG 图集或字体，因此按工程引用补入 `源码/src/assets/`：歌曲为本仓库原曲、图集复用现有 `人物/atlas.png`、字体复用已有站酷快乐体并保留 OFL 许可。
- 没有生成或修改人物主图集。工程内增加 `window.__mvReady` / `window.__mvSeek(t)` 截帧接口，方便无音频播放地按时间轴渲染。
- 校验：`npx tsc --noEmit`、`npm run build` 通过；成片完整解码检查，并抽查开头、主歌、间奏、尾段画面。音轨与工程时间轴同起点。
