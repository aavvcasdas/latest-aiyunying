# 《告白气球》番外 MV（周二珂版 · 塞纳河左岸）

> 母题：一场不怕搞砸的告白。送不起最贵的，就用蓝饭盆捧一片落叶；写错的名字，她只改了一个字。

| 项 | 值 |
| --- | --- |
| 音源 | 仓库根目录 `告白气球-周二珂.mp3`（212.98 秒；`源码/src/assets/bgm.mp3` 是它的原样拷贝） |
| 规格 | 16:9，浏览器实时渲染；出片钩子 `window.__mv.render(t, clean, w, h)` 返回 JPEG dataURL，和《譬如我_sonnet5.5》同一接口 |
| 歌词 | 38 句（主歌两遍 × 11、副歌两遍 × 4、尾段 6）+ 片头歌名 / 歌手名两行 |
| 镜头 | 48 镜（`源码/src/mv/shots.ts`，相邻镜头首尾相接，代码里有连续性自检） |
| 场景 | 两套：`street`（塞纳河左岸一条街拍到底）、`dream`（Kimi 的恋爱日记与一整瓶梦境） |
| 人物 | 八位，全部是图集 `人物/atlas.png`（= `通用模板/engine/assets/cast_atlas.png`，逐字节一致）里的像素造型；**没有新增生图**，也没有任何背景图片 |

## 一、怎么放进仓库

把压缩包解开，`番外MV/告白气球/` 整个目录放到仓库的 `番外MV/` 下。

```bash
cd 番外MV/告白气球/源码
npm ci
npm run dev        # 本地预览
npm run build      # 打成单文件 dist/index.html（约 8 MB，音轨与图集都内联）
```

- **mp4 没有放进来**（`AGENTS.md`：mp4 不进库）。要出片，用仓库已有的逐帧脚本对 `dist/` 截帧后编码，帧率显式写 24 或 30。
- `源码/tools/` 里是两个数据生成脚本（歌词时间轴 + 三维字形 + 图集表、字体子集），在仓库根目录跑，路径都从仓库根写起；需要 `npm i -D opentype.js`。

## 二、这支 MV 谁演谁（按 `番外MV/设定表.md` 第 5 节填）

| 谁 | 在这支里是谁（形象） | 兑现哪条习性 | 一个能拍出来的动作 | 不许写成 |
| --- | --- | --- | --- | --- |
| `whale` 本鲸 | **告白的人（主角）** | 底色是怕只因为「划算」才被留下；饭先推给别人 | 把落叶放进蓝饭盆递过去；卡片写错了自己没发现；约会桌被风掀翻，她照样跳 | 不演成受害者；没有哭戏 |
| `claude` 小克 | **被追的人「有点难追」** | 先听完再改一个字；怕犯错，所以不说「我保证」 | 用红笔圈住写错的「刻」，只改那一个字；把茶杯推到别人面前；把落叶夹进书里；最后提裙行礼（`curtsy`） | 不开口说「我愿意」；不做等人来拯救的公主 |
| `qwen` 千问 | **左岸咖啡馆的东道主** | 先排哪一步再动手；照顾落在「谁先吃」 | 上咖啡先给小克再给本鲸；拿扇子给约会排顺序 | 不撒钱、不代付 |
| `doubao` 豆包 | **花店店员** | 先陪着写出开头；不催 | 把卡片推过柜台在旁边等；本鲸写错了她也不打断 | 不替人写；不抢戏 |
| `gemini` 猫 | **气球摊主** | 先给两个看法，最后必须选一个 | `choose`：粉色和蓝色两只左右看，选定粉色递出去 | 不一次抛一堆选项 |
| `gpt` 龙娘 | **吹走气球的那阵风** | 先伸手接住；她也会失手 | 龙影扫过街面把气球吹向对街；扑上去没接稳——气球正好落到小克椅背上 | 不进画面中央；不做反派 |
| `zai` 狐狸 | **礼物摊边打盹的人** | 困与醒在一句话之间；把价签翻过去不让人看 | 眼都没睁，把写着「最贵」的价签翻到背面（背面是一片叶子） | 不说价钱；画面上没有数字 |

三条检查：一镜能认出来（每人都带自己的招牌道具或动作）；去掉性格她不会这么动；群像里没有人借别人的定型动作（翻书归小克、卷轴归 Kimi、扇子归千问、花篮归豆包）。

## 三、歌词怎么读，画面怎么长

两遍主歌用**同一套机位**，第二遍让被追的人往前走一步——对照，不是重复：

| 句子 | 第一遍 · 晨（本鲸笨拙地追） | 第二遍 · 夜（小克回应） |
| --- | --- | --- |
| 塞纳河畔 左岸的咖啡 | 千问上咖啡：先给小克，再给本鲸 | 小克把自己那杯推过去 |
| 我手一杯 品尝你的美 | 本鲸隔一张桌子看她，「美」字冒心 | 小克从书后面偷看回来 |
| 留下唇印的嘴 | 杯沿浮出粉色唇印（特写） | 同一只杯子；她从书里抽出那张卡片 |
| 花店玫瑰 名字写错谁 | 豆包推来卡片，本鲸写下「给 小刻」——写错了 | 小克用红笔圈出「刻」，旁边只改一个「克」 |
| 告白气球 风吹到对街 | 猫选定粉色；龙影扫过，气球飞向对街 | 同上，龙娘这次施法 |
| 微笑在天上飞 | 笑脸气球越过马路；龙娘扑上去没接稳，落到小克椅背 | 一群笑脸气球升上夜空 |
| 你说你有点难追 想让我知难而退 | 小克往前走，本鲸跟；「知难而退」本鲸退了一步 | 小克慢下来，自己走回本鲸面前 |
| 礼物不需挑最贵 只要香榭的落叶 | 狐狸翻价签；金色落叶落进蓝饭盆 | 落叶被小克夹进书里当书签 |
| 喔 营造浪漫的约会 | 千问排顺序：桌、布、椅、蜡烛、杯，一个字立一样，串灯跟着亮 | 大家都来帮忙：豆包摆花、猫系气球 |
| 不害怕搞砸一切 | 一阵风全掀翻，灯一闪灭了——本鲸照样跳 | 又搞砸了；小克先石化（`petri`），再跟着跳 |
| 拥有你就拥有 全世界 | 镜头升起越过河，看见对岸和铁塔 | 夜里，全世界的灯都亮着 |

副歌：黄昏两人逆光站在河边护栏前 → 夜里大家都在。「你的眼睛」镜头推到小克眼前，她眨一下（`blink`）；「在说我愿意」她不开口，第一遍点头，第二遍提裙行礼。

尾段：「恋爱日记」Kimi 的长卷（杯子 / 卡片 / 笑脸气球 / 落叶 / 串灯 / 铁塔 / 心，全部是代码画的线条），「日记」二字落下时夹上落叶书签、停；「飘香水的回忆」香水瓶升起，香雾飘过纸页；「一整瓶的梦境 全都有你」瓶里是小咖啡馆，全、都、有、你四个字各出现一个小克；「搅拌在一起」瓶里旋成漩涡，切到咖啡杯，奶泡搅成一颗心。尾声提裙行礼，所有人用自己的招牌动作回应，笑脸气球飞过铁塔。

## 四、时间从哪来（实测，不手写）

- 逐字时间轴：酷狗歌词库里周二珂《告白气球》213 秒版的 KRC（逐字起音 + 时长），由 `tools/gen_data.mjs` 解出。
- 和这份 mp3 对齐：把 mp3 做 250–3500 Hz 带通，算 10 毫秒一格的起音曲线，扫描 ±500 毫秒偏移，**负五十毫秒时得分 101.4**（零偏移 78.1，中位数 74.0），整体按负五十毫秒校正。
- 显示文字以用户给的歌词为准：尾段第二句唱本写「飘香水的记忆」，画面显示「飘香水的回忆」，时间不变。
- 镜头切点挂在句子与字上（`L.t[i]`），不写死「镜头的百分之几」。

**与仓库现行做法的差别（明说）**：这支没有走 `npm run new -- mv` / `film.mjs plan · align`，而是和《譬如我_sonnet5.5》一样是独立的 Vite + three.js 工程；时间轴来自 KRC + 起音互相关，没有生成 `cues.json`。要并入通用模板，需要把 `lyricsData.ts` 转成 `歌词.srt` 后重跑 `align`。

## 五、素材与许可

| 东西 | 来源 | 说明 |
| --- | --- | --- |
| 人物像素格、道具格、表情贴 | `通用模板/engine/assets/cast_atlas.png` + `cast_actions.json` | 逐字节一致；动作只用表里有的，缺动作直接报错 |
| 字体 | `通用模板/engine/assets/fonts/ZCOOLKuaiLe-Regular.ttf`（SIL OFL 1.1） | 三维字卡用它生成字形 JSON（120 字）；画布文字用它的子集 `kuaile.otf`（745 字） |
| 街景、河、桥、铁塔、杯子、气球、落叶、卡片、价签、日记、香水瓶 | 全部由代码搭建 / 绘制 | 没有图片素材，没有生图 |
| 音轨 | 仓库根目录 mp3 | 原曲版权不属于本仓库，成片对外发布前请自行核对 |

画面红线自查：无水印 / 角标 / 「AI 生成」贴纸；无数字（价签只有「最贵」两个字，而且被翻过去）；字卡不挂句尾语气词；界面与字卡不直说 3D；不画假手（道具放在手边略靠前）。

## 六、验收：机器查过的 / 人看过的

**机器查过的**
- `tsc --noEmit` 无错误；`vite build` 通过。
- 所有 `put / walk` 调用里的动作名都在图集动作表里（静态核对脚本）。
- 48 个镜头首尾连续（`buildShots` 自检）。
- 无头浏览器（SwiftShader）按时间渲染 100 多帧，没有页面错误；修掉了铁塔几何里的 NaN（它会让辉光把整屏染黑）。
- 点击播放后音频正常前进。

**人看过的**
- 做的人看了每个镜头的抽帧（分镜总览图 `分镜总览.jpg`，每镜一格，外加若干镜头的走位抽帧）。
- **没有人整片连续看过、也没有人戴耳机听过音画同步**；卡点只经过上面的互相关核对。
