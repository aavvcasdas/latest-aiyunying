# 告白气球 · opus5.5 笨鱼发（three.js 版）

用户上传的 `告白气球opus5.5笨鱼发.zip`，React + Vite + three.js 0.187，48 镜 / 38 句歌词，`DUR 212.98`，1280×720；塞纳河左岸街景 + Kimi 恋爱日记两套场景，八位角色全部来自 `人物/atlas.png`。包内 `public/告白气球_README.md` 原样保留。

**成片**：`成片/告白气球_opus5.5_笨鱼发.mp4`（1280×720 @30fps，3:32.95 / 6389 帧，h264 crf21 maxrate 3200k + aac 192k，82,438,033 B，`sha256 bea5562e56034e50…`）。音轨用仓库根 `告白气球-周二珂.mp3`。

## 出片前做过的改动

1. **音轨**：包内不带 `src/assets/bgm.mp3`，从仓库根 `告白气球-周二珂.mp3` 原样拷（`.gitignore` 里排除，重出时再拷一次）。
2. **字体**：`src/mv/tex.ts` 用 `../assets/kuaile.otf?inline`，就是模板自带的站酷快乐体（`通用模板/engine/assets/fonts/ZCOOLKuaiLe-Regular.ttf`，SIL OFL 1.1），原样拷成 `kuaile.otf`，没有换字体。`atlas.png` / `glyphs.json` 是包内自带。
3. 包自带 `window.__mv.render(t, clean, w, h)`，出帧不加钩子。

构建 `npx vite build`；出帧 `node tools/shoot_vite_mv.mjs --dist … --dur 212.98 --fps 30 --w 1280 --h 720`，编码 `python3 tools/encode_frames.py --crf 21 --maxrate 3200k`。
