# 那些没有天赋的人 · 笨鱼版

用户上传的 `那些没有天赋的人笨鱼版.zip`，React + Vite 单页，Canvas2D 逐帧绘制，25 镜，`DUR 152.1`，画布 1280×720。

**成片**：`成片/那些没有天赋的人_笨鱼版.mp4`（1280×720 @30fps，2:32.1 / 4563 帧，h264 crf21 maxrate 3200k + aac 192k，58,215,924 B，`sha256 c27e9b3c84f65e0c…`）。音轨用仓库根 `譬如我.mp3`。

## 出片前做过的改动（只动素材与出片钩子，画面逻辑没动）

1. **补出片钩子**：原包没有 `window.__mv` / `window.__seek`，`tools/shoot_vite_mv.mjs` 会 `frame got detached`。在 `src/App.tsx` 的 `draw` 之后加了一个 `useEffect`，挂 `__mv = { duration, fps, width, height, ready, render(t) }`，`render` 只把 `renderFrame(ctx, t)` 画到自己的 canvas 再 `toDataURL`，不碰播放状态。
2. **字体顶替**：`src/assets/serif.ttf` 用仓库 OFL 的 `通用模板/engine/assets/fonts/ZCOOLKuaiLe-Regular.ttf`，`index.css` 的 `@font-face` 改成 `.ttf` / `truetype`。
3. **音轨**：`src/assets/song.mp3` = 仓库根 `譬如我.mp3`（页面里暂停、只作出帧）。

出帧 `node tools/shoot_vite_mv.mjs --dist … --out /tmp/frames_benyu --dur 152.1 --fps 30 --w 1280 --h 720`（5.0 fps，约 15 分钟，4563 帧），编码 `python3 tools/encode_frames.py --crf 21 --maxrate 3200k`。
