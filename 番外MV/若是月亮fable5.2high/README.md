# 《若是月亮还没来》Fable 5.2 high

本目录收录 `若是月亮fable5.2high.zip` 解压后的完整工程、1980×1080 成片和两种比例的封面。

## 成片

- `成片/若是月亮还没来_fable5.2high_1980x1080.mp4`
- 画面：1980 × 1080，H.264 / MP4，30 fps，33.4 秒。
- 声音：仓库根目录 `若是月亮还没来.WAV`，原片头 2.4 秒留白，歌曲结束后保留尾声画面。
- 画面按工程的 `window.__mvSeek` 时间轴逐帧渲染；预览检查覆盖开头、歌词镜头、合影、满月尾声。

## 封面

两张都取自上述成片 **00:29.5** 的满月尾声帧，仅按目标比例裁切，没有另生成或替换人物画面：

- `成片/封面/若是月亮还没来_fable5.2high_封面_4x3.jpg` — 1440 × 1080（4:3）
- `成片/封面/若是月亮还没来_fable5.2high_封面_3x4.jpg` — 1080 × 1440（3:4）

## 人物与素材

本版继续复用仓库中已归档的三张本鲸姿态、笨鱼像素素材、山茶花和路灯素材；没有新生成人物，也没有改动 `人物/atlas.png` 或原人物主图集。姿态图在工程内 `源码/src/assets/gen/`，正式归档位置仍为 `人物/生成/满月篇/`；道具仍归档在 `人物/道具/满月篇/`。未跟踪的 `人物/q版HD_工具包/` 不属于本次提交。

## 构建

```bash
cd 番外MV/若是月亮fable5.2high/源码
npm ci
npm run build
```
