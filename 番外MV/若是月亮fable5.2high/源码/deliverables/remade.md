# remade · 满月篇《若是月亮还没来》第二版：把三十天放进每一个词

> 第零天 2026-10-24 → 第三十天 2026-11-23（满月）。纪念三十天的番外 MV，音源是仓库根目录的 `若是月亮还没来.WAV`（44.1kHz / 立体声 / 29.00 秒）。
> 这一版是在分支 `arena/bb6a02da-latest-aiyunying` 的 `番外MV/若是月亮还没来/源码` 上改的：第一版「别的 MV 和 Day 系列的东西太少」，这一版把第零天到第十六天、十九支番外 MV、九个人的登场日期与招牌道具，逐个放进了歌词的每一个词里。
> 本说明随 `满月篇_第二版.zip` 一起交付：zip 在仓库根目录解开，文件就落到下面写的位置。

## 二、新增生图：零张

- 你说「不要生成背景图片，分镜里有必要才按人物提示词生成人物和道具」。这一版逐镜过了一遍，**没有哪一镜非生图不可**：人物全部来自分支图集 `人物/atlas.png`（八位）与 `人物/q版/笨鱼_px.png`；新道具（拍立得、泡泡、日历、风铃、月相、粉笔格）都是硬边像素块，用代码画比生图再抠绿更干净，也守住了 `AGENTS.md` 的「不新增生图」。
- 第一版生成的五张（本鲸仰望 / 抱笨鱼 / 捧山茶、白山茶三态、路灯）原样沿用，文件与提示词都在 zip 里，没有改动。
- 背景一张都没有生成：夜空、城市、街、房子、窗台、树、月亮全部程序绘制。
- 不伪造接触：伞悬在本鲸头顶、红绳系在两人之间、道具浮在人旁边，都没有画手去拿。
