# 《譬如我》3D 版（sonnet5.5）· 上片记录

成片：`成片/譬如我_3d.mp4` — 1280×720 / 24 fps / **2:32.08** / 3650 帧 / 56.4 MB（h264 High crf23 + VBV 2800k，`sha256 7b769fb0…`），aac 44.1k stereo 193k。
工程：`源码/`（Vite + React 19 + three.js 0.187，`viteSingleFile` 打成单文件 index.html，9 MB）。

## 一、这包缺什么

zip 里是 27 个文件：`App.tsx` + `src/mv/` 十一个模块 + `src/assets/{atlas.png, glyphs.json}`。**代码和美术主体都在**——图集是完整母版 2048×3126，`glyphs.json` 也在（三维字形靠它）。

缺的是两个 import：

| 缺的文件 | 用途 | 处置 |
| --- | --- | --- |
| `src/assets/serif.woff2` | `tex.ts` 里 `loadFonts()` 给 canvas 纹理注册的 `MVSerif`（weight 900） | 用模板 `通用模板/engine/assets/fonts/ZCOOLKuaiLe-Regular.ttf` 转 woff2（871 KB，未做子集，全字表） |
| `src/assets/bgm.m4a` | `App.tsx` 的 `<audio>`，播放时以音频时间轴为准 | 仓库根目录 `譬如我.mp3`（152.11 s，与 `DUR = 152.1` 对得上）转 aac |

字形是 `glyphs.json` 里的 fonts 数据，所以**换字体只影响 2D canvas 纹理（`smileTex`、`clockTex`、`stampTex`、`nameTex("小鱼")` 这些），不影响三维字卡**——三维字卡是 JSON 里的字形轮廓挤出成实体，笔画是原设计。

## 二、源码只改了一处：出片钩子

原 `App.tsx` 已经挂了 `window.__mv.render(t)`，但只把时间塞给 `mv.render(t)`，**不返回画面**，而 `tools/shoot_vite_mv.mjs` 要的是 dataURL。改成：

```ts
(window as any).__mv = {
  duration: DUR, shots: mv.shots.length, ready: () => true,
  render: (s, _clean, w = 1280, h = 720) => {
    const c = canvas.current!;
    if (c.width !== w || c.height !== h) mv.resize(w, h);   // 只第一次真正重建 render target
    T.current = s; mv.render(s);
    return c.toDataURL("image/jpeg", 0.94);
  },
};
```

渲染器本来就有 `preserveDrawingBuffer: true`，所以 `toDataURL` 拿到的就是这一帧本体（后期 pass：色差 / 暗角 / 颗粒 / 划痕 / 闪白全在里面，和播放时一模一样）。页面尺寸是按容器算的（`maxWidth: calc((100vh - 76px) * 16 / 9)`），直接用 `mv.resize(1280,720)` 定死，不靠视口推。

## 三、出片命令（仓库根目录）

```bash
cd 番外MV/譬如我_sonnet5.5/源码 && npm ci && npx vite build && cd ../../..
node tools/shoot_vite_mv.mjs --dist "番外MV/譬如我_sonnet5.5/源码/dist" \
     --out /tmp/frames_y --dur 152.1 --from 0 --to 152.1 --w 1280 --h 720 --fps 24
python3 tools/encode_frames.py --frames /tmp/frames_y \
     --audio "番外MV/譬如我_sonnet5.5/素材/譬如我.mp3" \
     --out "番外MV/譬如我_sonnet5.5/成片/譬如我_3d.mp4" --fps 24 --crf 23 --maxrate 2800k
```

- 3650 帧，无 GPU 的 SwiftShader 软件光栅化，稳定 **3.0 fps**，整片 20 分钟；重镜（舞台 17 个精灵、7 束光柱、彩纸 + 三段后期 pass + UnrealBloom）会掉到 ~1 fps，帧号跳过是正常的，脚本按绝对时间取帧。
- 编码必须显式 `--fps 24`（`encode_frames.py` 默认 30，会把 2:32 压成 2:01）。
- 文件体积：这支片子每个像素都在跑颗粒噪声，码率下不来。crf20 → 73.4 MB，crf23 → 56.4 MB，逐帧对比颗粒保留度差别很小，取 23。
