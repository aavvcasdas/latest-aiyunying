## 一句话

一场被翻烂的舞台剧：书页是布景，剧本是台词，公主、狼、猎人都是纸偶。
本鲸先问一句「谁写的」，然后撕页、拿枪；小克是被写成睡美人的那位，这次自己睁眼。
最后一枪打穿的不是人，是挂在台口的那行剧本字。

## 三层结构

1. **前 52 秒**：四页剧本 + 念白（英文字幕原文，中文意思靠画面讲）——所有人都在照剧本演。
2. **52 秒「Stop！」到 2:39**：本鲸拍书、撕页、重写；小红帽、人鱼、公主三页被一页页改掉。
3. **副歌 2:39–3:14**：十个等长乐句，十镜；3:17 之后最后三句再吼一遍，三镜；3:25 幕落，真正的天。

## 分镜怎么切

- 段落边界实测（响度跳变 + 发声段检测），句内切点能测到停顿的用实测，测不到的按乐句等分。
- 口径与《童话镇》一致：**句级对齐，不做人声分离**，不号称逐字对齐。
- 详见 `分镜表.md` 末尾「时间轴是怎么来的」。
