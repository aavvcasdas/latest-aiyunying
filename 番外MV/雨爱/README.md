# 《雨爱》（司凤版）· 雨天治愈 MV

从用户上传的 `来源/雨爱-mv.zip`（一个只有源码、没带音轨与字体图集的 Vite + Remotion 工程）接进本仓库的模板线：
three.js 搭的 3D 雨巷与屋内 + 图集里现成的像素角色当纸片人，Remotion 逐帧驱动，音轨按采样对齐混入。

**规格**：30 个镜头、23 句歌词、131.2 秒（3936 帧，1920×1080 @30fps）。歌词条用雨天配色（蓝白细边、圆角），片头卡也是蓝调。

## 文件

| 文件 | 说明 |
|---|---|
| `film.json` | 元数据：`audio.file` 指向 `media/yuai-sifeng.m4a`，`output` 写成片子名「雨爱」 |
| `歌词.srt` | 23 句带时间的歌词（第 19–23 句是 99 秒后的副歌重唱，按音轨实际演唱补入） |
| `cues.json` | 卡点：`measured: true`，起点吸附在实测拍点上（八分音符 0.37033 秒、四分音符 81.0 BPM） |
| `plan.ts` | 排镜规则：一句一镜，切点 = 句起点 − 2 帧；四个长句在句中的实拍上再切一刀 |
| `project.tsx` | 交给 `@tpl/project` 的 `defineProject`，`subtitle: 'lyric'` + `lyricTone: 'rain'` |
| `shots/common.ts` | 共用布景件：雨巷、屋内（真开窗洞）、彩虹、接雨的蓝饭盆、涟漪、相框、伞与雨 |
| `shots/shotsA.ts` / `shotsB.ts` / `shotsC.ts` | 序章 + 主歌 / 两段副歌 / 雨后重唱 + 尾声 |
| `media/yuai-sifeng.m4a` | 原曲音轨（1.2 MB，AAC 44.1 kHz 立体声，131.27 秒） |
| `来源/雨爱-mv.zip` | 用户上传的原始工程包（只有源码：引擎副本 + `src/yuai/`），不动它，留作对照 |
| `成片/雨爱.mp4` | 出片结果（81 MB，2026-11-12 按用户要求入库；同目录还有 `qa.json` 与分镜总览图） |

**音轨是怎么来的**：仓库根目录原来那首《雨爱》司凤版.mp3 其实是 MP4 容器（H.264 + AAC 44.1 kHz），
用 `-vn -c:a copy` 无损抽出音轨（不重编码）。抽出来的 m4a 与源文件里那条 AAC 轨，各自解成 WAV 后
`sha256` 都是 `606c66e25aa5891ab4bf3d75073f798fb0686474666cadb86f73a380ed9f903a`——逐采样相同，
只是封装（容器元数据）不同，所以 `cues.json` 里记的是这一份 m4a 的 sha。

## 卡点是怎么对的

- **拍点**：`通用模板/cli/align_beats.py` 实测。八分音符 0.37033 秒（四分音符 81.0 BPM），梳状得分为基线的 4.65 倍，
  每 15 秒一窗复核最大相位漂移 0.010 秒。小节相位按低频起音最强的那一拍定。
- **人声起点**：音源是单声道混音，没法用中置声道分人声；用 faster-whisper（small）的词级时间戳定位每句，
  再用 300–5500 Hz 的能量阶跃复核句首，最后吸附到最近的八分音符实拍。
- **这是拍点级对齐，不是逐音节对齐。** 把握最小的是第 19 句（重唱的「窗外的雨滴 一滴滴累积」，约 99.5 秒）：
  识别结果在这一句上是乱的，起点取的是两遍识别都支持的那个拍。

## 相对模板引擎改了什么

原包带了一份 `src/engine/` 的引擎副本，与 `通用模板/engine/` 的差别只有三处，已经并回模板（不是只在这一支里生效）：

| 文件 | 改动 |
|---|---|
| `engine/kit.ts` | 加四套光照：`drizzle` 雨天 / `rainEve` 雨夜 / `cozy` 屋内 / `afterRain` 雨后 |
| `engine/subtitles.tsx` | 歌词条多一个 `tone`：`gold`（默认，童话书金色）/ `rain`（雨天蓝白，圆角、细边、淡金染色） |
| `engine/project.ts` + `Film.tsx` | 项目多一个 `lyricTone` 字段，片名卡的描边与字色跟着换 |

其余（引擎、布景、道具、时间轴）一行没改——原包是照这份模板抄的，`props.ts` 里的 `rain()` / `umbrella()` / `cameraProp()` 模板里都有。

## 结果

见片子目录下的 qa.json：帧数、时长、音画偏移、抽帧自检都在那里。**没有人把成片从头到尾连着看一遍、听一遍**——
做的是每个镜头抽帧看构图，加上引擎的角色预检（30 镜 / 3936 帧逐帧走过，0 个问题）与文字预检（26 处 / 101 个字，模板字体全有）。
