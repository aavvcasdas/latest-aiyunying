## 这条片子是什么

30 个镜头、23 句歌词、2 分 11 秒。母题一句话：**雨天里安静走开的人，后来喜欢上了雨；雨停以后，那个人自己走回来了。**

## 重出这两张封面

```bash
FF=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")   # 仓库里没有 ffmpeg 时
$FF -ss 20.40 -i 番外MV/雨爱/成片/雨爱.mp4 -frames:v 1 -y /tmp/y20.png
$FF -ss 32.17 -i 番外MV/雨爱/成片/雨爱.mp4 -frames:v 1 -y /tmp/y32.png
python3 -c "from PIL import Image; Image.open('/tmp/y20.png').crop((180,60,1500,1080)).save('/tmp/y20c.png')"  # 竖版底图先裁成近景
python3 tools/cover.py --still /tmp/y20c.png --title 雨爱 --out /tmp/c34 --name 雨爱 --punch   # 取它的 _3比4
python3 tools/cover.py --still /tmp/y32.png  --title 雨爱 --out /tmp/c43 --name 雨爱 --punch   # 取它的 _4比3
```

`--punch` 是给手机缩略图提神用的（饱和 +20%、对比 +10%、轻锐化、四角压暗），默认关，别的片子不受影响。
