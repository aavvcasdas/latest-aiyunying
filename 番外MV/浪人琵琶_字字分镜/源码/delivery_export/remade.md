## 0. 一句话

- **片子**：1280×720 · 30 fps · 30.14 秒 · **十一镜 / 三十四个词拍**，十句歌词里的每一个词都有自己的画面动作。
- **画风**：「字化万象」——每个词先以墨字落在宣纸上，再化成它的意思（念拆成今与心、钟就是一口钟、哗哗砸成倾盆、风散成风线）。与参考片（像素街市、荷塘、地图、俯视茶桌、圆窗）**一处不重**。
- **人物**：全部来自 `人物/atlas.png`，按 `人物/index.json` 原样裁帧，**没有新造型、没有生成图**。
- **背景与道具**：全部 Canvas2D 代码绘制。**没有生成任何背景图片，也没有生成人物和道具图**——逐镜核对过，分镜里没有哪一处非生图不可（伞、钟、黄历、水袖、铜钱、茶壶、玻璃杯、茉莉、牡丹、拼图、琵琶、乌鸦、雁都能用代码画出来）。所以本次**不附带新的人物提示词或生成图**。
- **歌词卡点**：句子起点按参考片底部字幕条**每秒四帧逐格实测**（精度约 0.25 秒）；句内的词按字数平分演唱段。`cues.json` 里 `measured: true`。

## 2. 深读歌词：这十句在讲什么

《浪人琵琶》写的是一个**穷书生自嘲式的单恋**。参考了 `参考资料/项目调研/Agent-Reach研究/` 里的角色与关系梳理后，选角与读法如下：

| 句 | 字面 | 底下的意思 | 画面怎么接 |
|---|---|---|---|
| 我的思念 | 我想你 | 「念」= 今 + 心，此刻的心 | 墨字拆开，心跳成念想泡泡，泡里是小克 |
| 似六月里的小雨哗哗 | 像六月的雨 | 六月是梅雨、是榴月，来得急、收不住；「哗哗」是拟声，说思念**哗地就下来了** | 心捏成雨滴 → 黄历翻到六月 → 龙娘在云上施雨 → 拟声字砸成倾盆 |
| 对你情有所钟 | 我钟情于你 | 「钟」字面就是一口钟，撞一下，心里嗡一声 | 红线牵过冷暖两半，铜钟落下撞三响 |
| 为你两袖清风 | 为你我一无所有 | 两袖清风＝清贫，袖里只有风；自嘲而不卑 | 深深一拜 → 大袖甩开 → 只抖出风、叶子和一枚滚走的铜钱，滚到「富商千金」千问脚边 |
| 小生的花伞还落在你家 | 我的伞忘在你家了 | 「小生」是戏曲行当，自报家门；伞落在你家＝**还有回去的理由** | 戏台亮相落「小生」印 → 花伞旋开 → 伞斜靠在你家门边 → 窗里亮灯，你探头 |
| 你美眷如花 | 你像花一样美 | 「美眷」本指佳偶，衬出门第 | 花环围拢、牡丹盛开 |
| 我浪迹天涯 | 我四处漂泊 | 「浪」字面是浪：脚印化成浪 | 转身上路 → 脚印成浪 → 一人一崖一行雁 |
| 为我泡杯花茶 | 你给我泡茶 | 待客之礼，温柔但客气 | 茶壶自己浮起注水（不给道具画假手），杯里茉莉舒展 |
| 和你有些不搭 | 我和你不般配 | 门第与处境的落差 | 画面斜劈：一半落雨一半开花 → 两块都是凸头的拼图，怎么也对不上 |
| 气氛开始有一点尴尬 | 有点尴尬 | 全段的笑点落地：深情铺满之后，一句大白话 | 灰雾漫起 → 乌鸦飞过 → 头顶「点、点、点」→ 冷汗问号，定格成一幅墨画 |

## 4. 怎么跑

```bash
cd 番外MV/浪人琵琶_字字分镜/源码
npm install
npm run dev          # 浏览器里播放、拖动、点词跳转
npx vite build       # 单文件 dist/index.html
# 逐帧出片（仓库现成工具，页面已装 window.__mv.render 钩子）
cd ../../..
node tools/shoot_vite_mv.mjs --dist 番外MV/浪人琵琶_字字分镜/源码/dist --out /tmp/fs_lrpp --dur 30.14 --w 1280 --h 720 --fps 30
python3 tools/encode_frames.py   # 按该脚本的参数把帧编码并混入 浪人琵琶.WAV
```

可选：`python3 源码/scripts/prepare_assets.py` 会从仓库根的 `人物/atlas.png`、`人物/index.json`、`浪人琵琶.WAV` 重新生成 `cast.png`、`castData.ts`、`langren.m4a`（需要 pillow 与 ffmpeg）。

## 5. 守住的规矩

- 零水印、零角标、零「AI 生成」贴纸；画面里没有进度条和任何数字（数字全写汉字：六月、一二三四五六）。
- 只用 Q 版像素造型，七头身立绘没用；没有新增生图、没换画风。
- 不伪造接触：茶壶自己浮起、伞自己落下，没有给道具画假手。
- 逐帧函数只读时间参数；角色每帧重新摆；缺帧直接报错。
- 画面上的字只用常用汉字，已裁进字体子集。

- 机器查过：`tsc` 与 `vite build` 通过；每个镜头在起、中、末三处取帧检查过不报错。
