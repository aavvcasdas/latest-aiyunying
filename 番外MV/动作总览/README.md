# 《动作总览 v2》· 96 个动作每个演一遍

**效果片，不是 MV**：没有歌、没有歌词、没有字幕、没有解说。目的只有一个——把 `update-character-animation-assets.zip`
（动作库 v2，见 [`../../人物动作替换v2.md`](../../人物动作替换v2.md)）里 **8 位 × 12 个 = 96 个动作**全部放进画面里看一眼。

**规格**：2 个镜头、48.0 秒（1440 帧，1920×1080 @30fps）、无声。

## 怎么排的

一排四个人，每人头顶一块名牌：上面一行是谁（金色小字），下面一行是**此刻正在演的动作**（白色大字）。
每 **2 秒**四人同步换下一个动作——2 秒正好是这个动作的一整轮（24 帧 @12fps），所以每一轮都是一个完整循环。

| 镜头 | 起止 | 谁 | 十二轮 |
|---|---|---|---|
| `S1` | 0–24s | 本鲸 / 龙娘 / 小克 / 豆包 | 待机、行走、挥手、说话、鞠躬、坐下、开心、思考、惊讶、跳跃、**专属一**、**专属二** |
| `S2` | 24–48s | 猫 / Kimi / 千问 / 狐狸 | 同上 |

专属动作：本鲸 递饭碗 / 鲸尾打拍，龙娘 举沙漏 / 展翼守护，小克 认真翻书 / 端杯思考，豆包 递出篮子 / 轻快踩拍，
猫 对照时钟 / 提笔创作，Kimi 展开卷轴 / 夹好书签，千问 轻摇折扇 / 茶会邀请，狐狸 拨动算盘 / 睡醒认真。

**没有 Grok**：上游包是九位角色，本分支 2026-11-12 已把她的形象删掉（`设定/人物/Grok.md`「暂无可上画造型」），
所以她的 288 格（12 动作 × 24 帧）在装包时就被剔掉了，这一片只有八位、96 个动作。

## 每轮对应的时间（方便对照）

`S1` 第 r 轮 = `r × 2` 秒（r 从 0 数到 11）；`S2` 第 r 轮 = `24 + r × 2` 秒。
例：想单独看「跳跃」，是 `S1` 的 18–20 秒和 `S2` 的 42–44 秒；「坐下」是 10–12 秒 / 34–36 秒。

## 文件

| 文件 | 说明 |
|---|---|
| `film.json` | 没有 `audio`、没有 `subtitles`，`output` 写成「成片/动作总览v2」 |
| `project.tsx` | 切点写死：`S1` 0 秒、`S2` 24 秒，全片 48 秒 |
| `cues.json` / `歌词.srt` | 引擎要求至少一句的占位，时间在片外（−30 秒），永远不会被画出来 |
| `shots/shots.ts` | 舞台、四人格位、名牌贴图（Canvas 2D + 模板字体）、每 2 秒换动作的逻辑 |
| `成片/动作总览v2.mp4` | 成片（无声；同目录有 `qa.json`、分镜总览图） |

## 出片

```bash
npm run film -- info   番外MV/动作总览
npm run film -- stills 番外MV/动作总览 30 330 660 740
npm run film -- frames 番外MV/动作总览
npm run film -- encode 番外MV/动作总览 --out 番外MV/动作总览/成片/动作总览v2.mp4
npm run film -- qa     番外MV/动作总览 --skip-frames
```

## 已知

- 48 秒里塞 96 个动作，每个只有 2 秒——**够看清一个循环是什么样，不够判断好不好看**。要细看某个动作，用
  `--shot S1 --n 12` 抽单镜的格子图，或者把 `ROUND` 调大重渲。
- 名牌是画在 3D 画面里的贴图（Canvas 2D + 模板字体），逐帧跟着人走；文字预检会核这 99 个字在字体里都存在。
- `qa` 会报一条「1 句的字幕条没检测到」——占位句在片外，这片子定义就是没有字幕，和《人物动作演示》一样。
