# 《雨爱》（司凤版）· 治愈风像素 MV

31 个镜头、22 句歌词、2 分 11.2 秒。做法照仓库里唯一的参考案例《童话镇》：
**three.js 搭 3D 世界，图集里现成的像素角色当 2D 纸片人，Remotion 逐帧驱动，歌词条逐字染色。**
人物形象全部取自 `engine/assets/cast_atlas.png`，没有新画任何人。

和《童话镇》不同的一点：这里没有用命令行出 mp4，而是把同一个 Remotion 合成放进 `@remotion/player`，在网页里实时播放（音轨一起打包）。

## 文件

| 文件 | 说明 |
|---|---|
| `cues.json` | 卡点：22 句的起止秒数 + 实测拍点（四分音符 0.74066 秒，约 81 BPM） |
| `歌词.srt` | 同一份卡点的 SRT 版本 |
| `project.ts` | 作品定义 + 这首歌自己的排镜规则 `plan()`（所有切点由歌词起点和实测拍点派生） |
| `shotsA.ts` / `shotsB.ts` | 31 个镜头 |
| `sets.ts` | 这首歌自己的布景和道具：雨巷、暖屋、窗台特写、彩虹、茶具、接雨的器皿…… |
| `../engine/` | 引擎，原样取自 `通用模板/engine`。改动三处：`kit.ts` 加了六套光（阴雨 / 雨中蓝调 / 暖屋 / 放晴 / 太阳雨 / 放晴的暖屋）；`engine.ts` 加了 `prebuild()`（网页实时播放时预先搭景，切镜不卡）；`Film.tsx` 调用它，并把片尾字加深了描边。去掉了只给命令行出片用的 `register.tsx` |
| `../assets/yuai.m4a` | 音轨。仓库里的 `《雨爱》司凤版.mp3` 实际是一段 MP4（H.264 画面 + AAC 声音），这里只把声音原样转存出来（`-c:a copy`，没有重新压缩） |

## 在这个仓库里出片

zip 里只带网页工程，音轨、图集 PNG、字体三个文件都没带（网页版是从仓库里跑起来的，打包时漏了）。补齐后：

```bash
node tools/render_zip_mv.mjs yuaimv2            # 出完整成片 → 成片/雨爱_mv2.mp4
node tools/render_zip_mv.mjs yuaimv2 --still 24 # 只抽第 24 秒一帧
```

补齐的三样：

1. `src/assets/yuai.m4a`（同时拷一份到 `public/yuai.m4a` 给命令行出片用）——从仓库根的《雨爱》司凤版源文件 `-c:a copy` 无损取出 AAC。
2. `src/engine/assets/cast_atlas.png` + `cast_atlas.json`——zip 里只有旧的 121 格 json，没有 PNG。现在用的是 `通用模板/engine/assets/` 那份 2048×3439、747 格的；旧 121 格的坐标逐条核对过，全部落在新图里且数值一致。
3. `src/engine/assets/fonts/ZCOOLKuaiLe-Regular.ttf`——无头渲染环境没有中文字体。

另外补了 `src/remotion-entry.tsx`：README 原文写明「去掉了只给命令行出片用的 register.tsx」，要出 mp4 就得把 `makeFilm(project)` 重新注册成 `<Composition id="Yuai">`。网页入口 `src/App.tsx` 没有改动。

## 卡点是怎么对的

- 全曲拍长用 `通用模板/cli/align_beats.py` 的 `measure_beat` 实测：八分音符 0.37033 秒，分 15 秒窗复核，最大相位漂移 0.01 秒。
- 每句起点：先用 faster-whisper（small）的词级时间戳定位，可疑的句子切成小段再识别一遍互相核对，最后吸附到实测的八分音符网格（弱起的几句落在十六分位）。
- 用户给的歌词是 18 句；音频在第 18 句之后把「屋内的湿气像储存爱你的记忆」到「彩虹的美丽」四句又唱了一遍（没有重唱「窗外的雨滴 一滴滴累积」），所以字幕共 22 句。
- 镜头切点 = 这一句起点 − 2 帧；长句在后半句开口的那个八分音符上再切一刀（L12 / L13 / L17 / L18 / L22）。镜头里的踩拍、落雨滴、涨水面都读实测网格。

## 检查过什么，没检查过什么

- 引擎自带的全片角色预检通过：31 镜 / 3936 帧逐帧走过，9 个角色用到 88 格精灵，顺着走和倒着走结果一致。
- 用无头浏览器（软件渲染）给每个镜头抽了一到三帧静帧看过构图：人有没有被画框切掉、有没有被歌词条挡住、窗棂有没有压脸。
- **没有人把它连续播放着看完、听完。** 卡点是算出来的，是拍点级对齐，不是逐音节对齐（没有做人声分离），个别句子的起点可能和歌声差 0.1–0.3 秒。
- 原曲录音和角色形象的授权沿用仓库现状，没有核实过。
