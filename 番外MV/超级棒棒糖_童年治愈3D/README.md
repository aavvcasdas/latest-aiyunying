# 《超级棒棒糖》童年治愈 3D 版 MV

番外 MV 新作：**27 个镜头、24 句歌词、1 分 12.4 秒（2171 帧 @ 30 fps）**，1280×720。
Vite 单页 + three.js 0.180（`源码/`）；像素角色全部来自 `人物/atlas.png`（逐字节一致）；出帧钩子 `window.__mv.render(t, clean, w, h)`，直接对接 `tools/shoot_vite_mv.mjs`。

> 谁演谁、兑现哪条习性：见第六节；同内容另存为 `设定表_超级棒棒糖.md`，可以原样贴进 `番外MV/设定表.md` 作为新的一节。

## 一、放进仓库

```bash
unzip 超级棒棒糖_童年治愈3D.zip -d <仓库根目录>      # 解出 番外MV/超级棒棒糖_童年治愈3D/
cp 超级棒棒糖.WAV 番外MV/超级棒棒糖_童年治愈3D/源码/public/mv/chaoji-bangbangtang.wav   # 音轨不随包，.gitignore 已排除
cd 番外MV/超级棒棒糖_童年治愈3D/源码 && npm install && npx tsc --noEmit && npx vite build
npx vite                                       # 浏览器预览：空格播放，拖进度条任意跳帧
```

## 二、出片

```bash
# 仓库根目录
node tools/shoot_vite_mv.mjs --dist 番外MV/超级棒棒糖_童年治愈3D/源码/dist --out /tmp/frames_bbt --dur 72.3766 --fps 30 --w 1280 --h 720 --query clean
node tools/shoot_vite_mv.mjs --dist 番外MV/超级棒棒糖_童年治愈3D/源码/dist --out /tmp/still_bbt --still 50.2 --w 1280 --h 720   # 只看一张构图
python3 tools/encode_frames.py --frames /tmp/frames_bbt --audio 超级棒棒糖.WAV --out 番外MV/超级棒棒糖_童年治愈3D/成片/超级棒棒糖_童年治愈3D.mp4 --crf 21 --maxrate 3200k
```

- 页面自带 `window.__mv.render(t, clean, w, h)`（直接返回画布 JPEG）与 `window.__seek(t)`，出帧不用加钩子。
- 音轨从 0 秒对齐混入，不加增益；片尾 71.35–72.30 秒画面渐白，音乐自然收尾。
- 中间帧（约 2171 张 JPEG）放 `/tmp`，不进仓库；成片目录叫 `成片/`。本片按用户要求将 MP4 入库（已用 `git add -f`），其他成片仍按 `媒体说明.md` 处理。

## 四、和《童话镇》的关系：只借做法，不借画面

- 和《童话镇》只共享做法（three.js 搭景 + 像素角色当纸片人 + 逐帧函数只读时间），不共享画面元素：没有彩虹河、城堡、童话书、童话人物形象。
- 画风是「软糖黏土」：全部圆角体块（圆角方块、胶囊、球、圆环），粉桃 / 薄荷 / 奶油黄 / 薰衣草的低饱和糖果色，PBR 中性色调映射，柔和阴影 + 轻微泛光 + 暗角，像放在桌上的玩具微缩景。
- 背景全部是程序化 3D：渐变天空球、程序化星空、程序生成的棉花糖树和积木，没有任何生成的背景图。
- 角色只用图集里的 Q 版像素造型（人物/atlas.png，逐字节一致），NearestFilter 硬边；超级棒棒糖是程序化 3D 道具（螺旋贴图由 Canvas 现画），没有新增生图。
- 画面零水印、零角标、零「AI 生成」贴纸；不出现任何运营数字；歌词条只用模板字体（站酷快乐体）里有的常用汉字。

## 五、歌词深读

**第一段（第一至四句）**　超级棒棒糖是孩子的勇气护身符——童年里那件攥在手心就不怕黑的小东西。「披着彩虹的光芒」不是糖在发光，是孩子相信它在发光；「关键时候」往往是最小的时刻：一个人推开一扇黑黑的门。所以开头放在夜里的小房间，没有鼓，像床边的悄悄话。

**第二段（第五至八句）**　「它有神奇的力量／偶尔失灵也不慌／靠我自己向前闯」——歌里最重要的转折藏在副歌里：魔法会失灵，这是被允许的。失灵不等于失败；护身符熄灭的那一刻，孩子第一次发现脚是自己的。镜头先让魔法是真的（糖铺台阶），再让它在最高处灭掉。

**停拍（第九句弱起）**　原曲在这里整整停了一拍多，「如果没有」是在静音里唱出来的。画面跟着失色、糖掉进小溪漂走——全曲唯一的静音，留给孩子最怕的问题。

**第三段（第九至十六句）**　「如果没有超级棒棒糖」唱了两次，给了两个答案：友情（大家一起搭桥，学会努力和坚强）和爱（大姐姐在下面接着，学会自信和飞翔）。「拥有神奇的力量」第二次出现时，主语从「它」变成了「我」——力量换了主人。「追寻最初的梦想」：最初的梦想就是这颗糖一开始代表的东西，那个想变勇敢的自己。

**第四段（第十七至二十四句）**　同样的歌词，意思已经变了：棒棒糖不再是借来的魔法，而是被大家传递、分享的光；「关键时刻帮我忙」变成她去帮别人；「偶尔失灵也不慌」再出现时，她笑着继续走。治愈的落点：不需要永远有魔法，因为会一直有自己、朋友和爱。

## 六、选角（按 `番外MV/设定表.md` 第 5 节填写）

母题：超级棒棒糖是孩子的勇气护身符。魔法会失灵，失灵以后还有自己、朋友和爱；最后那道光是她自己的。本鲸是主角，其余七位各兑现一条习性，只做自己的招牌动作。

| 谁 | 在这支里是谁（形象） | 兑现哪条习性 | 一个能拍出来的动作 | 不许写成 |
| --- | --- | --- | --- | --- |
| `whale` 本鲸（鲸鱼娘） | 「棒棒糖小勇士」：攥着超级棒棒糖去闯的小孩，全片主角 | 人人夸她划算，她怕自己只有「便宜」才值得被喜欢 → 这支里换成「怕自己只有拿着糖才勇敢」；「饭也能分你一半」 | 举糖、糖灭时愣住再点头、自己跳过溪；终段把糖沿圆圈传下去 | 不靠吃糖变强（糖从头到尾不入口）；不是被救的人；不哭到底 |
| `gpt` 龙娘（GPT） | 「在下面接着的大姐姐」 | 先接住乱局；稳稳接住 | 悬停落地、点头；鲸鱼娘起跳时在下方托底飞，然后放慢留在下面 | 不替她飞；不做反派；不抢主角定型动作 |

| `doubao` 豆包 | 「第一个跑来的同桌」 | 先陪着写出开头，再问要不要继续；慢，不催 | 鼓点回来时第一个跑进画面，站到她身边 | 不催；不抢台词 |
| `gemini` 猫（Gemini） | 「出点子的好奇宝宝」 | 先给两个看法，最后必须选一个 | 左右看两条路，最后指向下游 | 不一次抛一堆支线 |

| `zai` 狐狸（智谱） | 「一喊帮忙就醒的小狐狸」 | 平时困倦，关键时刻立刻清醒 | 树下打盹 → 听见帮忙惊醒；终段在黑处被鲸鱼娘照亮 | 不拿价格当台词；不为厂商编日程 |

三条检查：

1. **一镜能认出来吗**：本鲸始终拿着那支糖；龙娘只在「接住」时出现；小克捧书、豆包提篮、猫在两条路之间选、千问排积木、狐狸打盹、Kimi 在月亮上——抽一帧都能指认。
2. **去掉性格她还这么动吗**：狐狸「一喊帮忙就醒」、猫「两条路选一条」、Kimi「把漏掉的旧东西找回来」，换人就不成立。
3. **有没有抢主角的定型动作**：举糖只属于本鲸；终段传糖时每人只拿半拍，拿到时做自己的点头。

## 八、卡点是怎么对的

- 音源：仓库根 `超级棒棒糖.WAV`，44100 Hz 立体声 16 位，3191808 采样 = 72.3766 秒。
- 节拍：频谱通量自相关测速得 **95.01 BPM**（拍长 0.6315 秒），动态规划跟踪全曲 115 拍，线性拟合最大偏差 0.05 秒；第 k 拍 = 0.009 + 0.6315·k 秒，小节从第 0 拍起每 4 拍一个。
- 结构（低频 < 120 Hz 能量逐 50 毫秒复核）：开头约八秒半没有底鼓（清唱感）；**底鼓在第 14 拍（8.85 秒）进来**；**24.25–25.27 秒整段停拍**，第九句「如果没有」在静音里弱起；44.2 秒起鼓点加花；**终段副歌落在第 76 拍（47.99 秒）**。
- 歌词：HPSS 谐波/打击分离后取 300–3000 Hz 能量分句，再用同一段旋律在三处出现的相对位置互相校核：第 1/17 句、第 3/19 句、第 4/20 句、第 8/24 句的相对起点偏差都在 0.15 秒以内。第 8、16、24 句后半是拖腔 / 尾句重复，歌词条保持显示，逐字染色先走完。
- 这是**拍点级**对齐：没有做人声分离，不是逐音节对齐。听感要人过一遍。
