## 做了什么改动

| 改动 | 位置 | 说明 |
|---|---|---|
| **字幕时间按真人声重排** | `src/data/cues.ts` 的 55 行 `t` | 原来整条时间轴是估算的，第一句写 11.6s，实际人声 15.13s 才进来。现在逐句对着音频实测重排（第一句 15.13s、副歌 48.63s、桥 149.18s、末副歌 165.28s、尾声 202.03s），歌词文本与镜头内容一个字没动 |
| **补齐三件套** | `src/assets/` | zip 里缺音轨、图集、字体。音轨由根目录 mp3 转；图集与字体取自 `通用模板/engine/assets/` |
| **修图集高度** | `src/lib/atlas.ts` 的 ATLAS_H、`src/data/castAtlas.json` | zip 的 `castAtlas.json` 声明高 1006，但配的图集 PNG 实际是 1024×1212。高度一错，采样区间整体偏移又翻过来，**纸片人会头朝下**。换成模板配套的 JSON（多 13 个 `grok_*` cell，本片不用），高度改 1212 |
| **加出片模式** | `src/App.tsx`、`src/hooks/useMVPlayer.ts` | `?render=1` 时隐藏面板/片头卡/镜号轨/时码/右下角标注，时间由外部逐帧给，字幕与字卡改画进 2D canvas（`src/lib/lyricCanvas.ts`） |
| **切镜时重置计时** | `src/three/stage.ts` 的 `setCue` | 跳帧渲染时不能把上一镜的时间差当成这一镜的 `dt`，否则机位会先顿一下 |

## 字幕时间怎么定的

**别用应用自带的「自动对齐」**（`autoAlign` / `detectVocalOnset`）。这首歌前 13 秒是钢琴独奏，
那个函数会把钢琴的第一个音（6.84s）认成人声起点，对出来整条轴全歪。

现在的做法：把 `背对背拥抱.mp3` 解成 8kHz 单声道，按 10ms 窗算 RMS 包络，逐个歌词起点看「能量是不是在这一刻抬起来」，
再跟网上多份同版 LRC 交叉核对（多源一致，且 90 BPM 网格的平均偏差只有 0.125s，说明 LRC 本身是准的）。
BPM 自相关在 73.6 / 90 / 92 都有峰，**没有强行套拍网格**。

对出来的锚点（秒）：

```

33.28 谁无理取闹     36.48 你的双手甩开   41.93 然后战火再燃烧   48.63 我们背对背拥抱
52.28 滥用沉默在咆哮  55.93 爱情来不及变老  58.93 葬送在烽火的玩笑  63.33 我们背对背拥抱
67.05 真话兜着圈子    71.00 只是想让我知道  74.70 只是想让你知道   78.55 爱的警告
```

每句的 `end` 就是下一句的 `start`，歌词之间的空档留给间奏镜。

## 怎么出片

这支片子**不走 Remotion**（工程是纯 Vite + three.js + DOM，没有 Remotion 入口），
用无头 Chromium 逐帧驱动 + ffmpeg 合成：

先在这个目录里装依赖、打一次包（用工程自己的 vite，仓库根那套脚本不管这支片子）：

```bash
cd 番外MV/背对背拥抱
npm install
npx vite build
cd ../..
node tools/shoot_bb.mjs                    # → 本目录 成片/背对背拥抱.mp4（1600×900 30fps，7047 帧，3:54.9）

node tools/shoot_bb.mjs --from 45 --to 75  # 只渲一段看看（秒）
node tools/shoot_bb.mjs --still 48.63      # 抽一帧
```

- 帧先落系统临时目录，成片才写回 `成片/`；`*.mp4` 默认不入库（这支按用户要求随分支入库，见 `媒体说明.md`）。
- 这台机器没有显卡，Chromium 走 SwiftShader 软件光栅化：整页截图要 6 秒一帧，所以出片模式改成
  「页面内合成一张 canvas → POST 回 Node」，内部按 0.75 倍像素渲再放大，2 核上约 **2 帧/秒**，全片 96 分钟。
- 脚本默认用 CRF 18 出（约 135 MB）。GitHub 单文件上限 100 MB，入库那版重压成 CRF 24（65 MB），画质肉眼看不出差别。
- 画面里**没有任何水印/角标**：镜号轨、左下时码、右下角那行「three.js · 1600 × 900」在渲染模式全部不画。
