# 《若是月亮还没来》· 满月篇

项目源码从分支归档 `若是月亮还没来.zip` 解压，首页为 Canvas2D MV；角色以现有图集为基础，补充本次明确要求入库的鲸鱼娘姿态素材。

- **渲染输出**：`成片/若是月亮还没来_1980x1080.mp4`（工作区交付；MP4 按仓库规则不提交）
- **画面规格**：1980×1080，30 fps；项目时间轴从无声片头到满月尾声，共约 33.4 秒
- **歌词音源**：`源码/src/assets/若是月亮还没来.WAV`，MP3 播放副本为 `源码/src/assets/moon.mp3`
- **人物姿态素材**：`人物/生成/满月篇/`；笨鱼像素副本：`人物/q版/笨鱼_px.png`
- **分镜与卡点**：`番外MV/若是月亮还没来_满月篇/`
- **发布文案**：`文案.md`

## 构建源码

```sh
cd 源码
npm ci
npx tsc --noEmit
npm run build
npm run dev -- --host 0.0.0.0
```

`vite.config.ts` 已开放 `.e2b.app` 预览 Host，并监听 `0.0.0.0`。

## 入库素材

- 新增人物图均放在 `人物/生成/满月篇/`，有配套提示词与来源说明；没有重烘角色图集。
- 新增道具放在 `人物/道具/满月篇/`。
- 素材来源/规则说明保存在 `素材/remade.md`；字体为 ZCOOL KuaiLe，随源包提供 OFL 许可证。
- 新成片使用仓库 WAV，音乐/角色公开传播许可需依仓库现有规则另行确认。
