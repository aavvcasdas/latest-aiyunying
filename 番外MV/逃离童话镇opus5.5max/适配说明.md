## 二、字体：按这一版的实际用字重做子集

2D 版那套子集是按 2D 工程的字表做的（419 字）。这一版扫出来 **887 个字符**，其中
**476 字不在旧子集里**——直接沿用会让这些字回落到系统字体，字形风格会突然变。

但**上屏的字**（`src/mv/*.ts` 里的 `txt()` / 字卡 / 字幕，去掉注释和界面文案）只有
**238 个汉字，旧子集全覆盖**，所以正在跑的出片渲染没有字体问题。多出来的是
`App.tsx` 的界面文案（「准备就绪」「背景音效（M 键）」「混音导出中…」等）——那些字在
`?capture` 模式下不显示，但用户正常播放时会看到，所以还是把这版子集补全。

| 目标文件 | 源字体（SIL OFL） | 字数 | 体积 |
|---|---|---|---|
| `brush0.woff2` | Ma Shan Zheng 400 | 886/887 | 342,592 B |
| `cute0.woff2` | ZCOOL KuaiLe 400 | 887/887 | 90,436 B |
| `hei0.woff2` | ZCOOL QingKe HuangYou 400 | 886/887 | 127,612 B |
| `serif0.woff2` | Noto Serif SC 400 | 887/887 | 154,460 B |
| `{brush,cute,hei,serif}1.woff2` | 同上，拉丁补充（ASCII + 常用标点） | 121–273 | 4,952–20,276 B |

合计 764 KB。唯一的缺字是「·」（U+00B7）在 brush / hei 里没有——上游 Ma Shan Zheng 和
ZCOOL QingKe HuangYou 本身就不含这个点，2D 版也一样。

**做法**：`raw.githubusercontent.com` 不在沙箱放行列表里，拿不到上游完整 TTF，于是从
npm 的 `@fontsource/*` 取 —— 5.x 把汉字切成 90 多个 `unicode-range` 分片，每个分片
都是结构完整的字体。脚本按目标字符集挑分片、`fontTools.subset` 出每片需要的字，
再用 `fontTools.merge` 合并，最后 `pyftsubset --flavor=woff2`。第一次跑踩了个坑：
所有分片的临时文件都写同一个 `tmp.ttf`，30 个 part 全成了最后一个分片的内容，
合并后只剩 1 个字形；改成唯一文件名后正常。

## 三、出片

### 1. 构建

```bash
cd 番外MV/逃离童话镇opus5.5max
npm install                       # 干净安装，three 要 ^0.187（根目录那份是 0.170）
npx tsc --noEmit && npx vite build
# dist/index.html 15.6 MB（图集 + 音轨全 base64 内联）
```

`vite.config.ts` 不用改：出片走本地静态服务器 + 无头 Chromium，不需要对外暴露 Host。

### 2. 音轨：不能用 song.mp3，要用页面自己的混音

这个工程有一条音效轨，播放时由 WebAudio 把歌和音效实时混音（`audio.ts`：
`SONG_LEVEL = 0.9` + `SFX_LEVEL = 0.62` → 限幅 -2 dB）。导出静帧时那段代码不参与，
直接拿 `song.mp3` 当音轨会把铃、盖章、彩带、烟花全丢掉。

页面暴露了 `window.__mv.mixdown()`（播放界面的「下载混音音轨」用的就是它），
新增工具把它抓下来：

```bash
node tools/grab_vite_mv_audio.mjs --dist 番外MV/逃离童话镇opus5.5max/dist \
     --out /tmp/etz55_audio.wav
# MIX_OK 19,668,644 B · 111.5 s · 44.1 kHz 立体声，淡出已在页面侧做好
```

抓下来校验过：和纯 `song.mp3` 的互相关峰值 0.896（6 ms 偏移内），差异主要来自音效轨；
削波样本 47 个（不到百万分之五），没有破音。

### 3. 逐帧

```bash
node tools/shoot_vite_mv.mjs \
  --dist 番外MV/逃离童话镇opus5.5max/dist --out /tmp/etz55_frames \
  --dur 111.5 --fps 30 --w 1280 --h 720 --format png \
  --query capture --hide ".mv-grain"
# SHOT_OK 3345 帧，约 19 分钟（2.6–3.1 fps）
```

`--hide ".mv-grain"` 和 2D 版是同一个原因、同一层 CSS：`mix-blend-mode: overlay` +
SVG `feTurbulence` + `inset: -20%` + `steps()` 动画，软件渲染下每帧要重新栅格化整块
混合层。2D 版实测摘掉后 25.8 s/帧 → 0.49 s/帧。颗粒在编码侧用 `--grain 4` 补回
（原 grain 只有 `opacity: .09`，与原画面的平均差约 1，`noise=alls=4` 等强）。

### 4. 编码

```bash
.venv/bin/python tools/encode_frames.py \
  --frames /tmp/etz55_frames --audio /tmp/etz55_audio.wav \
  --out 番外MV/逃离童话镇opus5.5max/成片/逃离童话镇opus5.5max.mp4 \
  --fps 30 --crf 21 --maxrate 3200k --grain 4
# ENCODE_OK 39.4 MB
```

注意这里**不加** `--afade-out`：2D 版的淡出是页面的 `audio.volume` 做的，导出静帧后
失效，才需要在 ffmpeg 侧补；这一版的淡出在 `mixdown()` 里（`master.gain` 从 104.2
线性降到 111.0 的 0.0001），抓下来的音轨已经带淡出。
