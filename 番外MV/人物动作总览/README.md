# 人物动作总览（无声样片）

> 2026-11-21。八位角色的**全部高清派生动作**一次看完：一人一镜，一句一个动作，16:9 / 1920×1080 / 30fps。
> 没有音源（`film.json` 里没有 `audio`），按 AGENTS.md 只出**无声样片**，不是成片。

## 看什么

- 每个角色一个镜头：远景（全身、脚底基线、跳起离地、影子）一路推到近景（脸、头发、裙摆、描边）。
- 2 倍高清素材接进引擎之后的效果：和 1 倍图集的对照在同一帧上就能看出来（同姿势下脸、蕾丝、裙摆的像素块密度差一倍）。
- 动作表来自 `通用模板/engine/assets/cast_actions.json`；这一版用到的 71 个动作全部在表里，缺一个开渲前就报（`角色预检`）。

## 片子怎么来的

```bash
npm run film -- info  番外MV/人物动作总览      # 时间轴 + 角色预检 + 文字预检
npm run film -- sheet 番外MV/人物动作总览 --shot G_whale
npm run film -- stills 番外MV/人物动作总览 400
npm run film -- full  番外MV/人物动作总览      # 无声样片 → 成片/人物动作总览_无声样片.mp4
```

- 台词在 `台词.txt`（一行一个动作），卡点在 `cues.json`（`plan` 生成，每句 2 秒，`measured=false`）。
- 镜头在 `shots/shots.ts`：三个棚（动作棚 / 节奏棚 / 夜戏棚），名牌是 Canvas 画的模板字体。
- 动作起点读 `cues.json` 的句子开头，不写死秒数——改一句时长，动作跟着走。
