# 适配说明：这个包放进仓库时动了哪几处

原包（`浪人琵琶fable5.2high.zip`）是自带 Vite 源码的独立工程，说明见 `remade.md`、`README.md`。
进仓库时为了能在本机跑起来，只动了下面五处，**画面代码一行没改**：

| 处 | 原样 | 现在 | 为什么 |
| --- | --- | --- | --- |
| 目录 | `番外MV/浪人琵琶/` | `番外MV/浪人琵琶_fable5.2/` | `番外MV/浪人琵琶/` 已经被模板线（Remotion）那一版占着，两份同名会互相覆盖；这一版是 Canvas2D 单页、另一套出片链路，所以并列放 |
| 字体 | `src/assets/brush.woff2` | `src/assets/brush.ttf`（`App.tsx` 的 import 改后缀） | 包里没带 `MVBrush` 那个 woff2；本机也没有中文字库。用仓库自带的 OFL 字体 `通用模板/engine/assets/fonts/ZCOOLKuaiLe-Regular.ttf` 顶上，字形比手写体方一点，但字是全的（歌词、匾、木牌都正常出字）。想换回原字体：把 `MaShanZheng-Regular.ttf` 转成 woff2 放回 `src/assets/brush.woff2`，把 `App.tsx` 那行改回 `.woff2` 即可 |
| 交付区压缩包 | `src/assets/delivery.zip?url` | 空壳 zip（里面只有一行说明） | 原包没带上要下载的那个 zip；页面上的下载按钮不为它报错 |
| 交付说明路径 | `src/Delivery.tsx` 里 `../delivery/remade.md` | `../../remade.md` | 说明文件放到了作品根目录，不再单开 `delivery/` |
| 素材 | 构建前由 `scripts/link-assets.mjs` 从仓库根取 | 同左（未改） | 取 `人物/atlas.png`（校验 `sha256` 前缀 `5f9894b6ad38`）与 `大肥鱼翻唱《浪人琵琶》.mp3` → `src/assets/{atlas.png,bgm.mp3}`，两者不入库 |

## 出片

```bash
cd 番外MV/浪人琵琶_fable5.2/源码 && node scripts/link-assets.mjs && npx vite build
node tools/shoot_vite_mv.mjs --dist 番外MV/浪人琵琶_fable5.2/源码/dist \
  --out /tmp/frames_lrpp_full --dur 172.9 --fps 30 --w 1280 --h 720
python3 tools/encode_frames.py --frames /tmp/frames_lrpp_full \
  --audio "大肥鱼翻唱《浪人琵琶》.mp3" --out 番外MV/浪人琵琶_fable5.2/成片/浪人琵琶_fable5.2.mp4 \
  --crf 21 --maxrate 3200k
```

`src/assets/atlas.png|bgm.mp3|brush.ttf|delivery.zip` 与 `dist/`、`node_modules/` 都不入库（`.gitignore`）。
