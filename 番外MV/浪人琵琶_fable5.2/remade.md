## 2. 歌词核对：和给的歌词有两处对不上

做法：用 faster-whisper（small 模型，字级时间戳）识别音轨，再按原词逐句对齐。三遍副歌的句间隔互相对过，
误差在 ±0.15 秒内。结论：

| # | 现象 | 怎么处理的 |
| --- | --- | --- |
| 一 | 音轨里「官人进来坐坐 好吗」后面**多唱一句**「我的思念 似六月里的小雨哗哗」（66.7 秒、133.5 秒各一次）。给的歌词里没有这句；查了原曲歌词，是有的。 | 补进歌词表，各配一镜（s17、s29）。不补的话这两段各有六秒画面没有词。 |
| 二 | 结尾四句「我化成风 不舍一帘美梦 / 醉醒穿梭 终究是一场空 / 若非是你 今生又怎会懂 / 浪人回头 心动则心痛」**这版翻唱没有唱**：最后一句「早已经不想回家」唱到 171.3 秒，全曲 172.9 秒就结束了。 | 没有硬塞到片尾，也没有冒充演唱字幕。放在 104.7–120.4 秒的**间奏**里，写成画上的四句**题跋**：朱色字、带「题跋」朱印，`歌词.srt` 和 `lyrics.ts` 里都标了 `sung=false`。四句的时间是按小节（约 3.42 秒一句）排的，不是实测人声。 |

实测结构：

| 段 | 时间（秒） | 句数 |
| --- | --- | --- |
| 副歌一 | 0.0 – 24.5 | 7 |
| 主歌（凝眸 / 独酌） | 26.6 – 51.6 | 6 |
| 浪人段一 | 53.5 – 78.1 | 5 |
| 副歌二 | 79.5 – 104.7 | 7 |
| 间奏（题跋四句，未唱） | 104.7 – 120.4 | 4 |
| 浪人段二 | 120.4 – 144.7 | 5 |
| 副歌三 | 146.2 – 171.3 | 7 |

**卡点的可信度**：这是机器识别出来的字级时间，没有人戴着耳机逐句对过。识别对唱腔的误差通常在 0.1–0.2 秒；
歌词条比人声早一点点出现是有意的（提前 0.06 秒）。要改某一句，只改 `src/mv/lyrics.ts` 里那一行的三个数
（起唱 / 后半句起唱 / 收尾），镜头时机都挂在句子上，会跟着走。

## 3. 对这首歌的理解

伞落在你家，是浪人给自己留的一个回去的由头。整首歌只有一个动作：**想回去**。

- 副歌唱了三遍，词一个字没变。画面给三种读法：**第一遍是回忆**（暖色纸本）→ **第二遍是梦回**（雨夜，
  暖色只剩窗里那一小块）→ **第三遍是天亮以后真的回去**（暖色回来了）。
- 「和你有些不搭」落在两件道具上：小克的细瓷茶杯，本鲸的大蓝饭盆。第一遍并排摆着；第二遍一个在屋里冒热气、
  一个在路边接雨；第三遍花茶直接泡在了饭盆里。
- 「牵挂」画成一根朱线，出现四次：从心口抽出来 → 牵向来路 → 横过整片夜色连到那扇窗 → 最后很短，松松垂在两人之间。
- 「断了弦的琵琶」：第一次断一根，第二次只剩一根，弹的人还在弹。
- 「六月里的小雨」：第一次是真下雨，她没有伞（伞在你家）；第二次外面下的是雪，雨只落在路边一洼水里，水洼映出那扇窗。
- 「两袖清风」：第一次把饭盆翻过来，空的，只掉出一片花瓣；第二次把马留在了酒摊——不再东奔西走了。
- 四句题跋放在间奏，是全片唯一一次把「回去」说破成「一场空」：竹帘分开，屋里其实没有她。这之后她才真的掉头。

## 5. 画面做法

- **画风**：一卷手卷。上下两条磁青底泥金菱格的裱边；白天是暖色宣纸，夜里换成磁青纸、字和光用泥金。
  纸纤维、暗角、远山的水墨晕染都是算出来的。
- **五块布景**（`sets.ts`）：茶舍外景（带圆窗、门、花树、出门的路）、茶舍内景（月洞窗、挂轴、矮茶桌）、
  夜市酒肆「忘归楼」与酒摊、月下河岸拱桥、天涯路。每块都能按 昼 / 晨 / 暮 / 夜 / 雨 / 雪 换色。
- **镜头**：视差分层 + 推拉摇移；对幅（s02）、斜切对幅（s20）、并排两格（s21）、闪切（i2）。
  相邻镜头硬切在句首，只有换场（暖纸→夜、夜→晨）用叠化。
- **歌词**：竖排两列，毛笔字逐字写出来，底下垫一条「签条」保证压在人物上也读得清。
- **逐帧确定**：`render(g, t)` 只读时间 `t`，所有粒子（花瓣、雨、雪、萤火、风）都是时间的确定函数，
  同一个 `t` 永远是同一帧。角色每帧重新摆。缺帧、缺动作直接抛错。
- **道具不画手**：琵琶靠在石头上，酒葫芦、饭盆放在地上或桌上，没有任何「假手」。

## 6. 怎么跑、怎么出片

```bash
cd 番外MV/浪人琵琶/源码
npm install
npx vite           # 浏览器里看（会先自动取图集和音轨）
npx vite build     # 出 dist/index.html（单文件，约 6.4 MB）
```

页面装了截帧钩子，`tools/shoot_vite_mv.mjs` 会自动走最快的那条路（`window.__mv.render(t, clean, width)` 直接回 JPEG）：

```bash
# 在仓库根
node tools/shoot_vite_mv.mjs --dist 番外MV/浪人琵琶/源码/dist --out /tmp/frames_lrpp --still 23.5 --w 1280 --h 720    # 先抽一帧
node tools/shoot_vite_mv.mjs --dist 番外MV/浪人琵琶/源码/dist --out /tmp/frames_lrpp --dur 172.9 --fps 30 --w 1280 --h 720
```

帧序列出来后按 `tools/encode_frames.py` 的用法编码，并把仓库根那支 mp3 混进去。成片目录请叫 `成片/`；
mp4 入不入库要先问（`AGENTS.md` 的规矩）。

钩子一览：`__mv.ready()`、`__mv.render(t, 无字版?, 宽度)`、`__mv.seek(t)`、`__mv.duration`（172.9）、`__mv.fps`（30）、`__seek(t)`。
页面加 `?clean` 只留画面、不显示播放器界面。

## 8. 没做的事、需要人确认的事

这些我没有办法替你确认，写在这里：

1. **没有人整片看过、听过。** 机器查过的只有：全片每 0.1 秒渲一帧（1730 帧）不报错；42 镜首尾相接、盖满 172.9 秒；
   `tsc --noEmit` 零报错；压缩包解进仓库克隆后 `npm install && npx vite build` 通过（只新增 `番外MV/浪人琵琶/`，`git status` 里没有别的改动）。
   我看过的只有静帧：每镜两格的总览图和十几张放大图。声画是否真的对得上、节奏好不好，要人戴耳机从头过一遍。
2. **这不是模板线工程。** 它没有走 `npm run new -- mv`，`cues.json` 也不是 `film.mjs plan / align` 生成的，
   所以 `npm run film -- info / sheet / full` 对它不适用。它和 `情歌_opus5.5max` 是一类：上传的 Vite 单页工程，
   用 `tools/shoot_vite_mv.mjs` 出片。要并进模板线得另做一轮。
3. **`tools/shoot_vite_mv.mjs` 只跑过 `--still`，没有跑过整片。** 把压缩包解进仓库克隆、构建之后，用这个脚本
   （配 `@sparticuz/chromium` 153.0.0 / `puppeteer-core` 25.17.0，和仓库 `package.json` 一致）抽了 15.6、118.9、125.6 秒三帧：
   脚本识别为 `[mode] render`，三帧都正常出图，字体、角色、签条和离线测试一致。**5187 帧的整片截帧、编码、混音都没有跑**，
   所以「音画合在一起对不对」仍然没有机器证据，更没有人看过。
4. **字体是外部素材**：Ma Shan Zheng（马善政毛笔楷书），SIL OFL 1.1，来自 Google Fonts
   （`github.com/google/fonts/tree/main/ofl/mashanzheng`）。只裁了画面用到的 198 个字。它不是模板字体，
   `AGENTS.md`「画面上的字只用模板字体里有的」这一条我**没有守**——模板字体我没有核过是否含「琵琶、眷、腼腆、眸、醺」这些字。
   要换回模板字体：改 `core.ts` 的 `FONT` 和 `App.tsx` 里载字体那一行即可。请把这款字体补记进 `素材许可与来源.md`。
5. **音乐授权**：《浪人琵琶》原曲（词曲 单色凌）与这版翻唱的录音，仓库里都没有授权记录，公开前要自己核。
6. **人物图像的再分发许可**：沿用仓库现状——`README.md` 写的「到现在没有人核过」这件事没有变化。
7. **没有改任何现有文件。** `README.md` 的目录表、`番外MV/设定表.md`、`素材许可与来源.md`、`媒体说明.md` 都没动；
   要登记的话，`设定表_追加.md` 可以直接贴，其余几处各加一行即可。
8. 歌词卡点的方法和误差见第 2 节末尾。
