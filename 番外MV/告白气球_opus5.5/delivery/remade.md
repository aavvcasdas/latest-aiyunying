## 2. 歌词卡点

方法：faster-whisper（small，字级时间戳）识别音轨，按原词逐句对齐；两遍主歌、三遍副歌的句间隔互相校对。

| 段 | 时间（秒） | 句数 |
| --- | --- | --- |
| 前奏 | 0 – 23.9 | — |
| 主歌一 + 副歌一 | 23.96 – 85.6 | 14 |
| 间奏 | 85.6 – 109.4 | — |
| 主歌二 + 副歌二 | 109.42 – 170.8 | 14 |
| 桥段（恋爱日记…搅拌在一起） | 172.0 – 191.8 | 4 |
| 终段（别任性…我愿意） | 193.36 – 205.2 | 2 |
| 尾奏 | 205.2 – 212.98 | — |

**你给的歌词和音轨完全对得上**，没有多唱也没有漏唱。识别糊掉的三处按另一遍同一位置的间隔推算，**不是直接读出来的**：

1. 两遍「花店玫瑰」都被识成「呼火点玫瑰」：按「嘴」字到「花」字的间隔（两遍都是 2.98 秒）定在 34.54 / 119.90。
2. 第二遍「塞纳河畔」被识成「在那好棒」且挤成一团：按第一遍「塞」到「左」的间隔（1.02 秒）倒推，定在 109.42。
3. 第二遍「甜蜜的很轻易」偏移：按第一遍「从」到「甜」的间隔（2.68 秒）定在 156.80；后半句「很」落在 158.78，和识别出的那个字只差 0.02 秒，对上了。

**精度**：只有每句的起唱和后半句起唱是实测，半句里的逐字弹出是均分的。识别对唱腔的误差一般 0.1–0.2 秒，**没有人戴耳机逐句对过**。

## 3. 对这首歌的理解

《告白气球》很轻：一个人追另一个人，追得笨手笨脚，**一点都不怕搞砸**。整首歌的核心是这一句：

> 礼物不需挑最贵，只要香榭的落叶。

落到鲸鱼娘身上刚好。按 `参考资料/项目调研/Agent-Reach研究/` 的归纳（ⓒ 社区归纳 / ⓞ 本系列原创，**都不是厂商事实**）：
她的标签是「便宜、吃白饭」ⓒ，身世一句写着**怕自己只有「便宜」才值得被喜欢**ⓞ。这支片子让她送出去的礼物是一片**不要钱的叶子**——而这就够了。
画面上**不出现任何价格数字**：狐狸举的标价牌只写「最贵」两个字。

主歌唱了两遍、词一个字不变，画面就给两种视角：

| | 第一遍：鲸这边（早上→傍晚→夜） | 第二遍：小克那边（粉色清晨→傍晚→夜） |
| --- | --- | --- |
| 塞纳河畔 | 她牵着气球走向那张桌子 | 镜头在小克身后，她从书页上沿偷看 |
| 我手一杯 | 鲸从杯沿上偷看她 | 鲸被烫到吐舌头，小克在书后面笑 |
| 留下唇印 | 鲸看见杯沿的唇印，愣住 | 小克发现鲸在盯她的杯子，也脸红了 |
| 名字写错谁 | 千问把卡片写成「致小可」，鲸没看就跑 | 小克看了一眼，没说话，**自己把「小可」改成「小克」**——先听完，再改一个字ⓞ |
| 风吹到对街 | 龙影掠过，气球脱手飞走 | 气球飞到她这边，**她跳起来接住了** |
| 你说你有点难追 | 她书挡着脸走开，回头摇头 | 她嘴上说难追，**脚下越走越慢**，回头等鲸跟上 |

| 不害怕搞砸一切 | 桌子歪了、咖啡洒了 | 她笑得直不起腰，掏手帕给鲸擦 |

「你的眼睛在说我愿意」——**她的眼睛从第一遍就在说了**，第二遍只是让观众看见。

桥段收成三件道具：Kimi 的**恋爱日记**（咖啡杯、改过名的卡片、气球、落叶一格格贴上去）→ 一只**香水瓶**飘出回忆 → 瓶里装满了梦，「全都有你」时浮起好多个小克 → 回到第一镜那杯咖啡，俯视，**搅拌在一起**转出一颗心。
终段回到早上的咖啡馆，大家都在；两个人一起松手，告白气球飞上天，片名落款。

## 5. 画面做法

- **画风**：水彩明信片。五种时段（早上 / 正午 / 傍晚 / 夜 / 粉色清晨），角色在傍晚和夜里按时段罩色。
- **布景**（`paris.ts`）：左岸咖啡馆 + 对街花店（含马路）、塞纳河岸（石桥、梧桐、旧书摊绿箱）、香榭大道（两排梧桐收向凯旋门）。远景是一排巴黎屋顶和铁塔剪影，夜里铁塔整点闪灯。
- **镜头**：视差分层 + 推拉摇移；一句一镜，镜内在后半句起唱处再切（如「名字写错谁」切卡片、「你的眼睛」切头像特写）。换场（前奏→间奏、间奏首）用叠化。
- **歌词条**：下三分之一一条圆角签条，逐字弹出；夜景换深色底、金色字。
- **逐帧确定**：`render(g, t)` 只读时间；花瓣、落叶、星星、心形泡泡都是时间的确定函数。缺帧、缺动作直接抛错——这次就抓到两处：图集里**小克没有「吃惊」**、镜头首尾有 0.02 秒没接上，都已改掉。
- **道具不画手**：气球的绳子垂到手边、花束和卡片放在桌上或悬空，不画任何假手。

## 6. 怎么跑、怎么出片

```bash
cd 番外MV/告白气球/源码
npm install
npm run dev        # 预览（先自动取图集和音轨）
npm run build      # dist/index.html 单文件
# 仓库根
node tools/shoot_vite_mv.mjs --dist 番外MV/告白气球/源码/dist --out /tmp/frames_gbqq --still 113 --w 1280 --h 720
node tools/shoot_vite_mv.mjs --dist 番外MV/告白气球/源码/dist --out /tmp/frames_gbqq --dur 212.98 --fps 30 --w 1280 --h 720
python3 tools/encode_frames.py --frames /tmp/frames_gbqq --audio 告白气球-周二珂.mp3 --out 番外MV/告白气球/成片/告白气球.mp4 --fps 30
```

钩子：`__mv.render(t, 无字版?, 宽度)` 直接回 JPEG；`__mv.ready()`、`__mv.seek(t)`、`__mv.duration`（212.98）、`__seek(t)`。页面加 `?clean` 只留画面。
