## 为什么是本鲸

这里的「没有天赋」是角色比较自己时的感受，不是给现实模型下的能力结论。项目设定中，工坊向访客开放，本鲸担心大家只因便宜才会来找她。这种「我是不是可以被替换」的不安，比把其他 AI 写成反派更贴近歌词。

「热忱与自卑」可以并存：愿意重画图纸，就是热忱；画完又藏起来，就是自卑。「名垂青史」不是虚荣的笑话，而是希望投入的时间能留下痕迹。到最后，「一朵小小的花」也不是突然逆袭成功，而是终于允许一件没有掌声的事有价值。

## 声音与逐字对齐

参考视频是 640 × 360、15 fps、约 152.13 秒的 H.264 文件；音频为 48 kHz 单声道 AAC。实际抽取方法：

```sh
ffmpeg -i reference.mp4 -map 0:a:0 -c:a copy public/media/film-audio.m4a
ffmpeg -i reference.mp4 -map 0:a:0 -ac 1 -ar 16000 -f f32le audio.f32
```

原视频和提取音轨解码后的 PCM SHA-256 相同：`af2d3fd90b88eb9d6707a6df85975e98b6aaa072827d3b915895a7bf2643d68f`。另保存用户指定的同分支 MP3，仅用于不支持 AAC 的浏览器回退。没有合成新的人声或替换 BGM。

参考视频的文字属于画内动效，不是独立字幕流。使用用户提供的文本作为歌词底稿，并对原片抽帧核对段落，未把 OCR 或语音识别猜测冒充准确歌词。

`tools/align.py` 对实际人声执行中文 CTC 强制对齐，而不是把一行的时长平均分配给每个字。模型为 [parseh/aligner-zh](https://huggingface.co/parseh/aligner-zh)，来源为中文 wav2vec2 XLSR 模型。使用 16 kHz 波形、20 ms 帧距、带重叠上下文的分段推理，并在全曲上做单调 Viterbi 回溯。音节入场预留约 40 ms 的视觉提前量。模型文件只用于离线制作，不随网站分发。

```sh
python -m pip install numpy scipy onnxruntime pypinyin
python tools/align.py /path/to/aligner-model audio.f32
```

模型目录包含 `model.onnx`（上游 `model.int8.onnx`）与 `vocab.json`。输入文本及语义词组见 `src/data/lyrics-source.json`。共有 41 句、358 个字。词组起点取组内第一个字的实测对齐时间，保留乐句间的空白与间奏。

逐字模式将每个字从有深度的局部平面投影到镜头上，依照起音旋入、收束，叠加侧面形成厚度；整词模式共享词首入场点，发声字仍独立着色。镜头进度和字符进度都取同一条音轨的 `currentTime`，拖动和改速不需要重启字幕定时器。

## 来源与使用边界

- 角色：分支 `番外MV/情歌_opus5.5max-gpt6max开头/源码/src/assets/atlas.png` 和对应的 `mv/generated.ts`。本地角色动画仅重新排版为无损 WebP 条带，没有另造像素人物。
- 原创叙事涉及的八位角色均有真实分支素材。没有为缺少图集格的 Grok 临时替换别人的形象。
- 角色性格属于社区与本系列创作设定，不是官方设定。没有把额度刷新写成失忆，没有引入未经核验的模型价格或能力排名。
- 标题使用 Ma Shan Zheng，界面与歌词分别使用 Noto Sans CJK SC、Noto Serif CJK SC 子集。OFL 字体许可保存在 `public/fonts/licenses/`。
- 音乐和角色并无已核实的公开传播或商业授权。本作按用户指定素材制作预览，公开发布前需另行核实权利。

自动检查涵盖文本完整性、逐字时间单调性、章节跳转、字幕开关、词组模式、倍速、音量、全屏、角色出场、片尾重播、本地收藏、移动端宽度和构建。机器对齐不等于人工演唱听校；未声称已逐字人工验收，也未推送或发布到上游仓库。
