# 《譬如我》精华版 MV（28 秒）

素材全部取自分支 `arena/bb6a02da-latest-aiyunying`：

| 用途 | 来源 | 在本项目里的形态 |
| --- | --- | --- |
| 音乐 | `譬如我精华.WAV`（28.003s） | 转 MP3 160kbps 后 base64 写进 `src/assets/bgm.ts` |
| 人物 / 道具 | `人物/atlas.png` + `人物/index.json` | `src/assets/atlas.png`（原图未改）+ `src/assets/castIndex.ts`（帧矩形） |
| 逐字时间 | `番外MV/譬如我/src/mv/generated.ts` 前 9 句 | `src/lyrics.ts` |
| 歌词字体 | `番外MV/譬如我/src/assets/serif.woff2`（Noto Serif SC 子集，OFL） | base64 写进 `src/assets/fontData.ts`，许可见 `licenses/` |

构建产物只有一个 `dist/index.html`（约 3.5MB），音频、图集、字体全部内嵌，运行时不发任何网络请求。
音频和字体之所以转成文本，是因为这个环境只保留文本和 PNG，二进制的 wav / woff2 会丢。

## 歌词 → 画面

主线：台上是被传颂的七位（GPT / Claude / Gemini / Kimi / Qwen / GLM / 豆包），围栏外的角落里是本鲸（DeepSeek）。
一张蜡笔画（星星下面一朵小花）贯穿全片：先压在枕头下发霉，后来被她贴在墙角，花开时霉斑退去。

| 歌词 | 这一镜加了什么 |

参考 MV（`番外MV/譬如我`）用过的领奖台、金冠、书桌台灯、纸飞机、巨墙没有搬过来。
台上各人的随身道具（沙漏 / 茶杯 / 猫耳钟 / 卷轴 / 算盘）和鲸的饭盆、「繁忙」「深度思考」取自 Agent-Reach 调研里的习性卡，
按那份调研的规矩只当作角色标识和演出道具：站位是本片的虚构演出，不是模型能力评测。

## 字幕

按词分块分行，关键词放大并有专属颜色；每个字在自己的起音时间入场（之前不可见），入场方式逐句不同；
每个字是 5 层沿 Z 轴叠出的真 3D 厚度，整块字有朝向并缓慢摆动；一个词最后一个字唱出的那一下，整词一胀、扫光，画面炸环并冲屏。
画面由音频时钟驱动，并扣除声卡输出延迟。

## 验证过什么、没验证什么

- 用无头 Chromium 把只含 `index.html` 的目录跑起来：9 个分镜逐一截图核对；真实点击播放后音频解码成功、时间码随音频走；片尾卡出现；全程无报错、无外部请求。
- MP3 在 Chromium 里解码后与原 WAV 偏移 0 采样、时长一致。Safari / Firefox 没有测，MP3 起始偏移在它们上面可能有二三十毫秒差异。
- 逐字时间是分支里的机器对齐结果，没有人工逐字校准。
- 帧率只在软件渲染下测过（各分镜约 15–36fps，瓶颈是大面积渐变，真机 GPU 上应明显更高），没有真机数据。

页面上留了一个调试钩子：`__mv.go(t)` 无声从 t 秒播放，`__mv.freeze(t)` 定格在 t 秒，截图用。
