# 《譬如我》原版细节调整

本版以用户提供的原版为基础，保留 three.js 场景、分支像素人物、原曲和逐字立体字幕。没有生成或接入新的图片；新增的纸张、花、冠和名牌均由代码绘制。

## 画面与人物

- 暗部使用柔和的层次映射和较弱的暗角，让原有颜色与人物轮廓更容易辨认。没有增加新的聚光灯，并降低原场景中过强的泛光。
- 「枕头下发霉的梦」增加带霉点的花朵草稿；「还是想坚持」让纸飞机从书桌飞起；「某个角落」的种子纸与后来的花朵相呼应；「改写命运的诗」增加纸页轮廓。
- 保留原有稿纸、沙漏、笑容、花田、巨鲸与镜头运动。调整「平庸二字」字卡位置和入场放大幅度，减少字被画面边缘切掉的情况。
- 领奖台中央最高的位置属于小克，旁边第二席属于龙娘；小克的金冠、座位名牌与人物介绍保持一致。这是本片的虚构设定，不是模型能力评测。
- 播放前显示由原版场景实时渲染的片名画面，而不是黑帧。音轨载入失败时显示错误，不悄悄播放无声版本。

## MP4 导出

页面右上角的「导出 MP4」会在本机以 1280×720、24 FPS 逐帧渲染完整影片，再把原曲合成为 H.264/AAC MP4。视频使用点击导出时的字幕开关，音轨不受网页音量或静音设置影响。编码时可以取消；完成后自动下载，也可点击「再次保存 MP4」。

导出由 WebCodecs 和 Mediabunny 完成；没有原生 AAC 编码器时使用其 WASM AAC 编码器。需要支持 H.264 编码的浏览器，不支持时会提示换用新版 Chrome、Edge 或 Safari。导出用时取决于设备性能，期间请保持页面打开。
