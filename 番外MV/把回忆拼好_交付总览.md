## 封面模板改了什么

`tools/cover.py` 现在的产物只有两层：**剧照 + 片名**。

- 片名固定压在底部的一条暗带上（3 点深色描边 + 模糊投影），不再压在角色脸上；
- 竖版 3:4 用「剧照自身镜像铺满 + 重糊当底」，接缝处像素连续，不会出现色差硬边；
- 模板里**没有任何**画角标 / 账号名 / 平台名 / 二维码的代码——想加也没地方加；
- 配套 `tools/shoot_cover.mjs` 负责出「干净帧」（页面钩子 `__mv.cover(t)` / `__mvCover(t)` 会把歌词条关掉）。

```bash
python3 tools/cover.py --still <干净帧.jpg> --title 把回忆拼好给你 \
    --out 番外MV/<作品>/封面 --name <作品名>
```
