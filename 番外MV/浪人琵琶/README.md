# 《浪人琵琶》（大肥鱼翻唱版）MV

一句词一个镜头：**41 句 / 44 镜 / 2 分 52.9 秒**。本鲸演浪人，千问演那位「美眷」，其余六位各演镇上的一个人。
按 [`../童话镇/`](../童话镇/) 的做法写：three.js 积木搭景 + 图集里的像素纸片人 + 歌词卡在实测拍点上。**没有新增任何生图**：角色全部来自 `人物/` 图集；花伞、琵琶、酒壶、马、灯笼、牌匾全是引擎体块现搭的。

> 谁演谁、为什么：第 2 节。每一镜画什么：[`分镜脚本.md`](分镜脚本.md)（由镜头源码的 `note` 与实测时间轴生成）。

## 2. 这支 MV 里谁是谁

母题：浪人把花伞落在了一户人家，这把伞成了她唯一「想回去」的理由。全片三遍副歌，画面各不一样：第一遍是**回忆**（那个下午的花茶），第二遍是**另一边**（千问夜里发现门边的伞），第三遍是**回家**（两个人在一把伞下走回去）。

| 谁 | 演的形象 | 兑现她哪条习性 | 落成的动作 / 画面 | 不许写成 |
|---|---|---|---|---|
| `whale` 本鲸 | **浪人 / 小生**（唱这首歌的人就是她） | 「怕自己只有便宜才值得被喜欢」——歌里的「和你有些不搭」「两袖清风」就是这句话 | 带着饭盆去喝花茶（C03）；微醺爬不上马（C14）；雨里抖袖子什么都没有（C20 / C34）；最后在院门口挥手（C41） | 不演成可怜人：她路过醉花楼是自己选的，不进去也不是被拒 |
| `qwen` 千问 | **美眷「你」**：中式衣裙、宽袖、折扇、花茶的主人 | 「先排哪一步，再动手」——她先把茶盏推过去、把点心推过去，话一句不说（C03 / C25）；茶会戏的东道主 | 腼腆一笑 = 抬扇掩面一躬（C05）；拂袖 = 转身卷起花瓣（C10）；夜里发现伞，撑开，走出门去找人（C21–C27） | 不写成只会古风辞藻的大小姐；不撒钱、不代付 |
| `kimi` Kimi | **桥上弹琵琶的另一位浪人** | 「先把漏掉的旧句找回来」——她把**断掉的那根弦接回去**，掉下去的那个音才飘上来（C29） | 坐在桥心灯下弹（C15 / N1），第二遍停下来接弦 | 不靠堆书页显聪明；接弦是她的分寸，不是炫技 |
| `doubao` 豆包 | **醉花楼门口招呼客人的姑娘** | 「暖场的人」——踩着拍子揽客（C16），第二遍开门是好心让人躲雨（C31） | 欠身一句「官人进来坐坐好吗」，被摆手后耸肩回去踩拍 | 不做任何暧昧特写；醉花楼只画红灯笼和门，不进去 |
| `gpt` 龙娘 | **酒馆掌柜** | 「先接住乱局」——送酒、打烊按灯、把爬不上马的本鲸劝下来（C11 / C13 / C14）；屋顶漏雨先摆碗（N2） | 飘过来放下酒壶点个头；一盏盏按灭灯笼 | 不是反派；不替本鲸做决定 |

## 3. 卡点是怎么对的（时间只认实测）

音频是 2:52.9 的翻唱，**没有原曲的 LRC 可以照抄**，这份 `歌词.srt` 的时间是这样来的：

1. **结构**：对翻唱音频做小节级自相似分析（22.05 kHz，按拍切块、色度 + 频带特征），得到 52 小节 = 副歌 8 + 主歌 8 + 预副歌 8 + 副歌 8 + 间奏 4 + 预副歌 8 + 副歌 8，与胡66 原版（单色凌词曲）逐段对得上——翻唱**砍掉了原版的前奏与尾奏**，其余不变。
2. **拍点**：用仓库自带的 `align_beats.py` 实测，拍长 0.41668 秒（144 BPM 的八分 = 72 BPM），分窗相位漂移 ≤ 0.002 秒，全程稳定。
3. **每句起点**：按人声居中的特点算 side/mid 能量比（唱着的时候 ≈ 0.01–0.05，纯伴奏 ≈ 0.1–0.3），找每句开口的位置，再和原版 LRC 的句内相对位置互相印证；三遍副歌同一句的开口位置彼此相差 ≤ 0.03 秒。
4. `npm run film -- align` 把 41 句起点吸附到最近的实拍（平均移动 0.095 秒，最大 0.199 秒）。

**和用户给的歌词文本有两处不同，以音频为准**：

- 「我的思念似六月里的小雨哗哗」**音频里唱了**（两遍预副歌各一次，各占两小节：66.9–72.7 秒、133.6–139.4 秒），用户给的文本里没有这句，已补回。
- 「我化成风 … 浪人回头 心动则心痛」四句尾声**音频里没有**：翻唱在第三遍副歌「早已经不想回家」落下后 0.3 秒就结束了（172.9 秒）。最后一镜（C41）把「浪人回头」的意思做进了画面——她已经在家门口了——但没有这四句字幕。要是以后换成带尾奏的音源，加四个 OUT 镜头、重跑 `align` 即可。

## 4. 复现

```bash
npm ci && pip install --user numpy pillow
npm run film -- align  番外MV/浪人琵琶      # 实测拍点 → cues.json（结果应与仓库里的一致）
npm run film -- info   番外MV/浪人琵琶      # 时间轴 + 角色预检 + 文字预检
npm run film -- sheet  番外MV/浪人琵琶      # 分镜总览图
npm run film -- full   番外MV/浪人琵琶      # 逐帧渲染 → 编码 → 混音 → 自检（2 核软件渲染约 35–45 分钟）
```

## 5. 机器查过的 / 人看过的 / 没做的

- **机器查过**：`npm run typecheck` 通过；`info` 的**角色预检通过**（44 镜 / 5187 帧逐帧走过，8 个角色用到 295 格精灵，顺着走、倒着走结果一致）、**文字预检通过**（77 处、144 个不同的字，模板字体里都有）；`align` 实测卡点 `measured: true`。
- **人看过**：用 `stills` 抽了 14 帧（C01、C03、C10、C11、C15、C18、C22、C29、C33、C35、C41 等）看构图，据此改了四处：桥面高度（Kimi 原先被桥板吞掉）、C01 / C41 / C29 的机位（人被画框切掉、琵琶糊住半个画面）。**没有人从头到尾连续看过、听过**。
- **没做的**：没有出成片（沙盒里渲 5187 帧要 40 分钟上下，留给有机器的人跑 `full`）；没有逐音节对齐（拍点级）；没有封面与发布文案；原曲著作权与角色形象的再分发许可没有核（见仓库根目录 README）。
- **写镜头时踩到的一个坑，记下来给下一支**：`kit.ts` 的 `basic()` / `toon()` 材质**按颜色全局缓存**，镜头里直接改它的颜色或透明度，会把别的镜头里同色的东西一起改掉——角色预检会报「顺着走、倒着走不一样」。所以 `common.ts` 自己写了 `lamp()`（灯笼球体独享材质），`ghost()` 先 `clone()` 材质再调透明。
