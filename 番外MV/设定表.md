# MV 线设定表（速查）

**这条线的设定和 Day 线不是一套。** Day 是这间房里的日常口播；MV 是「这个人在这首歌里演谁」——性格还是那套，但**形象跟着每支 MV 换**。

**一人一页的完整设定在 [`设定/人物/`](../设定/人物/)**（索引 [`设定/README.md`](../设定/README.md)），共用的规矩在 [`设定/AI娘设定总纲.md`](../设定/AI娘设定总纲.md)；九位人物一张汇总表（习性 / 道具 / 关系 / 台词 / 身世 / MV 用法 / 边界）在 [`人物设定.md`](人物设定.md)。这张表只做一件事：**把习性对到每支 MV 的形象上**。
造型格、头像格的编号见 [`通用模板/README.md`](../通用模板/README.md) 的「九位角色与可用造型」；这里只管人。
Grok 2026-11-11 才补上造型格，本表里的两支 MV（童话镇、坏女孩）都没有她的位置；要用她，先在第 4 节那张空表里给她填一个形象。

**参照哪一支片子**：只有一支——[`童话镇/README.md`](童话镇/README.md)。新 MV 的空间做法、切镜节奏、卡点写法都照它看；别的片子（包括《坏女孩》两版）是自己走过的路，不当参照。

## 0. 开拍前问三句

1. **她在这支 MV 里是谁？**（形象，一句话能说清，不是「一个路人」）
2. **这个形象兑现她哪一条习性？**（对不上就别派给她，换人或者换形象）
3. **这条习性落成哪个动作？**（观众要靠动作看出来，不能靠旁白、不能靠字卡解释）

四条硬规矩：

- **一支 MV 一个人只演一个形象**，中途不换身份；群像里的人只能做自己的招牌动作，不许抢主角的定型动作。
- **性格靠动作兑现。** 去掉那行字，观众还该看得出这是她。
- **歌里的感情戏不回写进 Day。** 《坏女孩》里本鲸和小克是剧情，不是正史 CP；反过来也一样。
- **每支新 MV 先填第 4 节那张空表**，再去写 `shots/`；不填就写，等于在镜头里现编性格。

## 1. 《童话镇》（立体童话书 · 31 句歌词 · 40 镜）

母题：谁都读过这些童话，但书页会翻，人会走。本鲸在这支里是**旁观者兼讲述者的那条河水**，只有在她的段子里才自己上岸。

| 谁 | 演的形象（出现处） | 兑现她哪条习性 | 落成的动作 / 画面 | 不许写成 |
| --- | --- | --- | --- | --- |
| `whale` 本鲸 | **河水**（序章折纸船、「只有睿智的河水知道」）→ **丑小鸭**（「丑小鸭会变成白天鹅」）→ **小人鱼 / 泡沫**（「小人鱼在眺望金殿堂」、「把阳光抹成眼影」、「投进泡沫的怀抱」） | 先问哪条不能改，再筛；旁观、把话递出去 | 河水：折纸船离岸、水花扬起、只在两侧看着不进画面中央。丑小鸭：一闪变成另一个自己。小人鱼：站岸边望向金殿堂、仰头把阳光抹在眼皮上、最后化成泡沫升成星星 | 不是公主；不在别人的段子里抢中心位；泡沫不等于死亡，也不给「被救回来」的暗示 |
| `claude` 小克 | **白雪公主**（「白雪公主在逃跑」、「白雪是因为贪玩跑出了城堡」）→ **睡美人**（「睡美人被埋葬」、「睡美人逃避了生活的煎熬」） | 先听完再改一个字；怕做错，所以宁可先不动 | 白雪：提裙跑、回头、被追到城堡边才停。睡美人：躺下不动、宫殿长满藤、最后自己睁眼。**两段都是「她自己选的退场」，不演成受害** | 不做等待被吻的对象；不哭喊；不把「被埋葬」演成死亡特写 |
| `gpt` 龙娘 | **龙影**（序章掠过的龙影、「小红帽在担心大灰狼」）→ **金乌**（「阿波罗变成金乌」）→ 与侏儒怪对峙 | 先接住乱局，只问一个会改变做法的问题；也会失手 | 龙影：只从画面上方掠过，不进画面。金乌：一轮太阳压满天空，光把全场烤白。对峙：她挡住侏儒怪的路 | 不做最终反派；不真的伤害小红帽；不许演成「重置一下就变强」 |
| `gemini` 猫 | **爱丽丝**（「疯帽喜欢爱丽丝」）→ **糖果屋**（「森林里有糖果屋」）→ **匹诺曹**（「匹诺曹总说着谎」） | 先给两个看法，最后必须选一个 | 爱丽丝：在两条路的路口来回看，最后迈出一条。糖果屋：先伸手又缩回。匹诺曹：鼻子长一截，最后自己按住 | 不一次抛一堆支线把歌讲散；说谎那段必须让鼻子「停」一次 |
| `kimi` Kimi | **灰姑娘**（「灰姑娘丢了心爱的玻璃鞋」）→ **智者 / 河水**（「只有睿智的河水知道」，与河水并排）→ **长生树**（「悬崖有棵长生树」） | 先把漏掉的旧句找回来，标一句就停 | 灰姑娘：捡起玻璃鞋、举到光下看一眼、放下走开。长生树：在悬崖边站着不动，枝叶记得所有人 | 不靠堆书页显聪明；哭不是她的固定反应 |
| `doubao` 豆包 | **小红帽**（「小红帽在担心大灰狼」、「小红帽有件抑制自己」、「变成狼的大红袍」）→ **红舞鞋**（「红鞋子不知疲倦地在跳舞」） | 先陪着写出开头，再问要不要继续；慢，不催 | 小红帽：提着篮子等、把红袍披上又脱下。红舞鞋：跳个不停，最后有人按下她的脚才停 | 不强制口音；「变狼」是红袍的比喻，不做獠牙特写 |
| `qwen` 千问 | **疯帽子**（「疯帽喜欢爱丽丝」、「沾染魔法的乖张气息」） | 先排哪一步，再动手（这里故意反过来：她把顺序打乱） | 茶会上把杯子倒着排、把椅子推给爱丽丝、在魔气里照旧倒茶 | 不撒钱、不代付；疯不等于吵 |
| `zai` 智谱 | **彼得潘**（「彼得潘总长不大」）→ **杰克**（「杰克他有竖琴和魔法」）→ **侏儒怪**（「侏儒怪拥有宝石满箱」） | 先写完成标准，再做最小的一版；账要算对 | 彼得潘：悬在半空，脚不落地。杰克：用一把竖琴换掉整头牛。侏儒怪：抱着满箱宝石数，被人喊出名字时手停住 | 不拿价格当台词；不为任何厂商编日程 |

**这支的旁白规则**：河水知道一切，但只在「只有睿智的河水知道」那两句开口；其余时候她只是画面里的水。歌手名不上歌词条，片头只留歌名与歌手名两行。

## 2. 《坏女孩》（3D 夜雨 · 鲸鱼娘 × 小克 · Remotion 出片）

母题：一个人为了被留下，把自己染成对方喜欢的样子，最后又褪回原色。这是一支**情歌 MV**，感情戏只在这支里成立。

| 谁 | 演的形象（镜头） | 兑现她哪条习性 | 落成的动作 / 画面 | 不许写成 |
| --- | --- | --- | --- | --- |
| `whale` 本鲸 | **「坏女孩」本人 / 第一主角**：路灯下牵手、「雨不停」里哭、舞池光柱里的洋红剪影、「眼线与指尖」、「镜中人」、「卸下眼线」、「地上的伞」 | 怕自己只有「好用」才被留下 → 这次是「怕自己只有乖才被留下」，于是改颜色 | 洋红剪影先出现、剪影褪去才是她；镜中倒影被染成洋红，再一拍闪回原色；最后卸掉眼线、把伞丢在雨里、走进雾里 | 不演成受害者；不给她加「报复」桥段；她的哭只有一次，别每镜都哭 |
| `claude` 小克 | **说「保重」就走的那个人**：牵手后被拉断的丝带、骑车穿过雨夜、「多余的温柔」里走出伞下、「没有来电」里黑屏的手机、结尾背对背灯灭 | 改完会变成假承诺，就改回去 → 他**不给承诺**，也不解释 | 侧身走开、把伞留给她、走出伞下、背影越走越远；全程不回头给一个明确答案 | 不做坏人；不安排他追回来复合；不给他加独白解释动机 |
| `gpt` 龙娘 | **「陌生的肩」** / 舞池里她靠着的那个 | 先接住乱局，不问原因 | 坐在沙发上让她靠着、举杯；她直起身走开时才发怒 | 不是情敌戏码的赢家；不默认和本鲸是一对 |
| `doubao` 豆包 | **暖场红舞鞋**（间奏 4/4 空酒吧里先跳起来） | 先陪着，把场子热起来 | 空场里第一个踩拍，地砖一格格亮，鼓点进来时闪白切歌 | 不抢副歌；不给她台词 |
| `gemini` 猫 / `qwen` 千问 / `kimi` Kimi / `zai` 智谱 | **酒吧里的路人**：舞池里交替踩拍的那几个、街上撑伞走过的 | 各自一条小习性：猫踩拍乱跳、千问排舞步、Kimi 举着书签、狐狸数地砖 | 只在舞池和街景里做自己的小动作，不做主角的定型动作 | 不合唱、不抢镜、不与主角发生关系；唱词仍只归两位歌手 |

**这支的听觉规则**：两位歌手的音色靠歌词逐字染色的色相区分（小凌偏粉、徐良偏蓝），歌词条上不出现歌手名；片头只留歌名与歌手名。

## 3. 《坏女孩（Fable 版）》（同一首歌 · Canvas2D 软 3D · Remotion 出片）

- **故事、形象、性格全部沿用第 2 节**：本鲸 = 坏女孩，小克 = 走掉的人，豆包 = 暖场，猫 / 千问 / Kimi / 狐狸 = 路人。

## 4. 新 MV 怎么加

**先填这张空表，填不出来就别开拍。**

| 谁 | 在这支里是谁（形象） | 兑现哪条习性 | 一个能拍出来的动作 | 不许写成 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

填完过三条检查：

1. **一镜能认出来吗**：抽一帧给没看过设定的人，她至少能被指认成「那个 XX」，而不是「一个像素人影」。
2. **去掉性格她还这么动吗**：如果换谁来做这个动作都一样，说明这个形象没对到人。
3. **有没有抢主角的定型动作**：翻书、指屏幕、举沙漏、摊卷轴、推算盘，这些是各自的招牌，群像里别互相借。

**形象库（这些形象优先派给谁）**

| 形象 | 优先给 | 理由 |
| --- | --- | --- |
| 公主 / 睡美人 / 白雪 | Claude | 唯一戴金冠的公主；体面、怕出错、会自己退场 |
| 龙 / 大灰狼 / 金乌 | GPT 龙娘 | 威慑与守护是同一件事 |
| 小红帽 / 红舞鞋 | 豆包 | 还愿意先相信别人；陪人、等人 |
| 爱丽丝 / 匹诺曹 / 糖果屋 | Gemini 猫 | 好奇、两条路、说法多 |
| 灰姑娘 / 智者 / 长生树 | Kimi | 记得住旧东西，标一句就停 |
| 疯帽子 / 彼得潘 / 杰克 / 侏儒怪 | 千问、智谱 | 一个排顺序，一个算账；也能故意反过来演 |
| 河水 / 小人鱼 / 丑小鸭 | 本鲸 | 旁观、上岸、还没被认出来 |

## 5. 动作分三层（别用整体缩放冒充动作）

| 层 | 做什么 | 素材 |
| --- | --- | --- |
| 全身 | 平移、倾身、遮罩 | 图集立绘的造型格 |
| 局部 | 眨眼、嘴、发梢、衣摆、鲸尾、龙翼 | 按帧号确定性求值 |
| 关键姿势 | 转身、奔跑、近距离手势 | 补画的关键帧序列 |

**不新增生图、不换画风**：要更多动作，先把像素数据加进 `通用模板/cast/source/`，重建图集，再来写镜头。

## 6. 镜头与节拍

- 前景飘落书页 / 中景人物 / 背景深海或图书馆，做 2.5D 视差（《童话镇》）；夜雨、霓虹、路灯光柱做低机位纵深（《坏女孩》）。
- 用闭眼特写、手与道具的动作连接（饭碗、丝带、玻璃鞋、伞）、逆光轮廓、对拍反打；别每镜都站桩弹跳，别整片靠频谱条。
- 字幕像手写歌词嵌进构图，**不许大字遮住脸**；中文换行手工校。
- 先定音源与字词时间，再标鼓点与情绪转折；卡点由 `align` 实测生成，不手改数字。
- 随机数固定种子；实时循环或物理模拟不能按指定帧重现的，先导出确定性序列再合成。

## 7. 红线（两条线同一套）

- 永久禁用词：`擦屁股` `屁股` `屎` `拉屎` `尿` `粪便` `排泄` `屁`；「善后」写成收尾 / 返工 / 兜底 / 补漏 / 捞 / 背锅。
- 句尾不挂语气词：呀、啦、吧、嘛、诶、呜、呢、哦、哇、啊、哼、嘿。**字卡、纸条上的字同样算**。
- 不直说 3D；不报价格、额度、token 换算、排名；口播与字幕里的数字写成汉字。
- 不画运营数字（数据曲线、余额条、账本表格、进度条）；零水印、零角标、零「AI 生成」贴纸。
- 不伪造接触：不给道具画假手。
- 不把社区玩笑写成机制：重置不是失忆，摸鱼不是偷懒，白饭不必是 token。
- 不照搬上游美术与台词：参照动作，不复制立绘、音乐、声音、代码；素材授权各自核对（《坏女孩》《童话镇》的原曲都不在仓库里）。
