## 卡点是怎么对的

1. 解码 mp3（44.1 kHz，183.70 s），算 2048 点 STFT 的半波整流频谱通量，10 ms 一格。
2. 22–178 s 做自相关，候选拍长 0.706 s（85 BPM）/ 0.353 s（170 BPM）；梳状滤波细调到 0.70580 s，首拍 21.295 s。
3. 每 15 秒一窗复核相位，最大漂移 0.010 s。
4. 洛天依原版 LRC（时长同为 3:04）的每句起点吸附到最近的半拍：平均移动 0.093 s，最大 0.166 s。
   「你是月色真美」「又将它们相连」两句在人声频段（250–1200 Hz）里实测起点落在拍前四分之一拍，按实测取。
5. 这是拍点级对齐，不是逐音节对齐。

## 几条守住的规矩

* 一支 MV 一个人只演一个形象；歌里的感情戏不回写进日常线。
* 龙娘只从画面上方掠过；纸片人不画假手，牵手用两人之间的金线说。
* 片头只留歌名与歌手两行；最后一句唱完就结束，不加片尾卡；零水印零角标。
* 缺素材直接报错，不拿别的造型顶替。
