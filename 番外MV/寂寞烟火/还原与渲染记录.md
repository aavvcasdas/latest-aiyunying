## 重渲

从仓库根目录执行（需 Node 22、仓库根目录及源码各自 `npm ci`，以及 `pip install -r requirements.txt`）：

```bash
(cd 番外MV/寂寞烟火/源码 && npm run build)
node tools/shoot_jimo_mv.mjs --out /tmp/jimo_frames --to 65.09
FF=$(.venv/bin/python -c 'import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())')
"$FF" -y -framerate 30 -start_number 0 -i /tmp/jimo_frames/f%05d.png -i 寂寞烟火.WAV \
  -vf 'scale=-2:-2:flags=lanczos:in_range=full:out_range=tv,format=yuv420p' \
  -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv \
  -c:v libx264 -preset fast -crf 16 -maxrate 12000k -bufsize 2M \
  -movflags +faststart -c:a aac -b:a 192k 番外MV/寂寞烟火/成片/寂寞烟火.mp4
```

截图目录必须为空。不要用 `-shortest`，否则可能丢掉最后一帧；重渲后应重新核验音画、字体、帧数并人工听审。
