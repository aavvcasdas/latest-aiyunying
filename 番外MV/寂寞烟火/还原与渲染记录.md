# 《寂寞烟火》还原与渲染记录

## 当前状态（2026-11-25）

**尚未渲染出片。** `源码/` 为仓库根目录 `寂寞烟火.zip` 解压内容，保留原项目结构。压缩包没有原项目所引用的 `src/assets/jimo-yanhuo.mp3`；已从仓库根目录的 `寂寞烟火.WAV` 转为 192 kbps MP3 补齐该引用，WAV 实测约 65.09 秒，与项目声明的 `MV_DURATION = 65.09` 一致。这不等于已经人工听审或核验歌词卡点。

压缩包也没有 `src/assets/models/` 中的 11 个 GLB，但包含 `scripts/generate_blender_assets.py`。项目构建在补音频后仍报 `Could not resolve ../assets/models/viaduct_bridge.glb?url`。当前环境没有 Blender 可执行文件；尝试使用 Python `bpy==4.2.0` 执行生成脚本时，导入阶段因缺少系统库 `libXrender.so.1` 等失败，未生成模型，也未成功构建或渲染。

## 后续恢复步骤

1. 在安装有 Blender 3.4.1 及其系统依赖的环境中，从 `源码/` 目录执行：
   ```bash
   blender --background --python scripts/generate_blender_assets.py
   npm ci
   npm run build
   ```
   或提供原工程的 `src/assets/models/`：`viaduct_bridge.glb`、`sea_arch_pillars.glb`、`coastal_lamp_pine.glb`、`time_tea_pavilion.glb`、`arched_footbridge.glb`、`mirror_pavilion.glb`、`dream_crescent_arch.glb`、`star_astrolabe.glb`、`harbor_lighthouse.glb`、`origami_boat_rainbow.glb`、`dawn_breakwater.glb`。以上生成和构建步骤在当前环境尚未验证成功。
2. 做适配后逐帧采集并混入根目录 WAV。页面的 `__mv` 钩子以 `isReady()` 报告就绪，字幕在 Canvas 外的 DOM 中，采集时须等模型加载完成、保留字幕并隐藏播放控件；仓库现有 `tools/shoot_vite_mv.mjs` 不能未经验证直接保证这些条件。需要检查截图阶段的舞台尺寸、字体、字幕及歌词卡点，不得将未检查的画面当成正式成片。
3. 输出后验证时长、帧数、音轨、音画同步与全片画面，人工连续观看和听审，记录成片哈希及发布授权。用户要求推送视频，但本次未产生视频，因此没有提交 MP4；仓库已有 `《寂寞烟火》_0.mp4` 是既有素材，不是本工程渲染结果。
