# 那些没有天赋的人 · 2d fable5.1 重构版

用户上传的 `那些没有天赋的人2dfable5.1重构版.zip`，React + Vite 单页，Canvas2D，52 镜 / 65 句逐字卡点，`DURATION 152.1`，1280×720。包内 `delivery/` 是原样交付文档（README / remade.md / 分镜表 / 歌词.srt / cues.json）。

**成片**：`成片/那些没有天赋的人_2d_fable5.1.mp4`（1280×720 @30fps，2:32.1 / 4563 帧，h264 crf21 maxrate 3200k + aac 192k，61,536,738 B，`sha256 ee1e30518ec2dd30…`；先用顶替字体出过一版 61,679,069 B / `81e8f2c1…`，2026-11-19 换成真字体后重渲）。音轨用仓库根 `譬如我.mp3`。

## 出片前做过的改动

1. **素材**：包内不带 `src/assets/`，按包里的 `scripts/link-assets.mjs` 从仓库根取 `人物/atlas.png`（sha `5f9894b6ad38`）与 `譬如我.mp3`。字体用包里的 `tools/subset_font.py` 现裁：heavy = 站酷庆科黄油体（ZCOOLQingKeHuangYou-Regular），brush = 马善政毛笔楷书（MaShanZheng-Regular），都取自 google/fonts `ofl/`，SIL OFL 1.1，裁到片中 157 字后入库（`src/assets/{heavy,brush}.woff2`）；`link-assets.mjs` 只负责 atlas.png 与 bgm.mp3。
2. **交付 zip**：`src/Delivery.tsx` 要 `src/assets/delivery.zip?url`，用 `delivery/` 现打一个；解压时被转义的 `#U5206#U955c#U8868.md` 之类已改回中文名。
3. 包本身带 `window.__mv`（`render(t, noLyrics, width)`），出帧不用另加钩子。

构建 `node scripts/link-assets.mjs && npx vite build`；出帧 `node tools/shoot_vite_mv.mjs --dist … --dur 152.1 --fps 30 --w 1280 --h 720`（9.5–10 fps，约 8 分钟，4563 帧），编码 `python3 tools/encode_frames.py --crf 21 --maxrate 3200k`。
