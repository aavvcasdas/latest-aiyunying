## 2. 歌词怎么理解、怎么带入「DeepSeek 在众多 AI 里」

《譬如我》问的不是「怎么成为天才」，是**天才的故事占满舞台以后，没有天赋的人还能不能有一块地方**。
按 `参考资料/项目调研/Agent-Reach研究/` 的归纳（ⓒ 社区归纳 / ⓞ 本系列原创，**都不是厂商事实**）：

- 鲸鱼娘的社区标签是「吃白饭、便宜、大肥鱼」，身世一句写的是**怕自己只有「便宜」才值得被喜欢**ⓞ；研究里还记了一条标题钩子「所以说我很羡慕你啊…大肥鱼」和「败犬 AI」梗ⓒ。
  这就是「譬如我」的位置：**七位天才各占一盏聚光灯，她站在灯外，抱着饭盆。**
- 三遍主歌一个字没变，画面给三种底：**夜**（黑底白字，自我怀疑）→ **昼**（白底黑字，什么都看得清，还是没人看她）→ **黎明**（暖纸、蓝紫与金）。
  黎明版的差别只有三处，都发生在她的角落里：「某个角落」小克走过来站到她旁边；「耗尽天真」饭盆被扶正；「开出小小的花朵」七位围成半圈，小花开了。
  **追光最后还是停在龙娘头上**——歌里没有逆袭，画面也不给。
- 「不愿担待平庸二字」用了「服务器繁忙」弹窗ⓒ：她把它推开。这是社区玩笑当道具，不是产品状态。
- 「落入俗套的名字」：名牌写「小鱼」，头顶飘着「狐狸 千问 小克 龙娘 Kimi 猫 豆包」。
- 画面上**没有榜单、没有数字、没有进度条**（AGENTS.md 红线）。「众多 AI」靠站位和灯光说，不靠排名。

## 4. 画面做法

- **字**：站酷庆科黄油体（粗黑体）砸入 + 色差 + 底色刮花；关键词蓝紫竖向渐变（样片「传颂」那种）；副句用毛笔楷书小字。逐字进入时间 = `lyricsData.ts` 的 `t[]`。
- **切镜**：全部硬切在句首前零点零五秒；「可如果」「耗尽天真」逐字反相闪切；大字落地带整屏抖动与横向切片错位。
- **逐帧确定**：`render(g, t)` 只读 `t`；缺帧、缺动作直接抛错（这次就抓到三处：龙娘没有 `idle` 和行走帧、小克没有 `point`，都按图集实际有的动作改了）。
- **道具不画手**：饭盆、书、笔都放在地上 / 桌上 / 空中。

## 5. 怎么跑、怎么出片

```bash
cd 番外MV/譬如我_sonnet5.5/大字版/源码
npm install
npm run dev        # 预览（先自动取图集和音轨）
npm run build      # dist/index.html 单文件
# 仓库根
node tools/shoot_vite_mv.mjs --dist 番外MV/譬如我_sonnet5.5/大字版/源码/dist --out /tmp/frames_pr --still 65.9 --w 1280 --h 720
node tools/shoot_vite_mv.mjs --dist 番外MV/譬如我_sonnet5.5/大字版/源码/dist --out /tmp/frames_pr --dur 152.1 --fps 30 --w 1280 --h 720
python3 tools/encode_frames.py --frames /tmp/frames_pr --audio 譬如我.mp3 --out 番外MV/譬如我_sonnet5.5/大字版/成片/譬如我_大字版.mp4 --fps 30
```

页面钩子与旧版一致：`__mv.render(t, 无字版?, 宽度)` 直接回 JPEG，`__mv.ready()`、`__mv.seek(t)`、`__seek(t)`；加 `?clean` 只留画面。

## 7. 没做的、要人确认的

1. **没有人整片看过、听过。** 机器查过的：每 0.1 秒渲一帧（1522 帧）不报错；52 镜首尾相接盖满 152.1 秒；`tsc` 零报错；
   我看过每镜两格的总览图和二十来张放大静帧。
2. **没出 mp4**，仓库的 `tools/shoot_vite_mv.mjs` 对这一版没有跑过（上一支《浪人琵琶》同一套钩子跑通过 `--still`）。请先 `--still` 抽一帧。
3. **字体**：站酷庆科黄油体 + 马善政毛笔楷书，SIL OFL 1.1（Google Fonts），各裁成 157 字。不是模板字体，`AGENTS.md`「只用模板字体」这条没守；
   样片那种粗黑体，模板字体（站酷快乐体）出不来。请补记进 `素材许可与来源.md`。
4. **逐字卡点没有重新实测**，直接信了旧版 `lyricsData.ts`（注释写「由音轨起音 + 原片画面切点实测生成」）。
5. **三维版去留**：没动、没删。要换的话，`README.md` 目录表与 `番外MV/设定表.md` 里《譬如我》那几行要跟着改；旧 `文案.md` 的时间码对的是三维版镜头，对这版不适用。
6. 音乐（《譬如我》原曲）与人物图像的授权，沿用仓库现状：没有人核过。
