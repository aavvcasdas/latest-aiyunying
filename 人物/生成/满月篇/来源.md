# 满月篇人物姿态素材

这三张透明 PNG 是历史存量派生图，来自《若是月亮还没来》MV 归档的 `src/assets/gen/`，对应本鲸的三个新姿态：仰望、抱住笨鱼、捧着山茶。它们没有并入 `人物/atlas.png`，原有角色图集和鲸鱼娘基础形象未修改。

绿幕原件现在只保存在 `番外MV/若是月亮还没来/源码/gen_raw/`；提示词在 `人物/提示词/满月篇/`。生成时的模型 / 版本 / seed 未记录，状态 `legacy_unknown`。`assets.manifest.json` 逐项记录提示词、绿幕原件、canonical 透明 PNG 与两份 MV 副本的 SHA256；`tools/generated_assets/validate_generated.py` 会核对硬边 alpha、四角透明和副本一致性。

`benyu_px.png` 是现有 `人物/q版/笨鱼.png` 的像素化副本，不是新角色设计。许可与发布边界见 `素材许可与来源.md` 和 `番外MV/若是月亮还没来/素材/remade.md`。

**不新增生图、不替换现有角色图集。** 后处理如需复现，运行两个月亮工程各自的 `npm run assets:gen`；它们都调用 `tools/generated_assets/process_generated.cjs`，输出到 `src/assets/gen/`，不再写到失效的 `public/assets/gen`。
