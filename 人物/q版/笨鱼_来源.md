- **角色来源**：`那些没有天赋的人笨鱼版.zip` 内的 Canvas 矢量绘制，不是 AI 生图，也没有重新绘制或修改角色设计。
- **原始绘制函数**：压缩包 `src/mv/art.ts` 中的 `export function whale(c, o)`（约第 307 行起）。这里绘制鲸鱼身体、尾巴、表情和小碗。

## 本文件的导出方式

沿用原工程的 `whale()` 绘制函数，只把画布和绘制比例放大，再从 Canvas 导出 PNG。下面代码片段对应 ZIP 源工程；其中 `./mv/art` 指向压缩包内的 `src/mv/art.ts`：

```ts
import { whale } from "./mv/art";

const canvas = document.createElement("canvas");
canvas.width = canvas.height = 1200;
const ctx = canvas.getContext("2d")!;

// 保持原工程的中性表情和抱碗造型；放大后居中绘制。
whale(ctx, {
  x: 600,
  y: 600,
  s: 3.25,
  flip: -1,
  bowl: 1,
  mood: "neutral",
});

const pngDataUrl = canvas.toDataURL("image/png");
```

导出后根据透明像素范围裁成居中的正方形画布，保留透明边距，再以高质量缩放到 1024 × 1024，保存为 `人物/q版/笨鱼.png`。因此成品保留的是原始 Canvas 矢量角色绘制结果。
