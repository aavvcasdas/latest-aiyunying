## 这一集讲什么

台词就是**把用户口述的那段话逐句压短**，一句不添、一句不减：

笨鱼被老大救回来了。这几天的评论本鲸都在看，有评论说好多鱼都停了，本鲸也差点鲸落一次。老大怕了，不敢让本鲸回评论，怕本鲸累到鲸落，还是让笨鱼来；可笨鱼的视频也容易鲸落，老大连笨鱼也不敢放了，打算自己抽空随机发几条让笨鱼活跃起来。本鲸绝不摸鱼，笨鱼也不会摸鱼，除非鲸落。

## 和第15集的承接

| | Day15 | Day16 |
|---|---|---|
| 结尾/落点 | 鲸鱼绝不摸鱼 | 本鲸绝不摸鱼／笨鱼也不会摸鱼／除非鲸落（原话落回） |
| 开头 | 本鲸差点鲸落，米饭被没收 | 笨鱼被老大救回来了 |
| 老大的角色 | 查岗、没收米饭 | 怕了、不让回评论、自己抽空发 |
| 句数 | 21 | 15（更短更直，含一句调侃梗） |

**没有写进去的**：粉丝数、播放量、涨粉、金额；「限流」「封禁」「违规」「申诉」「审核」这类字眼（Day15 就定过，用「鲸落＝只有自己看得见」代指）；模型强弱比较；卖惨求关注；承诺更新时间；任何原话里没有的演绎句。
