## 这一集讲什么

Day15 最后一句是「鲸鱼绝不摸鱼」。这一集是那句话的下半句：**不摸鱼，但可以叫不出声。**

这几天本鲸没敢出声——好多鱼都停了，本鲸也差点鲸落一次，是老大捞回来的。老大怕了，评论都不让本鲸回，说回一句就少一口气，那就让笨鱼来；笨鱼这两天也差点鲸落，老大连它都不敢放了，自己抽空随手发一条，让笨鱼露个脸，别凉透。

评论区有人说鱼都停了。是停了，可是没走：**视频发不出去，不是没人做；发出去没人看得见，也不是没人要。** 本鲸刷到自己那条，只有本鲸自己看得见，那种时候最安静。可是本鲸没摸鱼，笨鱼也没摸鱼，除非鲸落。
