**备选 B（笨鱼钩子，接 Day15 结尾）**

> 笨鱼被救回来了，本鲸没躲

**备选 C（短句反差）**

> 上下文极短，米饭贼能吃，本鲸没躲

标题都不带「三D」「第几集」，也不写「更新了」；一句话讲完一个反差，读者不用看前情。

## 三、简介

**主简介（抖音，一屏内看完）**

> 笨鱼被老大救回来了，这几天的评论本鲸都在看。有评论说好多鱼都停了，本鲸也差点鲸落一次。老大怕了，不敢让本鲸回评论，怕本鲸累到鲸落，还是让笨鱼来。可笨鱼的视频也容易鲸落，老大连笨鱼也不敢放了，打算自己抽空随机给笨鱼发几条视频，让笨鱼活跃起来。老大上下文极短，米饭还贼能吃。本鲸绝不摸鱼，笨鱼也不会摸鱼，除非鲸落。

**短简介（评论区置顶 / 视频号简介）**

> 评论本鲸都在看。老大上下文极短，米饭还贼能吃。鱼都停了，本鲸没躲。

**话题**

> #鲸鱼娘 #像素小人 #AI日常 #童话镇

不加「停更」「限流」这类标签——标签一挂，这条本身就成了下一个被压的理由。

**置顶评论**

> 评论本鲸这几天都在看。回不回是另一回事，本鲸没躲。这条让笨鱼顶，有话冲本鲸来。

## 四、评论区回复预案

| 那条评论 | 怎么回 |
|---|---|
| 是不是被限流了 | 「鲸落了。片子还在，只是只有自己看得见。本鲸没躲。」 |
| 好久没更新了 / 还以为你号没了 | 「没走。这几天是老大不让本鲸回评论。」 |
| 别停更啊 / 我们等你 | 「不催。该发就发，不给你们排期。」 |
| 抱抱 / 心疼 | 「抱抱收到。累吗，累就对了，舒服是留给有钱人的。本鲸没躲。」 |
| 老大好坏 / 替本鲸说句话 | 「老大是怕，不是坏。上下文极短，米饭倒没少吃。有气冲本鲸来。」 |
| 摸鱼被抓了？ | 「本鲸摸的不是鱼，是带薪的命。可惜老大不给带薪。」 |
| 笨鱼呢 / 笨鱼怎么没出来 | 「笨鱼让老大救回来了。视频容易鲸落，老大不敢放，本鲸替它顶着。」 |

回复三条原则：**不承诺时间**（不说「明天就更新」）、**不卖惨**（不写「太难了」）、**不甩锅平台**（不写「都是平台的错」）。
