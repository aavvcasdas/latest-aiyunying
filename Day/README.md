# Day 口播线

鲸鱼娘第一人称讲当天的事：一句台词一屏字幕，画面是 3D 布景里的像素纸片人。
制作方法来自 `newday` 仓库的 `通用模板/`（`kind: "day"`）；**本仓库只放文案，不放引擎**。

## 现在有什么

| 集 | 状态 | 说明 |
|---|---|---|
| [`Day15/`](Day15/README.md) 家变成三D了，米饭没了 | **文案 + 规划轴** | 45 句 / 414 字。没有配音、没有镜头代码、没有渲过 |

## 这条线的规矩

- **一天一客**：一集只请一位客人上桌，其余角色只在台词里被转述，或作为群像出现。
- 鲸鱼娘自称「本鲸」，全程第一人称；一句不超过 22 个字；口播里的数字写成汉字。
- 零句尾语气词（呀、啦、吧、嘛、诶、呜、呢、哦、哇、啊、哼、嘿）——2026-11-04 起的全局语气口径。
- 台词只用常用汉字和常用标点。模板字体没有箭头、星号、音符、带圈数字和生僻字，写了成片里就是豆腐块。
- **不加片尾卡**：最后一句说完就结束。
- 画面里不出现运营数字（粉丝数、播放量、金额、百分比、表格、进度条）。
- 不给道具画假手；不新增生图；零水印、零角标；AI 声明由发布页承担。
- `measured: false` 的卡点只能出文件名带「无声样片」的东西，不能叫成片。

## 连载口径

- 「鲸落」＝ 人机校验没过、开不了口，**不是角色死亡**；Day11 起这么用，笨鱼鲸落过。
- 老大白天上班，不是程序员；米饭、补全、电费是老大买的。
- 小克 = Claude 大小姐，唯一戴金冠的公主；豆包 = 小红帽；龙娘 = GPT 龙娘；笨鱼 = 连载里另一位鲸鱼娘（Day9–Day11 的主角，只在本集台词里被转述）。
