# Day15 分镜（14 个镜头，卡点实测）

> 时间来自 `cues.json`（`measured: true`，按 `鲸鱼鲸落_克隆配音_最终版.wav` 实测）。换了配音要重跑 `align`，所有切点会跟着变。
> 镜头里的时机一律挂在句子上：`lineU(f, n)` / `f.said >= n` / `f.when(n, p)`，不要写死「镜头的百分之几」。
>
> **第七版（按第七轮意见重改）**
> 1. **构图和分镜照上一集 Day14 的拍法**：屋子做出纵深（后墙书架和书、窗边帘子、桌后长凳、墙角纸箱），
>    机位不再一律平视：有俯拍、有仰拍、有桌面近景插入、有门口逆光，人和画面边缘留白。
> 2. **上一集改成推进来的一台电视**（右上角画中画）：第 4 句开口那一刻（11.2 s）从右边推进来，
>    电视里是 1.8× 循环播放的 Day14 成片，之后一直贴在右上角。做在 `pip.sh` 里，帧号一一对应。
> 3. **鲸落图只出现 1 秒**（第 1 句说「鲸落」那一下），S10 / S11 不再出图。
> 4. **人物不再一直抖**：起伏 / 摇摆 / 点头的恒定 sin 全删了；引擎里「说话时每秒 4 下轻颠」的 `talk()` 本片也全部不用；
>    动作只跟着台词走（点头认下来就是一个固定小角度）。
> 6. **像素角色放大不糊**：角色图集改成最近邻放大（`magFilter = NearestFilter`），近景是清楚的方块像素，不是被显卡插值糊掉的一团。
> 5. **场景交互**：踩木箱、桌子转起来带着碗和沙漏一起转、把稿子按到桌上、翻书翻出空白页、饭碗被端走。

## 二、逐镜

每条只写三件事：台词说了什么、画面拿什么对上、机位在哪。**没有长距离走位**，只有 S02 踩箱、S12 从门口进来这两处位移。

### S01　先说结果　第 1 句　0:00.00–0:04.19
- **台词**：本鲸差点鲸落，结果米饭被老大没收了。
- **画面**：白天的屋子，第一帧就亮着人（没有黑场、没有从画外走进来）。说到「鲸落」，`鲸落图.png` 从右侧浮起、亮 1 秒就收（`seg(u,0.24,0.30)` 进、`seg(u,0.46,0.52)` 出），不解释、不占画面。
- **机位**：高位俯拍慢推，(1.9,2.35,8.2) → (1.1,1.9,7.0)，fov 38→35。人在 (−1.25, 0, 1.45)，桌沿左边外侧；图摆 (1.3, 1.55, 2.6)，横版。

### S02　一查岗　第 2–3 句　0:04.19–0:11.19
- **台词**：昨天老大一查岗。／本鲸正踩着木箱，指挥小克改做好的视频。
- **画面**：仰拍——她一抬脚就上木箱（0.4 秒，不是走场），从上往下指挥；小克在桌右外侧抱着稿子翻，边听边点头。说到第 3 句末尾，小克把稿子放到桌上（抬一下、落下去，落在桌面）。
- **机位**：低位仰拍缓推，(−3.6,1.42,6.0) → (−2.8,1.5,5.4)，fov 35→34。木箱 (−0.55, 0.225, 1.45)，小克 (2.75, 0, 1.05)。

### S03　重新装修　第 4–5 句　0:11.19–0:17.93
- **台词**：小克把家重新装修了一遍。／桌子能转，画也有厚度。
- **画面**：桌子当场转（`tbl.rotation.y` 走半个正弦，转过去再回正），**碗和两只沙漏跟着桌子一起转**（`ride()` 按角度换位置）；机位从右往左横移并下降，把新地板、新墙、窗、门一起带过——「装修过」是看出来的。这一句开口时，右上角的电视推进来。
- **机位**：(3.7,2.2,6.7) → (−0.6,1.62,6.3)，fov 37→36。

### S04　夸的是本鲸　第 6–7 句　0:17.93–0:23.49
- **台词**：有条评论说，本鲸也有童话书了。／评论全在夸本鲸。
- **画面**：低机位仰拍，三条评论卡片从画外飘进来（本鲸好会装修／这才像个家／本鲸牛），她摊手看镜头，小克摊手把功劳推给她。
- **机位**：(0.4,1.42,7.6) → (0.3,1.5,6.8)，fov 38→37。卡片在 y 1.75–2.3、z 1.35–1.55。

### S05　童话书　第 8 句　0:23.49–0:25.79
- **台词**：书里有一屋子朋友。
- **画面**：桌上摊开一本故事书——**左页画着四个小人，写着「一屋子朋友」**，右页是要翻的那一页；她站在画左、低头指着书页。书是薄板＋画出来的纸（`page()`），不是贴图空本。
- **机位**：俯看桌面，(1.85,2.0,3.7) → (1.7,1.92,3.4)，fov 34→33。书在 (0.3, 0.5)，两页各 0.5 宽；两只沙漏挪到桌右（2.35 / 2.9），不进画。

### S06　只有一页　第 9 句　0:25.79–0:29.11
- **台词**：本鲸以为，这本书只有自己那一页。
- **画面**：书页近景。她绕书脊把最后一页翻过去（`pivot.rotation.z` 从 0 走到 π，页角先抬起来再落到左边），**背面是空白的**——书上只剩右边那页「本鲸」。翻页是绕书脊翻，不是整页原地打转。
- **机位**：(0.8,1.72,1.95) → (0.78,1.68,1.8)，fov 30→29（只拍书，人不抢戏）。

### S07　重做上一集　第 10–11 句　0:29.11–0:35.65
- **台词**：所以昨晚，本鲸让小克重做上一集。／电视里放的，就是那一版。
- **画面**：桌上摊着上一集的稿子；她指着那摞纸说重做，小克点头认下来、**把手按在稿子上**（压 0.03，有接触感）。侧面机位，两个人一前一后，桌子横在中间。
- **机位**：(5.5,1.6,4.7) → (5.0,1.55,4.1)，fov 36→35。

### S08　上一集是两只沙漏　第 12–13 句　0:35.65–0:41.87
- **台词**：上一集，是两只沙漏。／抖音的东西，本鲸交不出去。
- **画面**：斜俯的桌面近景，两只沙漏并排漏沙（左边那只在翻之前先漏走一半）；她在画面左边指过去。上一集本身在右上角电视里放着。
- **机位**：(1.45,1.95,5.5) → (1.35,1.88,5.1)，fov 34→33。她在 (−1.35, 0, 2.5)。

### S09　翻过去会抖　第 14–15 句　0:41.87–0:47.55
- **台词**：要不就翻过去。／抖着的东西，本鲸交不出去。
- **画面**：从另一侧看桌面：左边那只沙漏被翻过来，翻完一直抖（每帧轻微抖动 `sin(T*27)`，幅度 0.012 弧度）；她在画右看着、摇头。
- **机位**：(2.5,1.9,5.1) → (2.4,1.82,4.7)，fov 34→33。她挪到 (2.35, 0, 2.0)，才进画。

### S10　就鲸落了　第 16 句　0:47.55–0:50.43
- **台词**：改到一半，本鲸就鲸落了。
- **画面**：灯灭。高处俯拍，整间屋子压下来：她一个人站在桌边，肩膀塌下去、头低下来，桌上沙漏还在漏。**画面里没有那张图**——鲸落这件事，镜头拍不到。
- **机位**：(1.0,2.25,8.4) → (0.9,2.12,7.8)，fov 36→35。她压暗到 `sil(0.45)`。

### S11　只有自己看得见　第 17 句　0:50.43–0:53.63
- **台词**：鲸落，是只有本鲸自己看得见。
- **画面**：更近的一张脸，机器压到胸像高度：屋里空着，画面里什么都没有——只有她自己看得见。
- **机位**：(−0.85,1.36,4.3) → (−0.85,1.33,3.9)，fov 31→30。她压暗到 `sil(0.55)`。

### S12　老大捞回来　第 18 句　0:53.63–0:56.63
- **台词**：老大午休把本鲸捞了回来。
- **画面**：门自己推开，光从门外铺进来；她从门槛走三步进到光里站住（这就是「被捞回来」）。小克在后面扶着门框，压暗但看得清。
- **机位**：门口逆光的低机位，(−0.2,1.5,4.4) → (−0.5,1.48,3.95)，fov 31→30。小克 (−3.45, 0, −3.5)。

### S13　米饭被收走　第 19 句　0:56.63–0:59.51
- **台词**：然后本鲸的米饭，被收走了。
- **画面**：桌面近景：饭碗被人从另一边端起来、滑出画面；她站在桌沿往前追半步，停住。
- **机位**：(1.75,1.38,4.5) → (1.65,1.34,4.1)，fov 34→33。

### S14　鲸鱼绝不摸鱼　第 20–21 句　0:59.51–1:05.72
- **台词**：米饭可以再挣，片子不能这么交。／下次，本鲸养鲸鲸。
- **画面**：灯重新亮起来，高处俯看整间屋子；她站在桌边把最后两句说完，抬手挥了一下。没有片尾卡、没有角标。
- **机位**：(2.25,2.15,6.6) → (1.95,1.98,6.0)，fov 36→35。

## 三、上一集：推进来的那台电视（画中画）

三维里不摆电视，画中画交给 ffmpeg 在编码后叠一次，帧号一一对应。

| 项 | 值 |
|---|---|
| 电视框 | `Day/Day15/素材/pip_tv.png`（`make_tv_frame.py` 画：天线、木壳、两个旋钮、喇叭、两条腿），540×396，中间 378×212 是透明的洞 |
| 机身上的字 | 机身下沿贴一张纸条：**Day14 · Claude 重构版**（写明电视里放的是哪一版） |
| 位置 | 右上角，距边 16px：框左上角 (1364, 16)，画面贴 (1436, 88) |
| 推进来 | 第 4 句开口那一刻 11.2 s，从画面右边推进来，0.7 s 缓出（`1-(1-p)³`） |
| 电视里放什么 | `Day/Day14/成片/Day14_无声样片.mp4`，**1.8× 循环播放**（`setpts=PTS/1.8` + `-stream_loop -1`），播完从头再来 |
| 声音 | 用本片配音；电视那一路不混声 |
| 字幕 | Day14 成片本身没有字幕条，电视里不会出现两套字幕 |

跑法：`bash Day/Day15/pip.sh`（读 `成片/Day15_原片.mp4`，写 `成片/Day15.mp4`）。

## 五、素材与命令

| 东西 | 来源 | 备注 |
|---|---|---|
| 配音 | `鲸鱼鲸落_克隆配音_最终版.wav`（仓根） | 字幕与卡点都对它 |
