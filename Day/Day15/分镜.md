# Day15 分镜（规划稿，15 个镜头）

> **这是规划，不是已经写好的镜头代码。** 布景、道具、造型只用 `通用模板` 里现成的东西（电视要新加，见第三节）。
> 时间来自 `cues.json` 的规划轴（`measured: false`），配音到位后会整体变——镜头里的时机一律挂在句子上：
> `lineU(f, n)` / `f.said >= n` / `f.when(n, p)`，不要写死「镜头的百分之几」。

## 二、逐镜

### S01　住在电脑里　第 1–2 句　0:00.00–0:08.73（8.7 秒）

- **场景**：房间+电脑（机箱、发光的屏、桌上的饭碗）
- **出场**：鲸鱼娘（光照 `night`）
- **画面事件**：第一帧是亮着的屏幕，本鲸站在屏前回头看镜头；机位一路后退，把房间、桌子、饭碗一起装进画面。
- **机位 / 挂点**：退到 z≈7 装下全身；第 2 句说到一半停稳。饭碗放画面中部，别被字幕条压住。

- **台词**：昨天，Claude大小姐把家改成了三D。／桌子能转，河也有厚度。

### S04　一屋子朋友　第 7–8 句　0:21.72–0:30.86（9.1 秒）

## 三、电视（本集的主要新东西）

- **放什么**：上一集的成片 `Day/Day14/成片/Day14_无声样片.mp4`，81.4–89.4 秒那 8 秒（群像 → 翻沙漏 → 沙漏特写）。
- **怎么放**：已经抽成 192 张 512×219 的 JPG，在 `Day/Day15/素材/tv_day14/`，24 fps 循环；帧号 `i = ((T − t0) × 24) mod 192`。
- **为什么不用 `<video>`**：逐帧渲染时 `currentTime` 的 seek 不确定，同一个镜头两个渲染页面会停在不同帧，成片里会跳。
- **引擎要加的**：`props.tv(w, h)`（木框 + 弧形屏 + 天线 + 屏幕平面），屏幕用 192 张纹理按帧号换；`t0` 从镜头参数传进去，别用全局变量。
- **摆放**：屏幕 1.9 × 0.81，中心高度约 1.15，放桌面右后方；本集对话条占画面 79%–96%，电视要整个在它上面。
- **什么时候亮**：S08 点亮（第一帧黑、第二帧亮），S09 特写，S10 关掉，S11 重新亮着，S12 一直播，S14 还在播。
- **上一集的对话条**：已经裁掉了（裁掉画面底部 24%），所以电视里不会出现两套字幕。
- **声音**：电视不出声。

## 四、这一集用到的模板积木

| 用途 | 用什么 | 注意 |
|---|---|---|
| 屋子 | `props.room()` ＋ `windowPane()` ＋ `plant()` ＋ `table()` | 同一间屋子连着好几个镜头，摆位写成常量共用，不然一切镜就跳位 |
| 电脑 / 屏幕 | `kit.box()` ＋ `windowPane()`（发光玻璃） | 第一镜的「住在电脑里」就靠它；别画屏幕里的第二个本鲸 |
| 电视 | `props.tv()`（**要新加**）＋ `素材/tv_day14/` | 见第三节 |
| 立体童话书 | `sets.book()` | 翻开的是 `cover`，书页的光用 `glow` |
| 沙漏 | `props.hourglass()` | 只画沙子，不画刻度、百分比 |
| 饭碗 | `props.riceBowl()` | 被收走＝碗滑出画面，不画手来拿 |
| 纸 / 纸牌 | `props.sheet()` ＋ `writeLine()` ＋ `standing()` | 纸上的字只用模板字体；平放的纸要么立起来、要么升机位俯拍 |
| 木箱 | `kit.box()` | 当凳子踩，要整个人完整入画 |
| 角色 | 鲸鱼娘 `whale`；客人 `claude`（`.wear('crown')`，唯一戴金冠的公主） | 一天一客：这一集只有 Claude 上桌 |
| 表情 | `whale/p_whale_think`（第 1、9、16、22 句）、`whale/p_whale_shout`（第 28 句） | 只在台词行首写，别在镜头里换头像 |

## 五、守住的画面红线

- 零水印、零角标；「AI 生成」声明放发布页，不进画面。
- 画面里没有任何运营数字：没有粉丝数、播放量、金额、百分比、进度条、账本表格。沙漏只有沙子。
- 不给道具画假手：碗滑走、纸片立起来、门自己开，都不画手。
- 不新增生图、不换画风：角色只用图集里的像素造型；电视里放的是上一集的成片，不是新画的画面。
- Day 不加片尾卡：第 28 句说完，0.6 秒后结束。
- 「鲸落」这一段只用灯、剪影、空碗、门光；没有伤、病、药、水淹镜头。

## 六、写代码时最容易踩的坑（照 Day14 的教训）

1. 每个角色、每件道具**每一帧都要写全**：造型和位置不会自动复位，没写的帧会停在上一次渲到的样子，成片里隔帧乱跳。
2. 电视屏幕的帧号只能由 `T` 算，不能缓存「上一帧 +1」。
3. 沙漏翻完要 `set()` 立正（Day14 那版样片就是在这里抖的），写完用 `sheet --shot` 看六格。
4. 说话的人 `.talk(T, line === n)`；第 10 句和第 25 句是「认账」，动作少、句子短，不要每句都颠。
5. 第 20 句（踩木箱）是本集唯一的「大动作」，其余镜头靠停顿和机位推进；不要用运镜掩盖人物不动。
