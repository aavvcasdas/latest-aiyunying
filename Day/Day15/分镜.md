# Day15 分镜（规划稿，18 个镜头）

> 这是**规划**，不是已经写好的镜头代码。布景、道具、造型都只用 `通用模板` 里现成的东西，
> 没有新增生图、没有新道具、没有新角色。时间来自 `cues.json` 的规划轴（`measured: false`），
> 配音到位后整体会变，所以镜头里的时机一律挂在句子上：`lineU(f, n)` / `f.said >= n` / `f.when(n, p)`。

## 二、逐镜

### S01　三D的家　第 1–2 句　0:00.00–0:05.90（5.9 秒）

- **台词**：本鲸的家，变成三D的了。／评论全在夸本鲸。
- **场景**：室内·家（房间、桌子、窗、地毯）
- **出场**：鲸鱼娘（光照 `golden`）
- **画面事件**：第一帧就是三D的纵深：桌角在前景，窗和地板往后收。本鲸站在中间，转身，抬手让镜头看这个家。
- **机位 / 挂点**：机位从近处一路退到装得下全身（z≈7），退的过程不停；第 2 句说完前停稳。

### S02　大小姐干的　第 3–4 句　0:05.90–0:12.87（7.0 秒）

- **台词**：干这活的是Claude大小姐。／她说，原来的家太扁了。
- **场景**：同上（同一间屋子，摆位沿用 S01）

- **画面事件**：小克蹲在地板上量墙角，怀里抱着卷起来的图纸；本鲸站在左边看，手一摊——活是她干的。
- **机位 / 挂点**：双人中景（z≈6.5）。两人左右各留 0.85，别被画框切掉；小克在地板上，要从字幕条上沿露出上半身。

### S03　七彩的河　第 5–6 句　0:12.87–0:21.12（8.3 秒）

- **台词**：桌子能转了，河也有厚度了。／有人数过，说七彩的河，一色不少。

- **机位 / 挂点**：俯拍 50° 以上，书放在画面上半（字幕条占 79%–96%）。推镜用 when 挂在第 5、6 句上，别按镜头进度写。

## 三、这一集用到的模板积木

| 用途 | 用什么 | 注意 |
|---|---|---|
| 屋子 | `props.room()`＋`windowPane()`＋`plant()`＋`table()` | 同一间屋子连着好几个镜头，摆位写成常量共用，不然一切镜就跳位 |
| 立体童话书 | `sets.book()` | 翻开的是 `cover`；书页上的光用 `glow` |
| 七色的河 | `sets.straightRiver(len, width, rainbow)` | `rainbow` 给 1；这是《童话镇》里那条河，不是新画的 |
| 沙漏 | `props.hourglass()` | 只画沙子，不画刻度、百分比 |
| 饭碗 | `props.riceBowl()` | 被收走＝碗滑出画面，不画手来拿 |
| 纸 / 纸牌 | `props.sheet()`＋`writeLine()`＋`standing()` | 纸上的字只用模板字体；平放的纸要立起来或者升机位俯拍 |
| 门 | `props.door()` | `set(0..1)` 开合，光从门缝来 |
| 木箱（当凳子） | `kit.box()` | 踩上去要整个人完整入画 |
| 角色 | 鲸鱼娘 `whale`；客人小克 `claude`（`.wear('crown')` 是唯一戴金冠的公主） | 一天一客：这一集只有小克上桌 |
| 表情 | `whale/p_whale_think`（第 1、10、21、29 句）、`whale/p_whale_shout`（第 16、44 句） | 表情只在台词行首写，别在镜头里换头像 |

## 四、守住的画面红线

- 零水印、零角标；「AI 生成」声明放发布页，不进画面。
- 画面里没有任何运营数字：没有粉丝数、播放量、金额、百分比、进度条、账本表格。沙漏只有沙子。
- 不给道具画假手：碗滑走、纸片立起来、门自己开，都不画手。
- 不新增生图、不换画风：角色只用图集里的像素造型。
- Day 不加片尾卡：第 45 句说完，0.6 秒后结束。
- 「鲸落」这一段只用灯、剪影、空碗、门光；没有伤、病、药、水淹镜头。

## 五、写代码时最容易踩的坑（照 Day14 的教训）

1. 每个角色、每件道具**每一帧都要写全**：造型和位置不会自动复位，没写的帧会停在上一次渲到的样子，成片里隔帧乱跳。
2. 沙漏翻完要 `set()` 立正（Day14 那版样片就是在这里抖的），写完用 `sheet --shot` 看六格。
3. 说话的人 `.talk(T, line === n)`；第 12 句以后本鲸是「认账」的语气，不要每句都颠。
4. 第 28 句（踩木箱）是本集唯一一个「大动作」，其余镜头靠停顿和机位推进；不要用运镜掩盖人物不动。
