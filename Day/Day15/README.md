# Day15｜家变成立体的了，本鲸的碗被收走了

Day 口播线的第十五集，用 `通用模板/`（`kind: "day"`）做的。18 个镜头、33 句、约 2 分 12 秒。
**现在是无声样片**：没有配音，每句的起止是按语速估的（`cues.json` 的 `measured=false`），不能发布。

文案、评论的用法、「鲸落」那一句的写法和备用句、要用户确认的三处：见 [`Day15文案.md`](Day15文案.md)。

## 这个目录怎么用

这一集是在 `aavvcasdas/newday` 的 `arena/a300c598-newday` 分支（提交 `3a9f40e`）上做的，引擎一行没改。
本会话只能推送到 `aavvcasdas/latest-aiyunying`，所以整个目录交在这里；用的时候把 `Day/Day15/` 原样放进 newday 仓库的 `Day/` 下面：

```bash
npm run film -- info  Day/Day15          # 时间轴 + 角色预检 + 文字预检
npm run film -- sheet Day/Day15 --shot C08   # 看某个镜头从头到尾六格
# 配音到位：放进 Day/Day15/素材/，film.json 加 "audio": { "file": "素材/配音.wav" }
npm run film -- align Day/Day15          # 按配音实测每句起止
npm run film -- full  Day/Day15          # 出成片
```
