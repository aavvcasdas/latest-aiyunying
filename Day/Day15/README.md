## 这一集讲什么

第一句先把两个结果甩出来：差点鲸落、米饭被老大没收。第二句倒回去：昨天老大一查岗，逮见她踩着木箱指挥小克改片子。然后讲装修、评论、那本书；她说动画还能提，所以让小克重做上一集——电视里放的就是那一版。改到一半，本鲸就鲸落了：鲸落，是只有自己看得见。老大午休把片子捞回来，米饭还是被收走。

## 怎么出片

```bash
npm run film -- info  Day/Day15
npm run film -- align Day/Day15        # 换了配音就要重跑
npm run film -- full  Day/Day15        # 出 成片/Day15.mp4（这一条先当原片）
mv Day/Day15/成片/Day15.mp4 Day/Day15/成片/Day15_原片.mp4
bash Day/Day15/pip.sh                  # 原片 + Day14 画中画 → 成片/Day15.mp4
```

画中画必须有：三维里不摆电视，右上角那块直接是修好的上一集，从第一帧一直播到最后一帧。
