## 这一集讲什么

Claude 大小姐把本鲸的家改成了三D，评论全在夸本鲸；本鲸为了回一句「动画还能往上提」，连夜让她重做上一集，昨天那条片子差点只有自己看得见，是老大午休捞回来的；老大查岗看见这一幕，说早知道不捞，收走了本鲸的米饭。

- 前两句先交代「本鲸是谁、谁给米饭」，第三句才进事件——没看过前情的人也接得住。
- 一天一客：上桌的只有 Claude；豆包、龙娘只在纸片和台词里出现。
- 电视里放的是已经渲好的上一集（两只沙漏），不是重画一版。
- 「鲸落」按用户给的截图写成「只有自己看得见」，不指控平台、不出现审核字样，见 `文案.md` 第 7 节。
- 下一集承诺：把上一集重做一遍，抖的那几秒一帧不留。
