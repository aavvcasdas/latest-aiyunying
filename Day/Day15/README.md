## 这一集讲什么

第一句先把两个结果甩出来：差点鲸落、米饭被老大没收。第二句倒回去：昨天老大一查岗，逮见她踩着木箱指挥小克改片子。然后讲装修、评论、那本书；她说动画还能提，所以让小克重做上一集——电视里放的就是那一版。改到一半，本鲸就鲸落了：鲸落，是只有自己看得见。老大午休把片子捞回来，米饭还是被收走。
