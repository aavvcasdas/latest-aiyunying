# 电视里放的上一集（抽帧）

给 Day15 的电视机用的：Day14 无声样片 81.4–89.4 秒那 8 秒（原 mp4 2026-11-12 出库，这里的 192 帧是当时抽好的，不受影响）。

| 项 | 值 |
|---|---|
| 源文件 | Day14 无声样片 mp4（sha256 `0a89374d27c5a566f568b17bb3fffc6de5685adfa83e5ae9dfeed002598598f4`，已出库） |
| 取段 | 81.4 秒起 8.0 秒（群像 → 翻沙漏 → 沙漏特写） |
| 裁切 | `crop=1920:820:0:0` —— 切掉画面底部 24%，那里是上一集的对话条 |
| 尺寸 | 512×219（2.34:1），24 fps，JPG q=5，192 张，共约 1.9 MB |
| 播放 | `i = ((T − t0) × 24) mod 192`，`001.jpg` 对应 `i = 0`；`t0` = 电视点亮那一刻的全片秒数 |

复现：

```bash
ffmpeg -ss 81.4 -t 8.0 -i Day/Day14/成片/Day14_无声样片.mp4 \
  -vf "crop=1920:820:0:0,scale=512:219:flags=lanczos,fps=24" -q:v 5 \
  -y Day/Day15/素材/tv_day14/%03d.jpg
```

为什么抽帧而不是直接播 mp4：逐帧渲染时 `<video>.currentTime` 的 seek 不确定，同一个镜头在两个渲染页面上会停在不同帧，成片里就会隔帧乱跳。整帧索引才能保证同一帧像素一致。
