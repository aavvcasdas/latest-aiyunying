# 本鲸修复短片对照 dist

这个目录是 `window.__FILM__` 捕获契约使用的静态短片源。`index.html` + `film.js` 从 `cast_atlas.json` / `cast_actions.json` 取同一批矩形和帧名，在 1280×720 画布上并排绘制三张真实图集：

- `original.png`：重画前母版基线；
- `v1.png`：上一轮本鲸重构；
- `v2.png`：当前 canonical 图集快照（SHA `fd02a0b7…`）；挥手 / 递出去已回退到「加裙子固定之前」的原始参考格（原始手臂姿势 + 各自裙摆，仍带原始稿的第三只手，属用户要求），干饭 8 帧已烘入可见饭碗，`idle` / `blink` 正面基础格恢复重画前旧版围裙 / 裙摆 / 靴子但不再锁死下半身，`pose()` 头身裙摆联动已修，8 帧侧视走路重做手臂 / 双腿 / 鱼尾节奏，仍保留 `master_soft`。

`compare.mp4` 是 6.5 秒、12 fps、78 张无损 PNG 经模板编码链得到的无声对照片；`contact.png` 是代表帧总览。短片覆盖 13 个本鲸动作，不是整片成片，也不含音频或人眼签收。

`v2_similarity.json` 用同一批三列快照实测重算，记录当前 111 个本鲸格相对原版的轮廓 IoU / RGB MAE：V1 `0.8679` / `43.0259`，当前 `0.9202` / `29.0110`，88/111 格轮廓更接近原版、83/111 格颜色更接近原版。回滚把挥手 / 递出去换回原始参考格，这两段颜色误差因此下降。

复现命令见 `../README.md`。若 canonical `通用模板/engine/assets/cast_atlas.png` 再次变化，必须重新复制 `v2.png`、重跑捕获与编码，并同步 `v2_similarity.json`，保持三列快照、页脚和报告一致。
