# 刚性角色资产制作记录

- 原始角色长提示词保持在 paperdoll/prompts/本鲸重绘_用户原始提示词.md。
- 身体补画输入：paperdoll/assets/whale-face-cleanplate-v2.png。
- 图片工具输出：body-cleanplate-source.png；模型、版本、seed 未提供，unknown。
- 图片工具任务：保持原画比例和角色注册，移除两条完整手臂（包括袖口、手掌和指尖）与裙摆以下双腿 / 鞋；补全背后的长发、衣身和蓝色鲸尾，不留下矩形缺口。保持无眼无嘴底图、原肤色、头发、衣服、围裙标志、裙摆与鲸尾轮廓；白底、单张生产底图，不是拼图，无文字和水印。
- 只在原四肢遮挡孔洞接入身体补画；不直接用整张重绘替代已核对的脸。
- 上肢按肩 / 肘 / 腕 / 掌，下肢按髋 / 膝 / 踝 / 鞋尖手工标注。每肢三段透明纹理只平移和旋转，局部圆形盖片补齐关节缺画；不使用线性蒙皮或横带变形。
- 袖子中的围裙 / 蕾丝误切白片去掉，鞋子从实际鞋口分开；膝盖不能沿用最初错位的袜口锚点。
- 运行 `python3 人物/立绘/tools/prepare-rigid-whale.py` 可重复生成分段、bind 与来源哈希。该命令不调用图片或视频模型。
- 此轮没有导出新视频。调试入口 npm run rig:preview，直接复用模板 Tachie，不是旧样片播放器。

- 本轮实际图片工具输入原文已补存到 `docs/prompts/whale_body_cleanplate.en.txt`；输入 / 输出与历史缺口统一见 `docs/prompts/本鲸_图片生成提示词与资产对应.md`。
