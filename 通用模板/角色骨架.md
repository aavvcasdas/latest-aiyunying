# 通用角色：固定骨长、走路与表情

## 当前入口

运行 `npm run rig:preview`，打开 5173 端口。根页面进入骨骼定格台，而不是旧 paperdoll 样片页面。这里直接实例化通用模板的 Tachie，与影片使用同一个类和绘制函数；不编码、不导出视频。

可播放 / 暂停、按 30fps 逐帧、拖时间定格、切换绑定直臂 / 走路 / 招手、显示骨架和支撑脚、固定右肩与肘角。肘角 0 表示上臂与前臂共线，手掌另有腕关节，不再把一整组 hands 图片晃动当作骨架。

## 真正改变的路径

- `通用模板/engine/rigid-character.ts`：通用三段刚性骨链、FK / 两骨段 IK、支撑与摆动相、独立表情绘制。
- `通用模板/engine/assets/rigid/whale/bind.json`：实际关节点、脸部锚点、地面高度及每根骨段纹理；不是横带百分比。
- `通用模板/engine/tachie.ts`：带 rig 的角色强制走新路径，缺绑定报错，绝不回退到旧横带形变；在 commit 时重画，expression / pose 在 act 之前或之后调用都生效。
- `通用模板/engine/tachie-assets.ts`：一起注册和预载身体、双眼、每肢三段，共 15 张运行时纹理。运行时不依赖 paperdoll 播放器或其 JS。
- `人物/立绘/tools/prepare-rigid-whale.py`：手工切层、局部关节补画和生成的无肢体底图接入。肢体纹理不缩放、不拉伸；来源与未知的模型 / seed 如实写在对应 provenance 文件。

原有八张单层立绘仍保留历史行为，不声称它们自动拥有独立手脚或喜怒哀乐。新角色要提供各自的分层、骨架与脸部锚点，再调用 setTachieRigid 注册；不能从一张 PNG 猜出正常骨架。新的骨架协议和运动求解器可共用，关节点与原画不能冒用。

## 镜头中使用

先在 project.tsx 中 import '@tpl/tachie-assets'，并把 `() => preloadTachie('whale_cutout')` 放进 preloads。

```ts
const actor = k.tachie('whale_cutout');
return f => {
  actor.actFrame('walk', f).expression(f.said >= 1 ? 'joy' : 'happy');
  actor.at(startX + actor.travelX(), 0, 0);
  return camera;
};
```

travelX 是步态的前进距离。加到角色位置后，支撑期脚踝在世界中固定；不加则是跑步机式原地观察。不能一边不加前进距离，一边宣称脚掌在世界中完全不滑。

调试可在每帧调用：

- `pose({arm_R: [0, 0]})`：肩角相对向下为 0，肘屈曲为 0，直臂。
- `freeze(0.3)`：骨架与表情时钟都定格到指定秒。
- `bones(true)`：显示关节点、骨链与支撑脚，仅调试时开启。
- `rigState()`：返回定格后的全部真实关节、接地状态与前进距离。
- `face({mouth: 0.5, blink: 0})`：独立嘴形与闭眼程度，不冒充实测音频口型。
- `expression('neutral' | 'happy' | 'angry' | 'sad' | 'joy' | 'surprised', strength)`：眼睛、眼睑、眉形、嘴形与泪光联合驱动，不只是标签变化。

begin 每帧复位上述修饰量；每帧重新声明。正序预检、逆序预检、实际影片都执行同样的复位。刚性角色尚未实现的 blend 或旧动作会报错，不再悄悄掉回软形变。

## 走路与表情的边界

每肢包含上段 / 下段 / 手掌或鞋；骨段只做平移和旋转，渲染器内没有 scale、shear 或横带。IK 不可达直接报错，不能伸长骨头兜底。双膝向同一个前进方向屈曲，脚掌姿态独立；摆动脚抬离地面，双臂反相摆动。

当前用正面本鲸原画实现二维步态，**不是自然侧面行走的逐帧复刻或三维人体重建**。袖子本身的圆润造型仍来自原画；固定骨长不等于已经得到完美的透视和遮挡美术。还需要人工确认步态观感和肩 / 膝的轮廓，机器测试不代替视觉签收。

新模板表情是同步、确定性的独立图层 / 路径绘制，不是把旧实验的 IkiPlayer 冒称已经接入模板。旧 Iki 实验只覆盖开合参数；新的喜怒哀乐在模板每帧真实求值。后续若使用 Iki 扩展绑定，仍须提供相应眉眼嘴差分与参数，不能只改参数名称。
