# 待授权的图片资产制作说明（不自动执行）

仓库默认不新增生图、不换画风。本文件仅是后续获授权时的制作提案；本轮没有调用图片或视频生成模型，没有替换任何角色素材。

## 先列镜头缺什么，而不是一次生八个角色包

以一个递物镜头为例，核对是否已有：

- 主姿态与递出 / 接住的关键姿态差分；
- 可独立运动的上臂 / 前臂、手部与道具；
- 肩、肘连接处的重叠余量和被遮住的衣料；
- 图层顺序、关节锚点与原画布坐标。

已有资产能满足就不生图。默认继承 Q 版像素风；水彩、蜡笔或高清重绘必须另获风格变更授权。

## 参考提示词（按缺失部件局部编辑）

```text
Use the supplied character reference and approved art style.
Edit only the selected region for the requested pose or isolated part.
Keep the character's identity, outfit, proportions and palette unchanged.
Show the complete attachment area with overlap allowance at the joint.
Use the approved canvas and registration coordinates.
No text, no watermark, no extra limbs, no baked drop shadow.
```

这只是约束意图，不能保证模型实际做到了“像素级一致”。对参考图、脸部、服饰和肢体数量逐项审核；必要时人工修边与补画。

## 背景与透明度

优先有效透明通道。色键底色必须避开角色颜色；绿底可能吃掉绿发，白底可能吃掉白衣。纯色背景不等于已经抠像，抠像后检查半透明饰品与发丝残边。

## 交付清单

- 每张 PNG 对应原画布偏移、pivot、z 层级；
- 左 / 右按角色自身方向定义，不按观看者方向；
- 部件接缝在目标输出尺寸下无裂口；
- 面部差分只改批准区域，无衣服 / 发型漂移；
- 道具单独 PNG，不把假手画在道具上；
- 来源、许可、授权、SHA-256 与能力清单入档；
- 单层素材只声明整图能力，不声明抬臂 / 接物 / 口型。

`tools/split_parts.py` 仅提供可按坐标拼回的水平裁片，**不是**上面这套资产制作流程。
