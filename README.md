# 鲸鱼娘 · MV 工作区

本分支只保留 MV、人物设定与人物调研，以及制作所需的共用引擎。

## 作品

- [童话镇](番外MV/童话镇/README.md)：通用模板参考作品。
- [坏女孩 · Three.js](番外MV/坏女孩/README.md)：三维版本。
- [坏女孩 · Fable](番外MV/坏女孩Fable/README.md)：软件 3D 版本，逐句歌词轴与多镜头间奏。

## 人物与资料

- [人物设定](设定/README.md)：一人一页，资产与角色规矩一并保留。
- `参考资料/项目调研/`：人物形象、角色适配及 MV 镜头研究。
- `参考资料/参考MV/`：MV 参考。
- `参考资料/历史MV工程/`：从旧存档筛出的 MV 工程，只读参考；不包含日更与运营。
- `设定/历史素材元数据/`：旧人物素材的来源、许可与切片元数据（不是原图）。
- `《雨爱》司凤版.mp3`：保留的 MV 音源。

## 制作

先读 `AGENTS.md` 和 `通用模板/README.md`。

```bash
npm ci
npm test
npm run typecheck
npm run new -- mv 番外MV/某首歌 "某首歌"
node tools/render_zip_mv.mjs fable
```

MP4 仅保留已获授权的《坏女孩》两版，详见 `媒体说明.md`。原曲版权不因项目代码开放而授予。
