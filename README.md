# newday · 鲸鱼娘 AI 短片

> **这份仓库是从 `aavvcasdas/newday` 的 `arena/a300c598-newday` 分支整份迁过来的**（代码、文档、测试、字体、图集全部在）。
> 大媒体（约 1.08 GB、714 个文件：旧的 MV 成片、存档里的立绘与图集、样板样片）留在原仓库，清单和取法见 [`媒体说明.md`](媒体说明.md)。
> 唯一带过来的大件是 `Day/Day14/成片/Day14_无声样片.mp4`（36.4 MB）——Day15 的电视机要放它。

用项目自带的八位像素角色，做两种短片：

- **Day 口播片**：鲸鱼娘第一人称讲当天的事，一句台词一屏字。
- **番外 MV**：给一首歌配满镜头，歌词卡拍。

两种片子现在共用一套做法：**three.js 搭 3D 世界，像素角色当 2D 纸片人站在里面，Remotion 逐帧渲染，音轨按采样对齐混入。**

> **2026-11 重构。** 这次按《童话镇》立体童话书复刻那一页的源码（`通用模板/来源/remotion-fix-and-mv-recreation.zip`）把整个项目重做了一遍。
> 此前的全部成片、引擎、模板和 skill **已废除**，原样移进 `存档/重构前/`，只留档、不再使用、不再维护。
> 新片一律用 `通用模板/`。

## 开始

```bash
npm ci
pip install --user numpy pillow

npm run film -- info 番外MV/童话镇        # 看时间轴
npm run film -- sheet 番外MV/童话镇       # 出分镜总览图
npm run new -- day Day/Day15 "标题"       # 新开一集口播
npm run new -- mv 番外MV/某首歌 "某首歌"   # 新开一部 MV
npm run preview                           # 浏览器里的预览台
npm test && npm run typecheck
```

完整用法、作品结构、写镜头的规矩、可用的角色造型和道具：[`通用模板/README.md`](通用模板/README.md)。
谁是谁、怎么说话、能演什么形象、哪些话不许说：[`设定/README.md`](设定/README.md)（**一人一页**，在 `设定/人物/`；共用的规矩在 `设定/AI娘设定总纲.md`；Day 线速查 [`Day/设定表.md`](Day/设定表.md)，MV 线速查 [`番外MV/设定表.md`](番外MV/设定表.md)）。

## 几条不变的规矩

- 新片**零水印、零角标**；画面里不出现粉丝数、播放量、进度条、数据图表。
- 时间只认实测：没对过音频的卡点（`measured=false`）只能出「无声样片」，出不了成片。
- 缺素材直接报错，不拿别的造型顶替。
- 自检（`qa.json`）只能证明「没坏」；好不好看、听着对不对，要人从头到尾过一遍。

## 公开发布前要自己确认的事

这些问题重构前就挂着，这次重构**没有解决**，只是原样带了过来：

- **角色形象**：八位角色的像素造型沿用重构前的项目素材。存档里的旧文档记着「上游人物图像的再分发许可仍未确认，公开传播前须核权」（`存档/重构前/Day/Day14/Day14方向.md`），这件事到现在没有人核过。逐项清单与已知来源链见 [`素材许可与来源.md`](素材许可与来源.md)。
- **音乐**：《童话镇》的原曲录音（素材目录里的 童话镇.mp4）没有任何授权记录。这支音源和成片都太大了，没有随本次迁移进这个仓库，见 [`媒体说明.md`](媒体说明.md)。
- **平台声明**：片子里不放「AI 生成」角标，合规声明要在发布页用平台自带的声明功能补上。
